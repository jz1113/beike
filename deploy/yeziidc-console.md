# 椰子云控制台：安全组与重置密码

实例：`ser757364384684`  
公网 IP：`103.108.66.184`  
不要放行 3000。

当前实测：22/80/443 的 TCP 能连上，但 SSH 在握手前就被断开。空安全组不要留着，按下面显式放行。

## 1. 新建安全组（你现在的空白表格页）

1. 确认右上角实例是 **开机** 状态。若是关机，先点 **开机**，等变成运行中。
2. 停在 **安全组** 这一页，点蓝色 **新建安全组**。
3. 名称填 `beike-web`，描述可空，保存。
4. 点进刚建好的那一行（名称或「管理 / 规则 / 操作」）。
5. 找 **入站规则 / 添加规则 / 授权端口 / 允许的端口**，用 TCP、来源 `0.0.0.0/0` 或「全部」，加三条：

| 端口 | 用途 |
| --- | --- |
| 22 | SSH，用来远程安装 |
| 80 | 浏览器打开 `http://103.108.66.184/` |
| 443 | 以后 HTTPS |

有的弹窗是一个输入框「允许的端口」，直接填：`22,80,443`。
若有「常用端口 / Linux」模板，勾选 22、80、443 即可。

6. 回到实例，确认 `beike-web` 已出现在安全组列表里。没有的话找 **绑定 / 应用 / 关联实例**，绑到当前这台。

做完把安全组列表截图发来。弹窗对不上也截图。

## 2. 重置 root 密码

1. 点顶部 **设置**（安全组右边）。
2. 只点 **重置密码 / 修改密码**。不要点重装系统、不要点救援系统。
3. 设至少 12 位、字母+数字的密码，提交。
4. 右上角点普通 **重启**（不要硬重启），等 1～3 分钟显示运行中。

**设置**里没有重置密码时，先看 **概要**，仍没有再截图，不要自己点 VNC/救援系统。

## 3. 发这三样继续安装

- IP：`103.108.66.184`
- 用户名：`root`
- 刚重置的密码

收到后在本机执行：

```bash
BEIKE_SSH_HOST=103.108.66.184 BEIKE_SSH_USER=root BEIKE_SSH_PASS='你的密码' \
  bash tools/scripts/deploy/remote-install.sh
```
