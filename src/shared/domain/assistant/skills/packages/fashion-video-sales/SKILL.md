# 服饰带货视频

## 范围与事实
仅适用服饰、鞋、包。锁定当前 SKU 颜色、清晰商品图、目标时长与画幅；属性和可见外观是事实，创作卖点是提炼，不编造功效、销量、价格、尺码或实测体验。用户提供链接时先解析；历史商品用 `list_user_products` 找到实际记录。

## 阶段一：商品与脚本
1. 核实商品与颜色图，不混用其他 SKU；缺少关键外观时暂停对应设计。
2. 阅读 `references/production.md`，按秒数规划连续分镜与口播，明确每段 `on_camera` / `voiceover`。未明确开箱且无必要换装时，服装优先直接上身的生活穿搭。
3. 出镜讲解段需要嘴部可见和可执行动作，默认正常距离的中景、中全景或全身。纯商品/手部方案服从用户选择。
4. 口播采用自然中文；按目标时长校验字数和停顿，不靠倍速塞入台词。

## 阶段二：素材
根据脚本优先规划同一成年人物已穿着或拿着商品、位于目标空间的可用讲解帧；空景、人脸和其他视角按需增加。人物年龄、场景、光向从商品与受众需要出发。商品结构、颜色、标识锁定原图。每张素材给独立 `image-prompt`，明确素材名、用途、参考顺序。
仅有提示词不能当作已得到图片。需要生成时先形成清单，再按用户明确要求用 `trigger_generate_batch` 提交。保留成功素材与原任务回执。

## 阶段三：视频定稿
只有实际人物/场景图片已获得并核对，才基于最终提交顺序定稿。此前可交付「待素材确认的脚本草案」。读取 `assets/final-video-prompt.md`，用一条完整 `video-prompt` 串起场景、参考职责、按秒动作与原台词、逐段声音来源、光向、输出和不变项。分镜是同一条视频的时间线，不能擅自改成逐镜拼接。

## 验收与恢复
台词逐段原文一致；出镜段有口型要求，画外音段不要求无脸画面对口型。无字幕、贴纸、价格条或无依据宣传。每段和全片时长都通过文字核算。参考图片或顺序改变时重新定稿；提交结果未知先核对回执，不重复计费。拿到视频后仍需实际听看确认口型，不能用任务成功代替质量结论。

参考成片只吸收有文件和时间点依据的机位、动作与节奏；剪辑候选需目测复核，频谱不能证明台词、语速或口型。未读取或未听辨的内容明确标注，不复制参考人物身份、声音、商品宣传或多款换装。优化先形成可检验假设，不把技能更新当作成片质量已提升；付费对比生成需用户明确要求。
