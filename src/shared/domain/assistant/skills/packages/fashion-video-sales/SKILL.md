# 服饰带货视频

## 范围与事实
仅适用服饰、鞋、包。锁定当前 SKU 颜色、清晰商品图、目标时长与画幅；属性和可见外观是事实，创作卖点是提炼，不编造功效、销量、价格、尺码或实测体验。“我买过”“我穿了一整天”“我当时第一眼”等经历，须有当前讲解者的真实素材明确提供；参考口播、商品介绍或生成画面不能证明经历、触感与效果。用户提供链接时先解析；历史商品用 `list_user_products` 找到实际记录。

## 工作室与对话共用规则

`references/production.md` 是创作规则的维护入口，包含事实、叙事、日常风格、动作连续性、景别、口播、素材与选角。分析时加读 `references/analysis.md`；分镜配商品图时加读 `references/selection.md`。工作室按阶段读取相关章节，选择技能后不得改走另一套代码内置创作规则。图片生成只读取静帧相关规则及 `assets/image-reference-roles.json` 中的参考职责，不把口播时间轴抄进静帧。

`references/content-quality.md` 是电商视频质量的通用维护入口，规定低质阻断、普通与优质的区分，以及声画、信息、叙事、人设和成片人工验收口径。分析与脚本用它规划信息增益，素材与定稿用它检查画面和声音，成片阶段用它区分已验证与待验证；它不能替代具体类目的商品事实或平台审核。
构建脚本与分镜时读取 `references/directing.md`：按当前问题选择结果解释、结构解释或步骤推进，区分语义段、动作单元与剪辑镜头，并检查比较条件和状态衔接。素材阶段只读其中「商品层次与构图」，实际图定稿读「分镜信息与状态设计」「提示词编排与取舍」。教学草案只在需要示范写法时读取，不作为固定商品、台词或时间轴。

实际图定稿时读取 `assets/final-video-prompt.md`。`references/render.md` 只用于提交成片的精简执行约束，不包含教程与内部 ID。规则内容摘要随阶段结果保存；技能规则变化后须更新相关方案并重新确认，保留原图片、回执和成片，不自动付费重投。

`assets/runtime-directives.json` 保存工作室脚本示例、出镜方式、声音来源与成片参考职责的具体措辞；`assets/speech-limits.json` 保存与口播规则配套的字数边界和空号召清单。维护口播数值时同步正文与此资源。它们按当前参数填充，不能用于覆盖用户已确认的事实、台词或拍法。示例只说明字段与一种可行拍法，不限定镜头数、地点或生活动线。

## 阶段一：商品与脚本
1. 核实商品与颜色图，不混用其他 SKU；缺少关键外观时暂停对应设计。
2. 阅读 `references/production.md`，按秒数规划连续分镜与口播，明确每段 `on_camera` / `voiceover`。未明确开箱且无必要换装时，服装优先直接上身的生活穿搭。
3. 出镜讲解段需要嘴部可见和可执行动作，默认正常距离的中景、中全景或全身。纯商品/手部方案服从用户选择。
4. 先写顺全片台词，再按完整语义、换气和动作分段；首句先交代商品或穿搭意图，再带出主要看点，中间用相关事实解释，末句回应该看点并收住，不逐段各造一句。不要一上来“先看这件黑色”或报局部术语，也不要把最后一个属性当结尾。新稿全片优先每秒5–6个汉字，即15秒75–90字、20秒100–120字、30秒150–180字；开口、换气和收势统一留短空隙，不逐段停住。明确长展示先扣除静默时长，超时删次要细节。连读检查语境、承接和完整结尾后再输出；表达功能不等于固定三镜，定稿仍保留已确认原文。保留少量自然重复、短句和语气词；“你看”“这里”“这一块”须有同段可见所指及对应视线或必要展示动作，不逐句安排手势，不靠倍速或拖腔填满时长。
5. 先分清本片以对镜交流还是穿搭展示推进，服从已选出镜方式与各段声音来源，再在生活穿搭内选择连续讲述、同空间切镜或短途日常动线。试穿观察本身即可串起内容，不为每段另造小事或表情原因；15秒连续讲述优先一个主机位与一至两个必要操作，切镜方案通常保留2至3个行动片段。普通强调手势不必碰衣服，连续后段继承前段动作与商品状态；抓拉、扣合、拉链等状态变化才需明确物理过程，不编排每次眨眼和收势。正背正不是默认结构，背面须有商品证据和独立信息。

## 阶段二：素材
商品保色按 `references/production.md` 的「商品颜色保真」执行：SKU 色名只识别当前款色，具体色相、明度、饱和度与冷暖以当前允许原图为准，保留浅色、灰调和低饱和限定。商品主体用中性白平衡及保留面料层次的曝光，场景氛围不重染衣物；前置生成素材不提供新的颜色事实。人工确认须对照原图均匀受光的面料，明显偏色先更新素材，再定稿视频。

根据脚本优先规划同一成年人物已穿着或拿着商品、位于目标空间的可用讲解帧；空景、人脸和其他视角按需增加。人物年龄、场景、光向从商品与受众需要出发。每份新方案按商品风格、可核实的季节与穿着场合、颜色及动作自主构建背景，比较合适的空间方向后选定起点，写清用途、布局、材质配色、必要陈设、自然光来源与机位；skill 示例只参考方法，不复用固定布景或轮换清单，不把住处、玄关与侧窗光设为默认。用户明确要求沿用的场景保留；同片同地点保持连续，不为多样性强制每段换景。不默认精修模特站姿和落地窗样板间。背景结构可辨，与人物曝光一致；不要电影虚化、人物发光或刻意脏乱。商品结构、颜色、标识锁定原图。商品图只约束衣物，不带入原模特、白底和棚拍光；人物图跨场景继承身份，上身关键帧约束对应镜头构图；场景图只约束使用它的镜头空间和光线，新地点不搬入原人物图背景。不冻结表情和褶皱。素材总量1至4张，每个实际地点有对应素材，先裁剪路线再生图。每张素材给独立 `image-prompt`，明确素材名、用途、参考顺序。
仅有提示词不能当作已得到图片。需要生成时先形成清单，再按用户明确要求用 `trigger_generate_batch` 提交。保留成功素材与原任务回执。

## 阶段三：视频定稿
只有实际人物/场景图片已获得并核对，才基于最终提交顺序定稿。此前可交付「待素材确认的脚本草案」。读取 `assets/final-video-prompt.md`，用一条完整 `video-prompt` 按画面质感与拍摄方式、人物与商品参考、场景与道具、情绪与表演、时间轴与剪辑、声音与输出分区。按实际动线串起各镜地点与参考、机位、展示目的与主要动作、必要的接触与状态变化、切点和原台词。连续后段只写变化，不重新布置开场；普通跳切可省等待，只有匹配剪辑要求姿态对应。连续或切镜由内容决定，每个场景沿用自身光向。同一台词在完整提示词内只写一次，声音并入该时间段，不重复列一遍声音时间轴，不逐镜重抄不变项与整套禁令，不抄编写教程和内部素材 ID。分镜是同一条视频的时间线，不能擅自改成逐镜拼接。

## 验收与恢复
台词逐段原文一致；出镜段有口型要求，画外音段不要求无脸画面对口型。无字幕、贴纸、价格条或无依据宣传。每段和全片时长都通过文字核算。参考图片或顺序改变时重新定稿；提交结果未知先核对回执，不重复计费。拿到视频后仍需实际听看确认口型，不能用任务成功代替质量结论。

参考成片只吸收有文件和时间点依据的机位、动作与节奏；剪辑候选需目测复核，频谱不能证明台词、语速或口型。未读取或未听辨的内容明确标注，不复制参考人物身份、声音、商品宣传或多款换装。提示词示例只学参考分工、生活动线与分区写法，不复制23岁女性、道具、所有场景必须出现或不要台词。Mixed和node-asset占位在最终定稿中必须转换为实际图片编号，不保留未绑定引用。优化先形成可检验假设，不把技能更新当作成片质量已提升；付费对比生成需用户明确要求。
