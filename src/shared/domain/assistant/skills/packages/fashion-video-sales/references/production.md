# 带货脚本与素材约定

商品事实来自当前 SKU 属性与同色清晰图。记录可见结构、颜色、标识和无法确认项，单品唯一。人物设为适合受众的成年人，保持全片同一外貌；不从照片推断真实族裔。

全片口播参考 3.2–4.6 汉字/秒规划，并给句间停顿；这是编写目标，实际需听看确认。逐段检查台词容量，避免每秒约 6 字以上的高密度段落。目标秒数变化时重算，不用总字数平均掩盖局部拥挤。

每段 speechMode 明确为 on_camera 或 voiceover。出镜段嘴部可见、由画内人物说完整原文，要求唇形、下颌、起止同步，停顿时停嘴；画外音不要求无脸画面对口型。

素材规划先提供人物全身穿搭与纯场景图，必要细节从实际脚本决定。默认正常距离的中景、中全景或全身，禁止把每个卖点机械转为 logo 特写。

素材变更、参考顺序变化、商品事实或时长变化时，标记相关最终稿失效，保留历史并重新定稿。成功且输入未变的素材可复用，原回执未知时不重复计费提交。

实拍展示默认固定手机机位，背景墙线、家具、曝光与白平衡稳定；自然妆容可以保留，不靠额外毛孔、噪点、脏乱、失焦、周期晃动或曝光跳变制造真实感。背景保留可辨空间，不用重度虚化或电影轮廓光遮盖接触与透视问题。

每个语义段围绕一个可见事实安排一个主要动作，写清起始姿态、接触部位、结果与收势。例如捏住侧边衣摆轻拉后松手，手先接触再带动褶皱，松开后依重力回落；没有材料性能依据，不把动作当弹性或舒适性证明。脚先承重再换重心，袖口、衣摆和头发随动作滞后后收住，不脚滑、穿模或无风飘动。说话可配嘴部无遮挡的小手势，转身与大幅低头放在句间，不每句结束都僵住，不循环点头或微笑。

分镜是语义时间段，不强制每段切镜或换参考图。按商品与台词需要安排连续展示或硬切，不均分镜头，不把长片的多款、多色、换装与全部手势压进短片。换装只在明确剪辑点发生，不连续变形换衣。半拍是自然换气，避免每句等长空白或逐字拖腔；环境声随实际动作出现，不强加衣料和脚步音效。

参考片记录文件、时间点、观察及可复用方法，不把背景差分候选当准确镜头数，不从频谱声称已听清台词、语速或口型。只吸收拍法，不复制参考人物脸与声音或未经证实的商品宣传。对比验证先固定同一 SKU、时长、画幅、模型和参考图，只改提示词，再单独比较素材；种子只有模型支持且已提供时才沿用。逐项记录商品与身份、接触与承重、背景稳定、表情与口型的问题秒数，付费生成另需明确授权。
