# 商品分析与合并

只根据当前 SKU 原始属性与当前允许图片分析。knownFacts 记录能回到原始资料或可见外观的事实，未知项保持未知；sellingPoints 至少提炼两条不同的有依据事实，用日常的话解释可见位置、形状、穿着场合或搭配，并说明依据，不生成必须照念的论证箭头。推不出场合或搭配就不要强写，不把模型提炼结果当新增证据。
creativeNotes 与 videoSuggestions 是创作建议，按开箱换装、生活穿搭、鞋包展示选择，不当商品事实；keyVisuals 只列实际会展示的位置。usageScenarios 与 painPoints 的推断要与已知事实分开，不推出触感、性能、购买与穿着经历。画面优先自然生活环境与正常距离展示，不默认棚拍、精修模特、推近或标志特写。
在 creativeNotes 中用简短建议说明本片的受众与需求假设、主要选择问题、开头可展示的看点和需要补充的证据；不要新增顶层协议字段。核心卖点关联 knownFacts 中的原始依据，并说明实际要展示什么及能支持到何种结论。事实不够时明确缺口，不凑两条、不把推荐拍法或生成演示当证据；只有普通外观介绍的方案说明尚缺哪项实用解释，不能自评已产出优质成片。
多批合并时去重，保留原始依据；矛盾或无法对应当前颜色的内容标明未知，不凭模型票数决定事实，不补写任一批均无依据的说法。禁止价格、金额、优惠、销量、功效和未经证实的实测结论。
