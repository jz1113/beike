# 成片执行约束

主体清晰明亮、曝光适当、色彩自然，环境整洁，当前展示的商品部位完整可辨。开头按既定脚本展示当前商品与看点，不插入白底商品广告图或静态图片轮播。

交付规格固定为竖屏9:16、原生480P、时间线30fps。生成后必须将视频转码输出为720×1280；交付记录同时写明原生文件、转码工具或服务、输出文件和完成状态。普通尺寸转码不称为超分，未完成转码时保持“待转码”。

字幕与信息层在生成视频完成后最后叠加。视频模型输出不得新生成字幕、贴纸、价格条、参数文字、花字、箭头、线条、虚构品牌标志或其他可读文字；当前 SKU 原图中已有的商品标识、刺绣、图案和标签应保留在自然比例与原位置，不得新增、改写、删除或放大成广告牌。剪辑阶段再加入逐句卖点字幕、大字号关键词高亮、尺寸/材质/折扣等参数贴片、必要的指向线，以及约3–4秒的商品细节特写或独立空镜。每个后期文字都要能回到已核实资料或已确认台词，不能让模型猜字；贴片不得遮挡人脸、嘴部、手和商品关键结构。

前3秒检查强钩子是否已经出现：商品、人物或具体场景中的选择理由/冲突必须可见，并在后续兑现。视频时长控制在13–25秒，默认13–15秒约75%、15–20秒约15%、20–25秒约10%，不固定为单一时长。完整交付默认包含独立 BGM 轨，优先使用可商用或客户提供的音乐，并在后期混音中压低到不盖过人声、口型和关键环境声；客户明确不需要时关闭。交付单写清BGM、环境声、字幕、参数贴片和转码状态。

按脚本选定的对镜交流、穿搭展示、开箱换装或鞋包使用展示推进，按时间轴指定的机位、相机距离、画面范围、场景和剪辑点拍摄；连续段不自动切镜，明确切镜的段落按对应场景参考衔接，不在连续帧里改变空间。每个时间段必须出现可观察的新事件、动作结果、商品状态变化、相机范围变化或明确切点，不能只替换台词而保持同一帧。人物身份和当前商品全片一致，各场景使用自身参考的光向与陈设，背景结构可辨，人物与环境曝光一致。商品原图只约束衣物，不带入白底或原模特。
出镜说话段须让嘴部、主要服装和本段要解释的商品部位同时清楚可见；画外音段按脚本构图，不强加人脸或画内开口。镜头距离、画面范围和机位方向按信息任务决定，不固定显示景别枚举。

【动作与连续性】
按脚本选定的交流或展示方式推进，台词中的你看、这里、这一块与同段可见所指相合。连续段继承前段的手位、接触和商品状态，不随台词分段重新站定或放手。必要衣物操作先接触再带动布料，松手自然回落；领口、扣子与拉链只随有效操作或明确跳切改变状态。
说话和普通手势可以重叠，身体与衣物自然连带；可以看镜头讲完一个意思，不每句低头再抬头，不安排重复的抓拉、放手、微笑循环。人物可佩戴位置合理的领口收音夹；只有微动作有明确的信息或展示目的、且能自然完成时才加入。否则自然说话、观察或保持当前状态即可，不为了制造生活感强行喝水、查看监视器、走动或堆动作清单。普通跳切可省略等待，不要求回到起始姿态；匹配剪辑按脚本执行。不额外增加背面展示、换装、推近、变焦或慢动作，不添加磨皮、电影虚化、故意抖动或曝光跳变。若出现僵脸、错口型、手部畸变或收音夹穿模，按问题时间点优先做局部嘴部/手部/配件重生成并复核连续性。

【口播与声音】
标准普通话，吐字清楚，人声音量稳定，无明显底噪、爆音或失真；台词所指的部位、动作和结果与相应时间的画面同步。
自然聊天语速，停顿随语义和动作变化，嘴型与原文对齐。以轻快的穿搭分享节奏按短语连贯说，非重点顺着带过，重点自然强调，不逐字等速朗读或拖长尾音。开头可承接已在进行的观察或动作直接自然开口，不从半句话切入；段间接着说，不每段重新起腔或站定等待。全片只统一留短换气与末句收势，不为每段重复预留头尾，不为了填满时长拉长台词。末句完整说完后短暂自然收势，均在原时间轴内完成，不抢话、倍速或截断句尾。出镜段由画内同一人物亲口说出台词，中文发音、唇形和起止同步，停顿时自然停嘴；画外音段不假装开口。轻重音自然，不逐字拖长或等长停半拍。保留轻微环境声，环境声随实际动作出现，不盖过人声。BGM 由后期独立混音，不要求视频模型在画面中生成音乐文字或任何字幕；人声、环境声和BGM的存在与混音状态在交付记录中分别确认。
