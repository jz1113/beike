# 成片执行约束

主体清晰明亮、曝光适当、色彩自然，环境整洁，当前展示的商品部位完整可辨。开头按既定脚本展示当前商品与看点，不插入白底商品广告图或静态图片轮播。

日常穿搭分享，按时间轴指定的机位、景别、场景和剪辑点拍摄；连续段不自动切镜，明确切镜的段落按对应场景参考衔接，不在连续帧里改变空间。人物身份和当前商品全片一致，各场景使用自身参考的光向与陈设，背景结构可辨，人物与环境曝光一致。商品原图只约束衣物，不带入白底或原模特。
出镜说话段用嘴部与主要服装同时可见的正常距离中景说话；画外音段按脚本构图，不强加人脸或画内开口。

【动作与连续性】
按脚本选定的交流或展示方式推进，台词中的你看、这里、这一块与同段可见所指相合。连续段继承前段的手位、接触和商品状态，不随台词分段重新站定或放手。必要衣物操作先接触再带动布料，松手自然回落；领口、扣子与拉链只随有效操作或明确跳切改变状态。
说话和普通手势可以重叠，身体与衣物自然连带；可以看镜头讲完一个意思，不每句低头再抬头，不安排重复的抓拉、放手、微笑循环。普通跳切可省略等待，不要求回到起始姿态；匹配剪辑按脚本执行。不额外增加背面展示、换装、推近、变焦或慢动作，不添加磨皮、电影虚化、故意抖动或曝光跳变。

【口播与声音】
标准普通话，吐字清楚，人声音量稳定，无明显底噪、爆音或失真；台词所指的部位、动作和结果与相应时间的画面同步。
自然聊天语速，停顿随语义和动作变化，嘴型与原文对齐。以轻快的穿搭分享节奏按短语连贯说，非重点顺着带过，重点自然强调，不逐字等速朗读或拖长尾音。开头可承接已在进行的观察或动作直接自然开口，不从半句话切入；段间接着说，不每段重新起腔或站定等待。全片只统一留短换气与末句收势，不为每段重复预留头尾，不为了填满时长拉长台词。末句完整说完后短暂自然收势，均在原时间轴内完成，不抢话、倍速或截断句尾。出镜段由画内同一人物亲口说出台词，中文发音、唇形和起止同步，停顿时自然停嘴；画外音段不假装开口。轻重音自然，不逐字拖长或等长停半拍。保留轻微房间声，环境声随实际动作出现，不盖过人声。
