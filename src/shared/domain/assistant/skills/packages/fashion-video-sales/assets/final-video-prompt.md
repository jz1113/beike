# 整条带货视频提示词

以下为填写模板；先选择拍法，删去未使用的分支与空白说明。只有实际参考图完成并核对后才填入实际编号交付最终视频提示词，素材未齐时仅标为「待素材确认的脚本草案」。

正文中的章节名、画面说明、动作与声音要求一律使用中文，不写英文协议值或字段名。只有外层数据字段和声音类型枚举沿用接口约定；已确认台词原文逐字保留。各章节和每段时间轴独立换行，不重复通用执行约束。

主体清晰明亮，曝光适当，环境整洁，当前展示的商品部位完整可辨；首个画面与脚本开头的商品及看点相符，不另做商品广告图开场。

{行动路线及实际空间}，图片{实际编号}负责{相应镜头的布局、光线与陈设}。{确有需要的道具、位置与使用方式，没有则省略}。人物身份跨地点一致，新场景不搬入原人物图的背景；每个场景按自身参考曝光和光向拍摄。
商品保持已人工确认素材与对应商品规格原图的色相、明度、饱和度及冷暖，场景光只产生合理局部明暗，主体采用中性白平衡与保留面料层次的曝光，不额外增艳或用氛围滤镜重染商品。

{按实际分镜继续，时间连续且总和精确，不均分秒数，不照抄样例时间码。同一连续镜头的后段继承前段手位与商品状态，只写变化，不重抄不变项和整套禁令，不为每段新增表情或收势。台词中的你看、这里、这一块对应同段可见部位及脚本已有的视线或必要展示动作，不擅自追加操作。保留口播原文的少量自然重复、短句和语气词。跨地点明确切镜，连续镜头内不变房间；匹配剪辑保持剪辑点身体位置，普通跳切可省去等待和重复整理，不要求先站正微笑再切镜。}

【声音与输出】
标准普通话，吐字清楚，人声音量稳定，无明显噪声、爆音、失真或忽大忽小；台词所指部位和动作与对应画面同步。
同一人物轻快的穿搭分享声线，短语连读，句内有轻重音与局部快慢，停顿随语义和动作变化，不逐字拖音。开头可承接正在进行的观察或动作自然开口，段间承接而非重新起腔或站定等一拍；全片统一留短换气与末句收势，不逐段重复留白，不把短台词拖满时间。末句完整说完，在既定时间内完成，不抢话、倍速或截断句尾。出镜说话段嘴部清楚可见，画内人物亲口说原文，中文发音、唇形、起止同步，停顿自然停嘴；画外音段画内人物不开口。同一段台词只写在对应时间范围，不另抄声音时间轴。环境声随当前地点和动作出现，不盖过人声，不自行增加配乐。
真实速度，无字幕、贴纸、价格条。身份和当前单品全片一致，空间和光向在对应镜头内稳定；不冻结姿势、表情和每道褶皱。不添加无依据的卖点、背面展示、换装或运镜。

15秒连续讲述优先一个主机位、一至两个必要操作；生活切镜通常保留2至3个可完成的行动片段，数量不是硬指标。不默认正背正，不强求一天所有地点。整段一次生成，时间分镜不改成逐镜任务。编写教程、模板说明及未填写的占位不进入最终提示词。
