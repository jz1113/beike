# 整条带货视频提示词

以下为填写模板；先选择拍法，删去未使用的分支与空白说明。只有实际参考图完成并核对后才填入实际编号交付最终视频提示词，素材未齐时仅标为「待素材确认的脚本草案」。

正文中的章节名、画面说明、动作与声音要求一律使用中文，不写英文协议值或字段名。只有外层数据字段和声音类型枚举沿用接口约定；已确认台词原文逐字保留。各章节和每段时间轴独立换行，不重复通用执行约束。

【画面质感与拍摄方式】
{精确时长}（13–25秒，按信息量选择；默认13–15秒约75%、15–20秒约15%、20–25秒约10%），9:16。原生480P视频，生成后转码为720×1280。前3秒必须出现强钩子：商品、人物或具体场景中的选择理由/冲突可见，并在后续兑现。{本片选定的连续讲述／同空间切镜／短途日常动线及各镜拍法}，按脚本写相机距离、人物与商品占比和需要看清的部位，不使用固定景别枚举。
主体清晰明亮，曝光适当，环境整洁，当前展示的商品部位完整可辨；首个画面与脚本开头的商品及看点相符，不另做商品广告图开场。

【人物与商品参考】
图片{实际编号}继承同一{东亚人种、按商品适合人群确定的具体年龄、完整外貌与可见特征}；人物提示词应写出脸部、眼睛、肤质、发型发色、妆容、服装配饰、表情、姿态、环境、光线、构图和真实摄影质感，不只写“东亚男生/女生”。图片{实际编号}只约束当前单品颜色、版型、图案和结构，不带入商品原模特、白底或棚拍光。仅列实际提交且需要的参考，不凑空号，不保留Mixed、node-asset或内部素材ID。手部或纯商品方案按原选择，不强加人脸。

【场景与道具】
{行动路线及实际空间}，图片{实际编号}负责{相应镜头的布局、光线与陈设}。{确有需要的道具、位置与使用方式，没有则省略}。人物身份跨地点一致，新场景不搬入原人物图的背景；每个场景按自身参考曝光和光向拍摄。
商品保持已人工确认素材与对应商品规格原图的色相、明度、饱和度及冷暖，场景光只产生合理局部明暗，主体采用中性白平衡与保留面料层次的曝光，不额外增艳或用氛围滤镜重染商品。

【情绪与表演】
{本片以对镜交流还是穿搭展示推进，以及整体交流状态；只有确有情绪转折时才写触发原因}。人物可以讲完一个意思再移开视线，顺手手势可与说话重叠，不每句低头、抬手、放手再微笑。衣物操作保留必要接触与结果，不逐个编排眨眼、呼吸或左右手轨迹。

人物可处于楼梯间、球场、通勤动线、工作室或电商拍摄现场等与商品相符的真实空间；只有当微动作有明确的信息或展示目的、且能在当前时间内自然完成时才加入（如走到机位后展示整体、整理衣摆后继续讲解）。没有这种需要时，人物自然说话、观察或保持当前状态即可，不为了制造生活感强行喝水、查看监视器、走动或添加动作清单。可佩戴位置合理的领口收音夹；保持同一具体年龄、外形和性格，避免换装换脸。用可观察的手势和情绪指令增强交流，但每个语义段最多一个主要手势和一次情绪变化，不循环点头、摊掌或微笑。

【时间轴与剪辑】
{起止秒数}｜{连续／明确切镜及切点}。{本镜地点及图片编号}，{拍摄者、固定／自拍／跟拍机位、相机距离与画面范围}。{起始状态→动作过程或切镜→结果状态；本段新增信息及必须同时可见的商品部位或搭配关系；一个主要动作或自然讲述状态，确有衣物操作时补必要接触与状态变化}。{中文声音来源}，台词：“{原文}”。
{按实际分镜继续，时间连续且总和精确，不均分秒数，不照抄样例时间码。同一连续镜头的后段继承前段手位与商品状态，只写变化，不重抄不变项和整套禁令，不为每段新增表情或收势。台词中的你看、这里、这一块对应同段可见部位及脚本已有的视线或必要展示动作，不擅自追加操作。保留口播原文的少量自然重复、短句和语气词。跨地点明确切镜，连续镜头内不变房间；匹配剪辑保持剪辑点身体位置，普通跳切可省去等待和重复整理，不要求先站正微笑再切镜。}
每段都必须有可观察的新事件、动作结果、商品状态变化、相机范围变化或明确切点；相邻段不能只换台词而保持同一姿势、同一构图和同一商品状态，不允许整条视频只靠同一张静帧做轻微嘴部或手部变化。

【声音与输出】
标准普通话，吐字清楚，人声音量稳定，无明显噪声、爆音、失真或忽大忽小；台词所指部位和动作与对应画面同步。
同一人物轻快的穿搭分享声线，短语连读，句内有轻重音与局部快慢，停顿随语义和动作变化，不逐字拖音。开头可承接正在进行的观察或动作自然开口，段间承接而非重新起腔或站定等一拍；全片统一留短换气与末句收势，不逐段重复留白，不把短台词拖满时间。末句完整说完，在既定时间内完成，不抢话、倍速或截断句尾。出镜说话段嘴部清楚可见，画内人物亲口说原文，中文发音、唇形、起止同步，停顿自然停嘴；画外音段画内人物不开口。同一段台词只写在对应时间范围，不另抄声音时间轴。环境声随当前地点和动作出现，不盖过人声。
视频生成阶段严禁新生成字幕、贴纸、价格条、参数文字、花字、箭头、线条、虚构品牌标志或其他可读文字；当前 SKU 原图中已有的商品标识、刺绣、图案和标签按自然比例与原位置保留，不得凭空新增、改写、删除或放大成广告牌。画面为后期信息层留出不遮挡嘴部与商品关键结构的安全区域。商品细节特写或独立空镜仅在脚本确有信息任务时出现，约3–4秒并有商品原图依据。
后期最后叠加逐句卖点字幕、关键词高亮、参数贴片和必要指向线，文字只来自已核实资料或已确认台词。默认加入一条可商用或客户提供的 BGM 后期音轨，压低到不盖过人声与环境声；客户明确不需要时关闭。交付说明同时写清原生生成分辨率 `480P`、时间线 `30fps`、目标输出 `720×1280`、原生文件、转码文件和转码完成状态；未完成转码时标为待转码，不把普通转码称为超分。
身份和当前单品全片一致，空间和光向在对应镜头内稳定；不冻结姿势、表情和每道褶皱。不添加无依据的卖点、背面展示、换装或运镜。

15秒连续讲述优先一个主机位、一至两个必要操作；生活切镜通常保留2至3个可完成的行动片段，数量不是硬指标。不默认正背正，不强求一天所有地点。整段一次生成，时间分镜不改成逐镜任务。编写教程、模板说明及未填写的占位不进入最终提示词。
