# 视频连续性核对

先记录目标秒数 T，再按叙事密度切分 [0,a]、[a,b]、[b,T]，镜头数量不固定。每段起点等于前一段终点，禁止重叠、遗漏或超出时长。

逐段字段：开始/结束 → 起始状态 → 主体动作与接触 → 镜头方向与速度 → 环境反馈 → 声音来源与准确台词 → 终止状态。

参考映射按真实附件顺序，身份、商品、构图、风格与声音各自负责什么要明确。首尾帧模式确认序号和顺序；一镜到底的地标、朝向和运动路径连续。

口播需留呼吸与停顿。时间码是制作计划，不是模型可逐帧执行的保证。无音轨时不能判断台词与音效，截图不能代替完整视频。

失败诊断按“参考冲突 → 动作密度 → 运镜冲突 → 空间/接触 → 台词容量”定位原因，每轮只改变一个主要变量。
