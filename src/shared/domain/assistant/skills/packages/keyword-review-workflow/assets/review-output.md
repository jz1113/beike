# 输出列与核对

默认在原数据右侧追加：最终垂类 | 是否制作。是否制作仅用“制作”“不制作”。保留 query 原文、原行序、空行规则与重复项。

用户明确要求完整审核时追加六列：最终垂类 | 是否制作 | 可做性状态 | 低价值关键词 | 强需生产方向 | 判定原因。
状态枚举与判断规则以 references/review-rules.md 为准；强需生产方向只给可制作泛实体，不适用填“-”。

检查：输出数据行数=源数据行数，逐行序号与 query 对齐，唯一垂类合法，制作枚举合法，批次无漏行，汇总与明细一致。
缺少实际写文件工具时输出按原顺序的结果数据，不用“已生成工作簿”描述仅有文本的结果。
