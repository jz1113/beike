# 关键词垂类与制作审核

## 输入与能力
读取真实表头、query、拓展词和行数。保留原列、原文、重复项与行序，不覆盖原“分类”。文档读取使用 `read_attached_document`；`execute_code` 是无文件系统的 JavaScript 沙箱，可整理已提取数据，不能据此声称已保存 xlsx。只有实际文件工具可用并成功返回时才报告工作簿完成；否则交付对应行序的结果数据并说明文件写回限制。

## 裁决流程
1. 先读 `references/review-rules.md`，采用其中唯一批准的中文垂类与排除规则。按语义主体判断，不能只匹配局部词根。
2. 判断明确意图、泛实体、限制过细、无优质参考源或禁止制作项，再决定制作/不制作。短词不自动判低价值；泛实体可做时结合拓展词给具体方向。
3. 宠物治疗/用药归医疗健康且不制作；普通品种与非医疗饲养归动物。玄学预测和姓名打分按低价值处理，普通梦境不自动套此规则。
4. 默认只追加“最终垂类”“是否制作”两列；用户明确要原因、低价值或方向时再追加相应列。明确要求完整六列时按 `assets/review-output.md` 输出，不擅自扩表。
5. 分批处理时记住起止行与已覆盖数量；长文按 offset/length 读取，不以首个片段代表整表。

## 验收与异常
逐行结果数等于源数据行数；序号与 query 逐字保持，唯一垂类和制作枚举合法，重复词不漏行，空 query 单独说明不猜测。汇总数量与逐行结果相等。未能读取的行不能填成已审核，歧义项依据批准规则说明原因；没有联网工具时不声称完成外部参考源核验。
