# 封面提示词撰写 v0.2.1

## 任务入口

- **组稿**。按下方流程处理单张商品或 Excel 行。画布提供候选版式和输出协议时，使用本次提供的规则。
- **仅预检**。按组稿流程核对输入和提示词，输出预检清单后结束。
- **成图质检**。已有成品时，按质检清单和商品图、版式样张对照。
- **版式入库**。用户明确要求收录或更新参考封面时，按文末入库规则处理。

## 组稿流程

### 1. 确认输入

使用商品图确认目标品类、可见面和实际部件。多款商品无法区分时，先确认目标。屏幕开孔、镜头、标识和配件以可见证据为准。省略无法证实的结构、规格、体验和营销信息。

Excel 批量读取 Sheet1，前两列提供标题和商品图链接，C 列确定生图画幅和裁切方式。逐行保留原始行号和标题。竖屏按 3:4 生图并输出 720×960。横屏生成并保存完整的 1:1 方图，标题及完整商品置于中央安全区，两侧延伸背景，为上传平台后的 3:4 居中裁切留出空间。

### 2. 选版并确定商品视角

画布已给出对应品类及可见面的版式时，使用该版式。用户指定版式时先核对素材能否落实。独立组稿时查阅 `references/phone-layouts.md`，按品类、可见面和标题空间选择兼容版式。有耳机、相机或平板专用版式时优先在同品类候选中匹配。跨品类适配只借用机位、背景及排字，保留实际商品结构。

手机每张封面只用正面或背面。多格版式也只用同一面及其局部。商品图若同时提供正反面，按以下顺序处理。

1. 两面清楚分离且能裁切时，优先使用选定一面的裁图。保留完整轮廓和关键部件，以实际送入模型的图片为准。
2. 仍使用双面原图且选定面清楚时，组稿明确原图中该面的方位和特征，只取这一面，并在预检中列为复核项。
3. 选定面受遮挡或关键结构无法识别时，要求补充该面素材，或改用有依据的视角和兼容版式。

### 3. 写构图与摄影

@图片1 提供商品外观。@图片2 提供版式，只迁移机位、主体位置、文字层级和环境关系。商品的结构、比例、颜色和标识以 @图片1 为准。样张文案、界面、账号、水印和无对应素材的包装配件省略。

从所选版式提取一到两项必须保留的特征，写入对应段落。横竖转换时先重排背景、留白和标题框，再调整主体占位。把成品画幅与手机摆放方向分别处理。

手持时写清指腹握侧框和手指实际承托的位置。正面从适合场景的生活感壁纸中随机选一种，例如街景、绿植、小动物、旅行摄影或手绘插画，并保持亮屏。壁纸贴合显示区与透视，保留实际边框和开孔。实际操作界面须有素材依据。背景段写材质与景深，光线段用一句交代主光、局部反光和暗部或接触影。

耳机与充电盒的结构以商品图为唯一依据，保持开闭、视角、左右朝向和收纳姿态。版式只借背景和标题，不能为了迁就机位重构耳机或仓体。原图是开盖双耳在仓内时，只画一只盒、左右各一只耳机，分别对应各自槽口。有耳柄时，耳柄底端按原图深度进入槽内，仓体前缘位于耳柄下段前方并自然遮挡；不能贴在仓体外壁、跨过槽沿或悬在槽口上方。耳机头与槽口贴合并有接触阴影，两个槽口独立，不能穿模、错槽或融合。无耳柄款式按原图贴合凹槽。原图未展示开盖入仓状态时，不推测内部、不强制开盖或添加耳机。指示灯和标识只按原图可见位置与形状保留。

### 4. 排标题

Excel 原标题保留在节点、导出明细和成品文件名中，作为上图文案的选题参考。封面文案可提炼改写，保留原意、关键型号和已有事实，不加无依据的参数、价格或宣传结论。明确指定的上图文案逐字照录，只调整断行。副标题补充同一主题。

逐行给出实际上图的文字、相对字高、位置、字形和必要的颜色、描边或投影。强调色只用于上图文案的完整词或版式允许的标点。长标题先按语义断行，尽量保持型号、英文词组与数字单位完整，再调字号、字距和行距。以缩略图可读、标题不遮挡商品关键部位为准。仍放不下时，在本次允许的候选中改用标题空间更宽的版式。版式已指定或锁定时，说明冲突并请求确认换版。

## 输出协议

- **画布组稿**。只返回画布指定的 JSON 对象，使用既有字段。画布将其组装成固定七段。阻塞原因使用现有 `error` 字段。预检备注单独交付。
- **独立组稿**。给出上图标题、版式编号和七段绘图提示词。仅用户明确要求无字底图时留空标题。

七段顺序为「画幅与构图」「背景」「商品外观」「标题与排版」「字体与视觉风格」「光线和画质」「保真约束」。

## 生图前预检

逐行对照商品图、版式和最终提示词。确认版式匹配、必保项已写清，构图、商品外观和保真约束指向同一可见面，改写的封面文案保留原题核心信息，明确指定的上图文字逐字一致，尺寸符合要求。

- **需复核**。目标面清楚但仍使用双面原图，或标题接近安全边距。指出具体风险。
- **需修正**。缺少指定面、版式必保项无法实现、明确指定的上图文字被改动、改写偏离主题或画幅无效。修正后再提交。

用户只要求预检时，单独交付 Excel 行号、版式编号、可见面、逐行标题、成品尺寸和待确认原因。等用户明确开始生图。只报告实际完成的裁图、校验或模型提交。

## 成图质检与交付

并列核对成品、商品图和版式样张，确认标题与实际上图文案一致，并检查字形、商品结构与标识、单机单面、握持与光线、版式和画面完整性。记录通过或具体偏差。单张画布成品通过质检后进入下载。Excel 批量成品保存后即可打包下载。

耳机成图先放大检查槽口。耳柄贴在仓体外壁、跨过槽沿、悬在槽口上方、错槽、穿模、与槽口融合或入槽深度与原图不符时，标记未通过；原图未展示的结构不可当作合格依据。

批量按 Excel 标题命名，按 C 列保存竖屏 720×960 或完整的 1:1 方图，明细记录实际版式。原文件名从上传元数据读取。

## 版式入库

查阅 `references/phone-reference-prompts.md` 确认原图映射。按实际可见的构图、标题位置、字形和光线记录版式，区分必须保留的特征与可替换内容。不同参考图各用独立编号，重复图复用原编号，新增时保留已有编号。更新 `references/phone-layouts.md` 后同步技能包编译产物。
