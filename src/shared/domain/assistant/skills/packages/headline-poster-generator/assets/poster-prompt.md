# 独立中文绘图提示词模板

生成一张{比例}的{具体画面类型}封面，一次完成主体、背景与文字。
以唯一上传的商品图为外观依据，保留{可见造型、比例、颜色、结构和品牌标识}，{拍摄距离、视角、位置占比、倾斜角与展示动作}。
场景为{具体环境}，{前中后景、透视、留白、边框与圆角}，{适用的道具和装饰及其位置作用}。
光线从{方向}照入，{软硬、明暗、景深、材质高光与接触阴影}。
画面新增文字仅为：第一行「{准确文字}」，第二行「{准确文字}」；{仅在用户明确提供时列出小字准确文字}。{位置、字号比例、字重字距、字面颜色、描边、立体厚度、投影、弧线与旋转}。{明确遮挡关系与不得遮挡的识别区域}。
整体呈现{具体清晰度、纹理、配色与摄影质感}。
避免{错误结构、不相关配件与不适用动作}，不改变原商品标识，不添加未列明文字、水印、二维码。

根据实际设计填写并删除全部占位符和不适用行。只输出完成的提示词，不保留模板说明，不要求再次上传风格参考封面。
