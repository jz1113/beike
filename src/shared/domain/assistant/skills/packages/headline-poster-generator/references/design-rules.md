# 七栏设计记录

1. 构图：比例、主体位置占比、倾角、透视、留白、前后景、边框与圆角，明确文字遮挡边界。
2. 字体：层级、字号比例、字重、行次字距、立体厚度、投影、弧线旋转。按选定样张写具体参数或相对关系。
3. 字色：字面、描边、衬底与背景明暗，保证缩略图可读。
4. 背景：环境、材质层次、光向、软硬与景深，不机械限制材质数量。
5. 主体：外观依据、摄影距离视角、展示动作、品牌型号及识别保护区。区分可见外观和用户提供卖点。
6. 搭配：颜色实际分工，不改变产品本色以迁就样张，不强制三色。
7. 排重：新主体适配原因，可保持系列一致；不为了差异破坏参考样张。

图上文字只用于视觉分析，样张原品牌与文案不迁移。最终提示词不包含内部记录编号、上一张差异或反推过程。
