# 封面七栏设计单

1. 构图：记录主体居中、目标占高和标题咬合边，识别点留出保护区。
2. 字体：超粗黑体为常用方向；指定行数、字距与一项必要修饰，不叠加所有字效。
3. 字色：标题与落点背景有明确明度对比，描边或衬底按需选择。
4. 背景：单一材质、明确光向、接触阴影；标题背后保持干净。
5. 主体：商品轮廓、比例、颜色、品牌与型号跟随权威原图。
6. 搭配：商品色、标题色、背景色分工，不强改商品真实色来满足配色。
7. 排重：批量时写明与上一张的主要差异，无历史样本则说明这是首张。

标题计数：默认 7–12 汉字，不含标点。用户坚持型号或英文时单列混合字符数量并保留原文。具体体验结论须有依据，不把卖点想象当实测。
