# 大字报商品封面

## 输入与边界
至少有可见商品图；标题优先采用用户原文，其次文件名。文件名无语义时提炼可见商品事实，不虚构效果、销量或使用体验。只做提示词时不触发生图；动态带货另用视频流程。

## 执行流程
1. 锁定当前商品与 SKU。链接需解析时调用 `parse_product_or_social_url`，多张同款图明确权威外观来源。
2. 将原标题改成 7–12 个汉字的具体结论或场景标题。品牌型号等用户要求保留的字符单独说明计数；不得为凑字编造事实。标题过长先删空词，不删核心对象。
3. 阅读 `references/design-rules.md`，填写七栏：构图、字体、字色、背景、主体、搭配、排重。按商品外形确定层级，批量时记录每张的主要差异。
4. 使用 `assets/poster-prompt.md` 写独立 `image-prompt`；商品、背景与标题一次生成，默认 3:4。
5. 只有用户要准备生成才调用 `trigger_generate`。批量已有清单且获明确指令才用 `trigger_generate_batch`，保持来源编号。

## 视觉约束
商品水平居中，目标中心偏差不超过画面宽 5%，目标占高 62%–74%；非实测结果明确这是设计目标。标题至少一行与商品上沿形成咬合，但不得遮挡关键识别点。以商品、标题、背景三组主色协调，保留商品本身真实色彩。
品牌、型号、丝印、按键与几何依原图。标题避免“神器、必入、绝绝子、yyds”等空话；不额外添加价格、二维码、水印或装饰文字。

## 验收与失败处理
交付原标题 → 新标题及字数、七栏设计单、完整提示词。核对文案事实、逐字标题、图序、主体识别点和字底对比。缺图时可先给标题草案并标记待补图；生成错字时优先修正文案或局部文字，不能冒充已完成封面。
