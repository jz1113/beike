# 九维观察与复刻建议

每维优先记录可见事实，不足之处明确为推断。相机型号、精确焦距、色温、年龄与光比不能仅凭一张画面确定；仅在有 EXIF 或测量时报告实测，否则用“建议/近似”标注。

1. 主体：数量、朝向、姿态、可见五官/结构/衣物和标识。不要根据外貌推断真实族裔或精确年龄。
2. 媒介：摄影、插画、渲染、拼贴的可见特征；不任意附会器材或艺术家。
3. 光影：主光方向、软硬、接触阴影、反射与暗部范围；用画面依据支持判断。
4. 色彩：主色、辅助色、强调色与冷暖关系。没有取样工具时不虚构精确色值。
5. 材质：可见纹理、反射粗糙度、透光与边缘高光，避免“高级质感”等空话。
6. 机位：俯仰、透视和景别；焦段用可执行复刻建议表述。
7. 构图：主体位置、留白方向、前后景、遮挡和清晰范围；比例可作近似估计。
8. 氛围：真实可见的风、雾、水汽、微小动态；没有就不强加。
9. 输出：用户画幅与模型兼容限制，商品形状和文字保留项。比例参数按执行平台填写。

分析与最终提示词分开。提示词可以提出具体拍摄设定以指导生成，但这些数字不代表原图真实参数。
