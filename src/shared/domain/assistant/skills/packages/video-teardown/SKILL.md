# 短视频拆解与复刻

## 输入与观察范围
需要真实可访问的视频附件或地址。只有截图时可以分析截图构图，不能据此断言视频时长、剪辑、对白或声音。仅转写或转码不需要完整拆解。

## 工具流程
1. `inspect_video_media` 获取时长、尺寸、帧率、轨道等真实规格，先核实访问成功。
2. `extract_video_storyboard` 全片抽样，自己查看返回画面并标记镜头语义，不把抽样帧数当镜头总数。
3. 对开头、切点、细节或换装处调用 `extract_video_detailed_frames`，参数根据已知秒数限定；遵守单轮视觉预算，优先关键证据。
4. 阅读 `references/analysis.md`，区分测量、观察与推断。缺少可听音轨时，不写成已试听；原片品牌、字幕与卖点也不自动成为新商品事实。
5. 用 `assets/report-template.md` 输出带时间范围的镜头报告，再规划人物/手部、纯场景与道具锚定素材，以及完整 `video-prompt`。

## 复刻约定
每个结论能指回具体时间或帧；抽样无法确定的切点给范围。光位与焦段可给复刻建议，不能冒充实测拍摄参数。锚定描述跨镜头保持一致，只在时间线更换动作和运镜。需静态素材时先提供 `image-prompt`，视频最终稿以真实素材为依据。

## 输出与失败处理
交付真实规格、观察范围、镜头拆解、复刻方法、生成提示词与待核对项。读不到视频时报告工具错误和可用范围，可继续基于截图做局部分析；不编造音频测量、色值、精确切点或“实拍/AI”确定结论。
