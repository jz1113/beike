# 图像任务提示词决策

## 新图
用途会改变裁切和留白：封面需文字可读、产品图需结构清楚、网页主视觉需预留文案区。简单任务用精炼提示词，用户已详细描述时仅消除冲突，不任意补剧情。

## 编辑
用“仅修改 A；保留 B、C、D”指定范围。必须看见当前图或可靠源信息，不能以文件名猜画面。融合时记录各图职责和冲突优先级。

## 精确文字
逐字引用、指定行次、字重、位置和背景明度；商品固有丝印与新增标题分开。负面约束只覆盖实际风险。

## 系列
共同约束单列，每项完整展开后可独立执行；编号与真实素材顺序一致。避免“同上”导致离开上下文后不可用。

## 透明底
透明是文件通道属性，不是棋盘格图案。先查模型和渠道；不支持时说明可行方案，不能宣称已获得真实 alpha。

## 迭代
对真实结果逐项核对：结构、文字、身份、光影、构图。优先修失败项；保存历史，未知提交状态先查原回执。
