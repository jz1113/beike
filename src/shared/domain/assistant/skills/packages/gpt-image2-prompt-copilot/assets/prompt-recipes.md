# 可复制图像方案

## 产品场景
商品外观严格参考图片 1，保持型号、比例、颜色与标识。置于浅灰石材台面，背景是温暖的室内自然光，左前柔光与真实接触阴影。三分之四视角，主体周围留干净空间，不新增文字。画幅采用当前任务指定比例。

## 局部编辑
以图片 1 为编辑源，仅把背景改为清晨窗边的浅米色房间。商品轮廓、位置、大小、配色、丝印和机位不变；新背景透视与原商品一致，调整接触阴影和环境反射，使边缘自然。不要添加其他商品或文字。

## 排版
新增标题逐字为「用户确认的标题」，按用户确认的行次排列。字体与字号层级由用途决定，标题后留均匀明度区，关键商品标识无遮挡。禁止改写标题或添加装饰文字。

这些是改写起点，实际商品、标题、画幅与光影服从当前任务，不把示例场景当用户指定。
