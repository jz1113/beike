# Model prompting guides

Every video model has habits: some reward long cinematic descriptions, some prefer short prompts, some are best at image-to-video, some generate sound. These guides cover what each model is good at, how to prompt it, and three example prompts.

Model versions change often. The guides stick to general, durable advice; check each model's page for current durations, resolutions and aspect ratios. In Vivideo, the options for a model appear when you pick it in [manual mode](https://vivideo.ai/features/manual-mode).
