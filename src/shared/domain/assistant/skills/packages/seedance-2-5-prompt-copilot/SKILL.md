# Seedance 2.5 视频提示词

## 输入与分流
核对目标时长、画幅、所选模型与参考顺序。仅在缺失信息改变结果时集中询问；纯提示词可注明合理创作假设，提交参数必须符合实际渠道能力。不要从技能名称推断特定渠道必然支持的时长、分辨率或音频参数。
- 多参考：给每个素材唯一职责，依次明确身份/商品、场景、动作、镜头与声音。
- 首尾帧：锁定起始与终止图的有序索引，描述能到达终态的中间路径。
- 一镜到底：保持可通行的空间路线、连续视点与可完成的动作密度。

## 执行步骤
1. 简报目标与不可变化项：人数、身份、商品几何、台词、场景关系。
2. 阅读 `references/timeline.md`，写从 0 到目标秒数无空隙、无重叠的时间段。每段有起态 → 动作与接触 → 环境反馈 → 终态，接续下一段。
3. 为镜头运动给方向、速度与叙事目的，避免短时间叠加冲突的旋转、推拉和变焦。
4. 对白逐字引用，区分画内讲话、画外音、环境声和配乐；用户要求无配乐时在全局和收尾均保持。
5. 参考 `assets/video-prompt.md` 输出一条完整 `video-prompt`；除用户明确要求拆片，分镜属于同一条视频时间轴。

## 工具与状态
视频素材检查可用 `inspect_video_media`；需要画面证据再抽故事板或局部帧。核对当前能力用 `get_view_capabilities`。提交已有生成清单用 `trigger_generate_batch`；无清单不编造 sourceId，先交付提示词。回执只代表请求或任务状态，不能证明视频或口型质量。

## 验收与诊断
时间线合计等于目标时长，参考编号与真实附件匹配，首末状态相接，声音来源明确。漂移先减少动作或冲突参考；穿帮先修空间与接触；口型问题先核对台词时长与嘴部可见性。给出一个主要修复变量并保留已有成功结果。
