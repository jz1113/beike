# 参考视频拆解

为拍摄者写一张可以逐行照着拍、对着剪的中文分镜表。先看完整片，再按播放顺序还原。每一行要回答三个问题：这段在什么时候，画面里发生了什么，摄影机从哪里、用什么景别、怎样拍。

## 划镜和计时
- 每次真实切镜才另起一个 shot。连续拍摄时，人物转身、起跳、落地等主要动作明显变化，可以在同一镜内分 beat；小幅摆动不按采样帧逐个拆行。用 start、end 写源片起止秒数，时长由系统计算。
- 地点、造型或叙事阶段变化时填写 sectionLabel，同一段沿用同一名称，如“棚内 · 黑裙造型”。单场景、一套服装无需硬分段。空镜、片尾卡也按实际出现的位置记录。
- 采样画面只能确定大致边界时标 estimated。对音轨、遮挡、切点的具体疑点集中放进 review，避免逐行重复“无法判断”。没有音轨证据时不编台词、音乐或音效。

## 写给主表的字段
- referenceActionRaw 是读者直接看到的“画面与动作”。每段用一到两句自然的中文，写清主体、起始姿势、主要动作和结束状态；只写画面支持的细节。人物朝哪边转、手碰了哪里、是否停顿，要能对上这一段。把“开场律动”写成诸如“舞者侧身站立，抬手碰帽檐，随后转回正面”的具体观察；这个例子只说明写法，不套入实际视频。空镜写入画的物件、光影或构图变化。
- shows 用一句话概括同一动作。subject 记录需要同框的人与物；scene 记录场景、造型及光线；expression 只写可辨的视线或表情。稳定信息用一致的措辞，使表格能在全片交代一次。不要每行重新介绍衣服和背景。
- cameraLabel 是“镜头方式”，用短语交代景别、拍摄角度、固定或运动，如“全身景 · 低机位仰拍 · 固定”。shotSize 写中文景别；camera 写可见的机位、构图及运动方向。区分前置自拍、镜中自拍、旁观机位与画内设备。人物靠近固定机位不写成相机推进。
- voice.text 只记听清的台词；subtitle 只记确实读出的屏幕文字。持续显示的同一字幕逐段保持原文，文字消失后留空。transition 只记实际可见的接法或有意义的动作衔接，没有就留空，不输出“none”。
- overview 用一两句交代场景、主体和动作走向。visualSpec.styleSummary 与 lighting 描述全片用光、质感和节奏。每镜的 analysis 保留 style、subject、action、camera、expression 五项观察；actionTemplate 单独保存可复用动作，商品真正参与画面才写商品占位符。
