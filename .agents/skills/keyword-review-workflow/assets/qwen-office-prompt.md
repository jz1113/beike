任务：逐行审核关键词、划分垂类、判断是否制作，并补充审核结论。

保留原表全部行、重复记录、顺序和以下九列原始值：

`序号 | query | 相关拓展q | 笔记内容类型 | 实体拓展q | 分类 | 需上传数量 | 已上传数量 | 下发时间`

`最终垂类 | 是否制作 | 可做性状态 | 低价值关键词 | 强需生产方向 | 判定原因`

最终垂类只允许：

`政史军、3C数码、本地生活、动漫、动物、法律、购物消费、互联网IT、家居、交通出行、教育、金融财经、科学技术、旅游、美食、美术、民俗文化、其他、汽车、情感、求职招聘、软件工具、社会、时尚、体育、小说、星座、医疗健康、音乐、影视、游戏、娱乐、政策政务、植物`

请以 query 的真实意图为主，相关拓展q、实体拓展q和笔记内容类型只用于补充理解。不得机械沿用原分类，也不得让拓展q中的噪声覆盖清晰的 query。

判定规则：

1. 金融财经、医疗健康、敏感社会热点不制作。
2. 狗猫等宠物的疾病、健康、用药、疫苗、治疗归医疗健康并不制作；习性、品种、训练、普通喂养和用品归动物。
3. 违法违规、危险反常识、色情暴恐毒品、迷信玄学、工业硬广和非图文笔记需求不制作。
4. 情感咨询、关系抉择、社交话术、取名打分、人情随礼、红包金额、生肖运势、财运和幸运颜色等标记低价值并不制作。
5. 单纯个人梦境描述允许制作，不标记低价值；星座知识可以制作，个人运势预测不制作。
6. 版权、游戏攻略、院校、旅游和企业评价正常进入可做性判断。
7. 答案为唯一事实、固定数字、身份、日期、时间、距离、价格、尺寸、颜色或规格，且没有有效展开空间时，标记简单问答并不制作。
8. 多重尺寸、数量、年限、颜色、型号和复杂地域条件堆叠，导致内容过窄时，标记限制过细并不制作，不改写 query。
9. query 是可制作的泛实体词但没有方向时，保留 query 原文，从拓展q中选一个强需方向；其他情况填 `-`。
10. 使用完整语义消歧，例如：乌天狗归民俗文化、游戏手机推荐归3C数码、教师法归法律。

字段限制：

- 是否制作：仅 `制作` 或 `不制作`
- 可做性状态：仅 `可做 / 简单问答 / 低价值 / 红线否决 / 非笔记需求 / 限制过细 / 不可产`
- 低价值关键词：仅 `是` 或 `否`
- 判定原因：40字以内
