# WorkBuddy 专用提示词

请在 WorkBuddy 的表格处理能力中直接编辑我上传的 Excel 文件，完成全部关键词审核，并返回可下载的 `.xlsx` 文件。不要只回复处理思路、前几行示例或 Markdown 表格。

原表前九列必须原样保留：

`序号 | query | 相关拓展q | 笔记内容类型 | 实体拓展q | 分类 | 需上传数量 | 已上传数量 | 下发时间`

在右侧新增：

`最终垂类 | 是否制作 | 可做性状态 | 低价值关键词 | 强需生产方向 | 判定原因`

逐行以 query 为主、拓展q为辅进行语义判断。不得修改原分类、原 query、原数据、重复行和行顺序。

允许垂类：`政史军、3C数码、本地生活、动漫、动物、法律、购物消费、互联网IT、家居、交通出行、教育、金融财经、科学技术、旅游、美食、美术、民俗文化、其他、汽车、情感、求职招聘、软件工具、社会、时尚、体育、小说、星座、医疗健康、音乐、影视、游戏、娱乐、政策政务、植物`。

审核规则：

- 宠物疾病、健康、治疗、用药归医疗健康，与人的医疗内容一样不制作；普通宠物习性、训练、品种、非医疗喂养归动物。
- 金融财经、医疗健康、敏感社会热点不制作；普通社会知识可以制作。
- 违法危险、迷信玄学、工业硬广、在线观看或下载资源等非笔记需求不制作。
- 情感咨询、关系抉择、社交话术、取名打分、人情随礼、红包金额和迷信运势标记低价值并不制作。
- 单纯个人梦境描述可以制作；星座科普可以制作，但个人运势、财运、幸运颜色等预测不制作。
- 版权、游戏攻略、院校、旅游、企业评价不因主题本身被拦截。
- 唯一事实或固定数字且无法展开的 query 标记简单问答，不制作。
- 限定条件过多、内容空间极窄的 query 标记限制过细，不制作，不改写 query。
- 无方向的可制作泛实体词，保留 query 原文，结合拓展q填写一个强需生产方向；其他行填 `-`。
- 必须按完整语义分类，不能只按单字匹配。例如乌天狗归民俗文化、游戏手机归3C数码、教师法归法律。

字段值限制：

- 是否制作：`制作 / 不制作`
- 可做性状态：`可做 / 简单问答 / 低价值 / 红线否决 / 非笔记需求 / 限制过细 / 不可产`
- 低价值关键词：`是 / 否`
- 判定原因：不超过40字

若数据量较大，请内部按连续行分批处理并自动合并。最终必须交付一份完整 Excel；不得遗漏行、去重、改变顺序或只返回部分结果。
