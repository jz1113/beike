# 大字报商品封面生成

## 输入与交付

- 输入列默认识别：商品图片链接（`封面链接`、`图片链接`、`商品图`、`url`）与标题（`标题`、`修改后标题`、`文案`）。没有表头时，第一列按图片链接、第二列按标题处理。
- 每一行保留 `原始标题` 作为最终图片文件名；为了文件系统兼容，只替换 `\\ / : * ? " < > |` 等非法字符。
- 默认输出一张 `3:4` 竖版 JPG。批量交付时将所有成功图片打成 ZIP，不额外改写原始文件名。

## 固定工作流

1. 校验图片链接和标题，空值或非 HTTP(S) 链接标记为失败，不阻塞其它行。
2. 用图片生成模型，以原商品图为参考生成白底商品图：纯白背景、完整商品、无手无人、无新增海报文字；商品结构、颜色、真实品牌标识、型号、面板丝印和按键必须与参考图一致。商品本体原有的文字不得擦除、模糊、马赛克、遮盖或改写。
3. 用多模态「封面设计导演」同时判断标题与版式：根据商品图和原始标题输出 7–12 个中文字符的标题、构图关系、商品取色、背景材质、字体表达与装饰语法。保留事实，不杜撰参数、价格、功效或品牌背书；不要调用小红书种草文案模型来代替封面判断。
4. 用白底商品图执行本地分层合成：先按白底边缘抠出商品主体，再生成对应的纸感/对角/深底/studio/网格/拼贴结构背景，最后叠加真实商品、接触阴影与标题。禁止把白底商品再次交给图片模型重画，因为这会抹掉商品 Logo、型号和面板丝印。
5. 用系统可用的超粗中文字体在本地合成底图上排主标题。默认只排主标题，2 行优先、必要时 3 行；白/黄/近黑三色按背景对比选择。每张必须使用一种明确字组关系（错位、压图、局部色块或短下划线），不使用居中等宽的固定白描边模板。
7. 展示每条记录的白底图、优化标题、提示词、成品和失败原因。成品完成后可单张下载，或批量打包。

## 视觉架构：先生成设计方案，再写提示词

参考封面并非同一种「大字 + 商品」模板；稳定的共同点是标题、商品和背景三层有明确主次。下列系统是可组合的设计语法，不是按品类硬套的模板。同类商品也应根据标题的情绪、产品颜色、材质与批次中的重复情况，生成不同构图与字效；同一张只使用一套自洽的视觉语法：

| 适用商品/内容 | 风格族 | 背景配方 | 标题处理 |
| --- | --- | --- | --- |
| 美妆、穿搭、食品、轻生活 | 纸感编辑大字报 | D1 米白纸纹 + 极细网格 + 商品色纸片 | 近黑超粗字，左上两行错位，最多一处柔和高亮 |
| 反差、结论、性价比话题 | 对角几何结论款 | D2 商品取色的 6:4 对角色面 | 近黑超粗字，右上或左上，两行错位 + 一条同源短下划线 |
| 手机、相机、电脑、强品牌数码 | 深底品牌氛围款 | D3 近黑/品牌色哑光底 + 低透明巨型抽象背景字 | 暖白或黄色描边字，压底或压产品，最多一个黑色语义块 |
| 高端小家电、设计感器材 | 清透杂志陈列款 | D4 有方向的柔光 studio + 巨型低对比背景字 | 近黑标题，中部偏左压产品，单个角标/括号装饰 |
| 耳机、手表、配件、键盘 | 浅冷器材测评款 | D5 浅冷几何 + 品牌色细线 | 近黑标题，顶边错位，一条细线 + 圆点系统 |
| 洗护、清洁、家居、生活电器 | 生活场景纸感款 | D6 纸感留白 + 木桌/石台/织物等真实材质带 | 近黑标题压顶并咬合商品，最多一条商品色荧光笔划 |

无论选择哪个系统，都必须满足：商品水平居中（中心偏差不超过画面宽度 5%）、占画面高度 62%–74%、标题至少一行压住商品上沿或紧贴其顶部。避免「上半标题、下半商品、彼此分离」的电商详情页构图。

### 每条必有的设计方案

先输出或保留以下六项，再写生图提示词：

1. **内容判断**：原标题被压缩成什么具体结论，不能只是替换同义词。
2. **构图关系**：例如压顶错位、对角切面、下压主视觉、杂志侧压、顶边器材；描述标题与商品如何压叠，而不是只写“左上标题”。
3. **商品取色**：从商品主体或原图提取一个强调色，配低饱和同源色和中性色，总色数不超过三色；禁止默认套紫蓝、粉蓝或彩虹配色。
4. **背景材质**：只选一种明确材料或结构，例如纸纤维、石材、磨砂金属、织物、双色拼贴或哑光色面，并写明光向与接触阴影。
5. **字体表达**：在编辑粗黑、斜切描边、黑块黄字、杂志印章、冷调测评、荧光笔刷等语法中选择一个；字体、描边、倾斜、强调线必须统一。
6. **排重理由**：同一批内避免相同构图、相同字效、相同背景材料连续出现；优先由设计导演改变构图关系与标题语法，再改变颜色。静态默认方案只允许在导演不可用时降级。

```text

主题：{优化标题}，仅用于理解内容，不能生成在画面里。
参考图：@图片1 是白底商品，@图片2 是原始商品图；以两张图锁定商品外形、比例、颜色、材质、真实标识、型号、面板丝印和按键。商品本体已有的文字与标识必须保留原位，禁止擦除、模糊、遮挡、重写、替换型号或重画成电商渲染。
```

提示词必须包含「参考锁定、风格族、背景结构、三色来源、商品位置与比例、标题落点、光影材质、禁忌」八部分。只写“高级、干净、柔和渐变、产品居中”视为无效提示词。

## 本地字体与排版

- 主标题控制在 8–12 个汉字，优先 2 行、每行 4–6 字；字太长时先压缩信息而不是缩小字号或添加副标题。
- 使用免费商用的思源黑体 Black、得意黑、未来荧黑等超粗字体；不要依赖系统苹方或普通字重。字体文件未随客户端加载时，必须显式检测并降级，不能假定浏览器有某种字体。
- 两行标题宽度应吃满画面 84%–94%，行距为字高的 1.05–1.15 倍，字距收紧而非拉开。
- 每张在「两行错位、字压商品、局部语义色块、短下划线 + 圆点、角标细线」中只选一套；颜色只用白/近黑加一个商品来源的强调色。
- 深底可用暖白或黄字 + 3%–5% 黑描边；浅底使用近黑字并只加很轻的投影/白描边。禁止彩虹字、厚重多层描边、全屏发光和整行渐变字。

## 质量门槛

- 商品不能被缩成角落配图，不能被替换为其它款式，不能出现额外商品。
- 商品必须居中放大到画面高度 62%–74%，标题与商品有压叠关系；只有“标题在上、商品在下”的分区构图应重跑。
- 标题字数控制在 8–12 字，含义必须由原始标题或商品图支持；不能使用“实拍体验、使用体验、很不错”等空泛收尾。
- 每张图只使用一套标题和装饰语法，并且背景要有纸纹、色块分割、巨型背景字、细网格或真实材质带等明确结构；避免玻璃拟态、紫蓝霓虹、无意义 HUD、满屏高饱和元素和堆叠贴纸。
- 中文文字由本地排版完成；背景文字和装饰不再由图片模型临场生成。商品只经过一次保真白底生成，后续用本地抠图和分层合成，避免二次重绘造成标识丢失。
- 单条失败不应终止全批；失败记录保留原图、原始标题与错误信息，支持仅重试失败项。

## 界面原则

- 先导入、再预览清单、最后执行批量任务；不要要求用户逐条配置。
- 把「白底图 → 标题 → 提示词 → 封面」进度显式展示；用户可在开始前修改封面标题，并在任务完成后检查提示词。
- 导出按钮只在存在成功成品时可用，并明确显示使用原始标题命名。
