# 服饰带货视频

## 适用范围

为一件服饰、鞋或包编写连贯的带货方案。分镜安排同一条视频的时间轴，成片使用一条完整提示词，一次出片。

本技能仅用于服饰鞋包。其他品类使用工作室的通用自动创作流程，不套用换装、面料飘动等服饰叙事。

## 输入与事实依据

- 必填：商品名称、可核实资料、当前 SKU 颜色和至少一张已确认属于该颜色的清晰商品图、目标时长与画幅。
- 可选：品牌、价格、已知卖点。商品链接是资料来源，商品图可以采集或手动补充。
- 人物、人脸、场景无需人工上传，依据脚本自动规划和生成；旧项目已有素材可以保留，但不能跳过有效性校验。
- 原始商品属性是事实依据，创作卖点是模型提炼结果，两者分开。没有依据的功效、评价、销量、实测、优惠、尺码或链接不编造。
- 规格图分类不代表属于当前颜色。未知、冲突或多色图不得静默作为单品外观参考；证据不足时先明确确认。

## 执行流程

1. **确认商品**：锁定当前 SKU 颜色和允许使用的商品图，完整图库另行保留。
2. **设置创作参数**：确认目标秒数、画幅与多模态模型。此阶段无需选择视频模型。
3. **分析与脚本**：提炼可证实卖点，编写口播和连续分镜。各段起止连续、无重叠或空档，分段时长加总等于目标时长。口播约每秒 3–4 个字，为动作与停顿留时间。
4. **规划素材**：根据脚本规划必要的人物、场景和关键静帧及其绘图提示词，不强制凑齐三种图片；人脸特写只有明确需要时生成，必须依赖同一人物。
5. **自动生图并校验**：使用所选绘图模型。商品上身或手持画面带入当前 SKU 商品图；场景依脚本生成。每张图完成即保存；部分失败只补缺失项，提交未知先核对原任务。校验颜色、版型、图案、人物身份和脚本一致性，冲突或无法判断时阻止直接提交。
6. **选择视频模型**：素材完成后验证实际参考图数量、目标时长、画幅、清晰度和原生口播能力。不兼容时明确提示调整，不静默改秒数、丢图或拆段拼接。
7. **实际图片定稿**：多模态模型查看真实生成图片后，依据最终提交顺序编写一条完整视频提示词及对应分段说明。此时才固定“图片1、图片2……”的编号，不引用尚未生成或空地址图片。
8. **一次出片**：明确授权后提交一次整段视频任务。保存回执；已有回执先查询，不因刷新或配置变化重复计费。

## 叙事选择

只选择适合当前商品的一种叙事，不机械套示例：

- **开箱换装（unbox）**：适合上衣、裤、裙、外套。先抽出并展示单品，中段保持身体位置匹配剪辑到已穿上，后段连续转身或姿势展示。
- **生活穿搭（lifestyle）**：已穿着单品，在同一空间改变站位、整理衣服或走动，采用中景、全景和自然手持感。
- **鞋包展示（accessory）**：拿出、上手或上脚并展示结构和细节，不写换装或面料飘动。

## 素材与参考规则

- 商品原图作为外观依据，不修改采集原图；生成画面中的单品仍须符合当前颜色、版型、图案或鞋包结构。
- 人物生成设定明确成年外观、穿搭和姿态；上身图使用商品参考，不能仅凭文字生成相似款。
- 人脸特写从已经生成的人物派生，不单独随机生成另一张脸。
- 场景遵循脚本中的真实空间、光线和构图；不同静帧共享必要的身份与空间约束。
- 静帧都是实拍照片风格：真实皮肤、空间、自然光和比例，不使用插画、动漫、塑料皮肤或棚拍假人。
- 静帧不写口播、运镜时间轴、字幕、价格或拼图文字。
- 视频参考编号对应实际提交数组位置，不是商品图目录的 `imageIndex`；编号连续、用途明确，不预留空号。
- 所选模型不支持必需的多张参考图时明确说明限制，不能擅自丢弃商品或人物参考。

## 输出与阶段区分

脚本阶段交付：商品分析、选定叙事、口播、分镜时间轴和素材生成计划；这不是最终视频提示词。

素材阶段交付：实际图片、来源与用途、生成和校验状态。未实际生成时不能声称已得到图片。

视频定稿阶段交付：一条可整体复制的中文 `fullPrompt`，以及按原 `shotId` 对应的分段 `prompts`。人物、场景绘图提示词属于前面的素材规划，不再由最终视频定稿反向提供。

完整视频提示词依次写：**场景 → 实际参考用途 → 按秒时间轴 → 灯光 → 色彩 → 当前输出参数 → 一致性锁定**。

锁定人物外貌、单品颜色/款式、光向和动作连续性；明确口播与嘴型要求。画面无字幕、贴纸、大字标题或价格条，发布文案与画面叠字区分处理。

## 费用与恢复

- 仅请求分析或提示词时不擅自调用付费图片/视频生成。
- 单项重生成会产生费用，依赖该图的素材可能也需更新，操作前明确说明。
- 已成功且输入未变化的图片复用；已有任务回执先查询。提交结果未确认时禁止自动重复提交。
- 改颜色、商品事实或时长后检查下游失效；改变实际图片或参考顺序后重新定稿。保留历史结果，但不把过期结果当作当前有效输出。

## 交付自检

- 当前商品颜色和素材有明确依据；无法确认的内容已标明。
- 口播仅使用可核实事实，时间轴合计等于目标秒数。
- 按脚本自动规划图片，人脸与人物一致，商品外观有参考约束。
- 最终提示词在实际图片完成并校验后产生，编号与提交顺序一致。
- 视频模型能力已检查；不支持的配置显式阻断，不改成逐镜拼接。
- 只在拿到真实图片、任务回执或成片后报告对应完成状态。
