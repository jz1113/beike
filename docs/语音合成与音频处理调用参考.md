# 语音合成与音频处理调用参考指南

本文档全面梳理当前主流语音合成（TTS）、音频转写（STT）模型（OpenAI Audio、MiniMax Speech、阿里百炼 CosyVoice 等）的官方调用规范、gpt-best 聚合网关对接方式、二者核心差异以及在贝壳云图系统中的集成映射。

---

## 1. 适用模型目录

| 模型 ID | 厂商 | 类型 | 音色/语言支持 | 典型延迟 | 推荐场景 |
| --- | --- | --- | --- | --- | --- |
| `speech-01-hd` | MiniMax | 语音合成 (TTS) | 超拟真中文、多情感音色 | 300~600ms | 电商口播讲解、剧情角色配音首选 |
| `speech-01-turbo` | MiniMax | 极速语音合成 | 中文、英语、粤语 | 150~300ms | 实时交互对话、快节奏旁白 |
| `tts-1-hd` | OpenAI | 语音合成 (TTS) | 多语言、标准播音腔 | 400~800ms | 国际化商品外贸介绍视频 |
| `tts-1` | OpenAI | 极速语音合成 | 多语言 | 200~400ms | 界面操作反馈音、低延迟播报 |
| `cosyvoice-v2` | 阿里百炼 | 语音合成与克隆 | 情绪可控、高保真克隆 | 400~700ms | 拟人客服、方言趣味带货 |
| `whisper-1` | OpenAI | 语音转写 (STT) | 99+ 语言高抗噪识别 | 异步/分段 | 视频音频字幕提取、灵感口述转文本 |

## 2. 官方原生调用规范

### 2.1 OpenAI Audio API (Speech & Whisper)

- **官方文档**：`https://platform.openai.com/docs/api-reference/audio`
- **基础端点**：
  - 语音合成：`POST https://api.openai.com/v1/audio/speech`
  - 语音转写：`POST https://api.openai.com/v1/audio/transcriptions`
- **鉴权**：`Authorization: Bearer <OPENAI_API_KEY>`

#### 官方 TTS 请求示例
```bash
curl -X POST https://api.openai.com/v1/audio/speech \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "tts-1-hd",
    "input": "欢迎来到贝壳云图，开启全新的一站式电商内容创作之旅！",
    "voice": "nova",
    "response_format": "mp3",
    "speed": 1.05
  }' \
  --output welcome.mp3
```

---

### 2.2 MiniMax Speech API (T2A V2)

- **官方文档**：`https://platform.minimaxi.com/document/t2a_v2`
- **基础端点**：`POST https://api.minimax.chat/v1/t2a_v2`
- **鉴权**：`Authorization: Bearer <MINIMAX_API_KEY>`

#### 官方入参示例
```json
{
  "model": "speech-01-hd",
  "text": "本期爆款真丝衬衫，现货仅剩最后一百件！",
  "stream": false,
  "voice_setting": {
    "voice_id": "female-shaonv",
    "speed": 1.1,
    "vol": 1.0,
    "pitch": 0,
    "emotion": "happy"
  },
  "audio_setting": {
    "sample_rate": 32000,
    "bitrate": 128000,
    "format": "mp3",
    "channel": 1
  }
}
```
*注：MiniMax 官方非流式响应体默认在 `data.audio` 中返回十六进制编码（Hex-encoded）或 Base64 编码的音频字节流。*

---

### 2.3 阿里百炼 CosyVoice API

- **官方文档**：`https://help.aliyun.com/zh/model-studio/cosyvoice`
- **基础端点**：`POST https://dashscope.aliyuncs.com/api/v1/services/aigc/text-to-speech/synthesis`
- **鉴权**：`Authorization: Bearer <DASHSCOPE_API_KEY>`

## 3. 三方聚合网关（gpt-best）调用规范

gpt-best 针对音频模态全面兼容了标准 OpenAI 协议，并支持 MiniMax 原生透传。

### 3.1 标准 OpenAI Audio 兼容端点（推荐）

通过统一端点，使用一致的请求格式调用 OpenAI 或 MiniMax 语音模型：
- **端点**：`POST https://{{BASE_URL}}/v1/audio/speech`
- **认证**：`Authorization: Bearer {{API_KEY}}`
- **请求体**：
```json
{
  "model": "speech-01-hd",
  "input": "高腰垂感阔腿裤，视觉拉长腿部比例，职场通勤百搭必备。",
  "voice": "female-shaonv",
  "speed": 1.0
}
```
- **响应**：直接返回 `audio/mpeg` 二进制音频数据流，可直接写入 `.mp3` 文件或通过浏览器 `URL.createObjectURL(blob)` 实时播放。

---

### 3.2 MiniMax 原厂格式透传端点

针对需要精细控制 `emotion`（喜悦/悲伤/严肃）、`pitch`（音高）的高阶场景：
- **端点**：`POST https://{{BASE_URL}}/minimaxi/v1/t2a_v2`
- **认证**：`Authorization: Bearer {{API_KEY}}`
- **数据格式**：与 MiniMax 官方完全一致，网关自动透传。

---

### 3.3 语音识别与转写 (Whisper)

- **端点**：`POST https://{{BASE_URL}}/v1/audio/transcriptions`
- **认证**：`Authorization: Bearer {{API_KEY}}`
- **Content-Type**：`multipart/form-data`
- **参数**：
  - `file`: 待识别的音频文件（mp3, wav, m4a 等）
  - `model`: `whisper-1`
  - `language`: `zh`（可选，加速转写）

---

## 4. 官方 vs 三方核心差异对比

- **二进制流直吐 vs Hex 解析**：
  - 官方：MiniMax 原厂接口在 JSON 内包装 Hex 字符串，前端或后端需先解码 `Buffer.from(hexStr, 'hex')`。
  - 三方网关：标准 `/v1/audio/speech` 路由自动解码并以原生二进制 `audio/mpeg` 响应，大幅降低客户端处理负担。
- **音色代码映射统一**：
  - OpenAI 标准音色：`alloy`, `echo`, `fable`, `onyx`, `nova`, `shimmer`。
  - 网关扩展音色：当模型选用 `speech-01-hd` 时，`voice` 字段可直接传入 MiniMax 的音色代号（如 `female-shaonv`, `male-qn-qingse` 等）。
- **鉴权简化**：
  - 无论切换至哪家厂商的 TTS 引擎，前端均只需配置单一网关 Token，无需维护多套厂商密钥。

## 5. 贝壳云图程序集成规范

### 5.1 前端模型配置与模态管理
- 在 `src/client/features/settings/model/modalityModelDefaults.ts` 中维护 `voice` 模态：
  - 默认模型：`speech-01-hd`（展示为 **MiniMax Speech HD**）。
  - 备选模型：`tts-1-hd`、`speech-01-turbo`、`cosyvoice-v2`。
- 服务商管理页 `ApiServicesTab.tsx` 支持动态测试音频模型连通性。

### 5.2 语音合成前端播放与剪辑导出
- 在工坊和视频卡点制作中，前端调用音频合成后将二进制 Blob 转换为临时 ObjectURL 放入音频管理器。
- 最终导出时，通过 Go 后端音视频管线将音频与生图、生视频产物合成最终商用成片。
