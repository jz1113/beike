## 维护方式

每个主题只保留一处完整规则，其他页面通过链接引用。源码路径、默认值、接口与参数以文中列出的代码真源为准；外部资料链接不代表渠道已经完成在线验收。正式测试保留在源码旁，临时计划、截图和一次性验证报告放在项目外。

改动文档名称或位置时，同步更新本页、项目首页、文档互链及代码中的文档标识。历史实现从 Git 查询，不为已完成迁移保留第二套操作说明。
