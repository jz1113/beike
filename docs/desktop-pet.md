# 桌宠

桌宠显示在贝壳应用窗口内，不占用操作系统桌面。设置页从上到下是命令导入、预览调整和形象卡片。预览里可以开关显示、调整大小和动作，形象在卡片中切换。

默认形象是原来的紫色喂图小怪兽。应用同时预置四款 Codex v2 桌宠：Q版大肥鱼、Yena、Sena、The Real Tronald Dump。选择「无」或关闭显示后，封面页工具栏的「投喂样张」仍可打开喂图面板。

导入使用 Codex 的安装命令，一行一条：

```sh
npx codex-pets add q-ban-da-fei-yu
```

页面只解析宠物标识。服务端按 codex-pets 的协议从 `https://codex-pets.net` 下载并校验 `pet.json` 与 `spritesheet.webp`，不会执行粘贴的命令，也不会写入本机 Codex 目录。导入的桌宠按工作区保存在数据目录的 `pets/` 下，不属于可清理的派生缓存。

精灵图播放 Codex v1（1536×1872）和 v2（1536×2288）图集。v2 会在待机时看向指针；v1 继续播放待机。封面投喂优先于全局生成状态。打开设置或离开封面页时，投喂面板关闭，避免页面缓存留下第二个桌宠。
