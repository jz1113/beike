# 无限画布

## 节点与参考

画布把提示词、图片、视频、音频及生成结果组织成节点，连线表达参考关系。文字节点内容按参考列表与当前节点内容组合；媒体须有可用地址且未被标记为缺失，才能作为输入。禁止自连接、重复连接和形成循环；锁定节点须先解锁。

通过节点端口可以新增、断开或重连。端口支持 Enter 或空格进入，保留创建并连接新节点的入口；面板可用 Tab、方向键及 Enter 操作，Escape 返回画布。重连保留连线标识，并移除原连线的分组引用；保存失败后可重试保存。空的生成节点也能提前连线，形成待执行的生成链。

连线端口只是输入关系，实际能否提交仍取决于所选模型、生成方式与素材校验。图片编辑需要已批准、启用且支持编辑的模型及有效参考图。视频的全能参考、首尾帧、编辑和延长规则见[视频接入](models.md#视频生成)；音频端口不代表所有视频模型已接入参考音频。

## 节点编辑与撤销

从首页打开项目后，键盘焦点进入画布。`Ctrl/Cmd+A` 全选节点，`Ctrl/Cmd+C`、`Ctrl/Cmd+V` 在当前画布复制粘贴选区；`Ctrl/Cmd+Shift+V` 强制粘贴已复制的节点。复制保留当前结果、全部生成版本、选区内部连线和完整分组，内部节点引用跟随新节点 ID，不续接原节点的任务。鼠标尚未进入画布时，键盘粘贴放在视口中央。

`Ctrl/Cmd+G` 打组，`Ctrl/Cmd+Shift+G` 解组。分组名称可用键盘聚焦，Enter 或空格选中，F2 改名。Delete 或 Backspace 删除选中的节点、连线或分组内容；输入框中的按键仍用于文字编辑。`Ctrl/Cmd+Z` 撤销，`Ctrl/Cmd+Shift+Z` 重做，Windows 也支持 `Ctrl+Y`。删除节点、连线和分组作为一次操作记录，一次撤销恢复完整选区。撤销历史从项目加载完成后开始，只在当前打开会话保留；刷新会保留最终保存的内容，不把项目加载本身作为可撤销编辑。

## 任务与重试

图片和视频通过统一的持久化生成任务执行。启动前先恢复全局生成历史，再同步节点状态；节点切换显示的产物与服务端任务状态分别保存。每个节点最多保留 20 条运行记录，可切换历史产物，但切换记录不会撤销上游生成。

Studio 的「更多工具 → 生成任务」按节点显示本次任务状态、图片和视频参考数量及生成版本数，支持键盘操作。尚未提交的任务可取消准备和排队，不影响其他节点；已提交的任务只能停止画布等待，后台仍会继续。停止等待后可继续等待原任务，或在完成后手动恢复结果。取消和失败会恢复先前选中的结果并保留全部版本，迟到的旧任务回执不会覆盖新的尝试。复制节点或项目不保留这些任务关联。

「重试本次任务」创建新的提交标识并复用原任务固定的参考、提示词及参数；即使当前连线已改变，也不改用新的参考。「按当前连线生成」使用当前节点配置与连线。提交回执尚未确定时先核对原任务，避免重复提交。生成请求派发前先保存节点关联及本次任务的固定输入；本机保存失败则不派发，修复存储后可重试。保存成功但任务尚未写入历史时刷新，使用保存的输入和原提交标识核对回执，不自动重发；确认没有记录后可显式重试。参考素材准备阶段刷新、尚未形成任务记录时，解除中断的节点锁定并保留原结果，检查历史后可重新生成。

重试沿用原任务保存的输入和模型。提交结果未知时，先按原提交标识核对，恢复来源素材后才能创建新尝试；不能把网络中断视为上游未接单。停止浏览器等待也不能保证取消远程任务。

生成按当前连线读取参考，分组中的文字与媒体完整展开并去重。缺失、未完成、正在生成或类型不兼容的上游会阻止提交；输入校验失败会解除节点的生成中状态，替换素材后可直接重试，刷新也不会残留按钮锁定；断开和重连后不再沿用旧模板的节点依赖。分组按依赖顺序等待每个生成节点返回结果后继续，失败停止后续节点；重新运行时使用本次上游的新结果。切换上游生成版本后，下游使用当前选中的结果。

窄窗口中的参考素材工具条会换行并保持在视口内；「替换参考素材」支持键盘触发文件选择。替换保留节点标识和连线，生成前重新校验素材类型。刷新重开会根据保留的素材重建临时预览，不复用上次页面的预览 blob 地址。

普通视频节点会提交已连接的参考音频，并按当前模型和生成方式校验。语音节点当前支持文字配音，语速取决于所选模型。高清放大使用即梦智能超清 API，支持 4K 和 8K。

本地参考视频需要配置对象存储并转换为上游可访问的地址。存储未配置、素材失效或转换失败时应提示错误，不能漏掉素材后继续生成。

## 保存与深度处理

画布项目结构保存在浏览器 IndexedDB `beike-canvas-projects`，写入按队列串行执行，只保存改动项目，加载完成后才保存。两个窗口编辑同一项目时，较旧窗口的保存会提示冲突并保留窗口内的编辑，可先导出副本再重开。旧 localStorage 项目迁移保留备份，项目删除时同步移除对应的备份条目。保存失败会提示；清理浏览器站点数据会丢失本地项目结构，服务端媒体任务记录不能还原全部节点布局。

首页最近画布在桌面宽度下固定为一排四列：一个新建入口和最多三个最近项目，新建卡片不随项目数量扩宽。项目名称叠在封面底部；「全部」跳转到资产页并选中画布标签（`?view=assets&tab=canvas`），展示完整网格、搜索、时间范围、修改或创建时间排序、修改日期与导入恢复入口。链接支持刷新恢复与浏览器前进后退。小屏按两列或一列排列。首页画布模式只展示最近项目与创作工具小卡片，不设置创作想法输入栏或左侧创作推荐大卡片。项目卡片可重命名、复制和删除。电商视频 · 新版、封面生成和电商图文是系统内置演示画布，按固定项目 ID 保护，重命名后仍不能删除，复制出的普通项目可以删除。新浏览器使用内置工作流初始化，已有项目沿用原画布。`Ctrl/Cmd+S` 保存当前画布，失败后可重试保存。项目读取失败时先重试读取，不使用旧备份或空列表覆盖现有项目。普通项目确认后永久删除，写入失败会恢复项目供重试。复制会保留节点、连线和生成版本，并独立复制项目范围内的素材缓存，不续接原项目进行中的生成任务。

旧画布和 Studio 画布均可使用工具栏的「导出项目」生成完整 ZIP 备份。旧画布包含节点及其尺寸位置、连线与参考关系、分组和节点状态、文字与生成参数、缩放和平移、图片、视频、音频以及节点中全部已保存的运行结果；Studio 画布保留节点连线、文本批注、涂鸦、分组、视口及全部已保存生成版本。只备份项目中仍保留的结果，不包含已删历史、撤销栈、正在执行的远程任务、全局账号、模型配置或项目外的资产库。普通附件、PDF、3D 文件及第三方软件的任意 ZIP 不属于本备份格式的支持范围。素材无法完整读取时不提供部分成功的备份，可修复素材后重试。备份和素材总量限制为 500 MB，恢复还受浏览器可用存储空间限制；旧画布的内嵌媒体编码会比 ZIP 素材占用更多本机空间。空间不足或写入失败时保留原有项目，释放空间后可重试。

资产页画布标签的「导入与恢复项目」及画布工具栏「导入工作流」共用恢复流程，支持贝壳完整 ZIP、旧画布 `nodes/edges` 项目 JSON 和旧工作流 `nodes/connections` JSON。JSON 不保证自带媒体，素材地址必须可读取；无法读取时拒绝恢复。旧画布通过自己的「导入与恢复项目」按钮使用相同流程。先校验全部素材、节点与连线，再另建项目，不替换当前项目。旧 JSON 中的远端素材会先缓存；缺失素材、损坏文件或本机写入失败会保留原项目并提供重试。恢复不续接原生成任务。Studio 恢复后的素材保存在新项目的独立缓存中，打开时解析为临时预览地址，保存仍使用持久化引用。旧画布直接使用可跨刷新读取的内嵌媒体 URL，兼容现有预览、下载、复制和参考链路，不依赖原服务端地址或临时 blob。旧画布的视口独立于 Studio 保存；早期未保存视口的旧项目继续按节点自动适配。两类画布刷新后均可重新打开。

深度图片、深度视频由 Go 接口调用 Python 推理环境；安装及检查步骤见[部署说明](deployment.md#深度图片与视频环境)。

实现真源：`src/client/features/canvas/model/canvasGraph.ts`、`store/canvasPersistence.ts`、`hooks/canvasGenerationActions.ts`、`hooks/useCanvasGenerationSync.ts`，后三条相对于 `src/client/features/canvas/`。

WorkBuddy 或 Codex 可以通过[画布远程 MCP](canvas-mcp.md)创建线上草稿并保存提示词修改；打开草稿链接会进入可编辑的本机副本。

## 商品画布工作流

从「画布 → 新建画布」选择「商品短片」「商品图文」或「商品封面」，创建已连接的独立项目。首页旧快捷按钮和模板卡片区已移除。创建、复制和打开项目均不会自动调用模型。

三类工作流直接复用编辑器现有的素材、文本、图片生成、视频生成、语音、预览和本机下载节点，不再把旧制作页嵌入节点。短片依次制作分镜、首帧与视频，独立旁白为可选分支并单独下载；图文包含场景图与发布文案两条分支；封面包含准确标题、绘图提示词、图片与交付，单张和批量共用品类、可见面与版式匹配规则，按兼容版式的顺序轮换，并组装完整的七段绘图提示词。手机成图使用同一可见面，正面组稿会随机选生活感壁纸。商品参考为第一张图；版式样张作为第二张图提交，仅用于构图、光影和排版。替换整套素材库后，旧提示词需重新撰写，避免相同编号配到新的样张。生成节点必须先获得上游的真实结果，不能把提示词当作生成结果提交。

单张和批量共用已连接的「商品素材」节点。单张可在这里上传并查看图片，在「标题确认」文字节点填写确定的上图文字。可选风格参考提供排版、布光和色调线索。「版式候选」先显示参考样张，成图后自动显示 AI 生成图。「成图对照」并排展示本次生成使用的商品原图和成品。旧成品没有原图记录时仅显示成品。「成图质检」通过后即可从下载节点导出。

批量时在同一个「商品素材」节点上传 Excel（.xlsx 或 .xls），读取 Sheet1 的前三列。前两列填写标题和 HTTP(S) 图片链接，顺序可交换；第三列填写「横」或「竖」，也支持 4:3 和 3:4。导入后节点显示 Excel 行数，点击可更换工作簿。商品图和 Excel 可以同时保留。点击画布右上角「批量封面」后，使用画布的封面提示词节点和封面生成节点所选的模型。批量面板里切换模型也会同步更新对应节点。每行使用自己的商品图、标题和画幅，最多同时执行 20 行。每次执行都会重跑当前表格的全部行，已有成品的行也会重新生图。原图片任务仍在执行时先等待它结束，再提交本轮任务。Skill 可提炼封面上的文案，节点和导出文件名沿用 Excel 原标题。批量 ZIP 直接收录本轮已保存的 PNG。C 列为「竖」时按 3:4 生图，等比缩放到 720×960。C 列为「横」时生成并保存完整的 1:1 方图。标题和完整商品放在中央安全区，两侧只延伸背景，为上传平台后的 3:4 居中裁切留出空间。画布和 ZIP 使用同一份成品。

图片、视频和音频以实际格式下载，文字可连接本机下载节点导出 TXT。旧业务项目迁移为原生节点时保留旧场景、业务草稿和成果。重新打开项目时按原任务或批次标识查询尚在运行的任务，并把取回的成果添加到画布。旧批量导入、审核、字幕与合成仍由兼容业务流程提供。

项目创建、复制、恢复和重命名时避免重名，重复名称使用「 · 02」起的后缀；历史默认名称统一为商品短片、商品图文与商品封面，自定义名称保留。

电商视频画布统一使用应用桌宠作为助手入口。深度复刻上传原视频、商品图和目标人物图。原片自动生成遮脸分镜页，05核对镜头与动作，06按开场对应格生成目标人物、服装和原片场景的整合参考图，07优化后由08继承提示词及图片。分镜提供各镜的场景、道具、光线与动作，人物身份与服装分别使用目标人物图和商品图。旧上传背景保留为素材，默认断开复刻连线；已有画布及结果保留，新版是独立空白画布，从上传素材开始走查。

图层分离在调用模型前，将操作标识按工作区、项目和源节点保存在本机，并确认画布占位节点已保存。跨标签页使用同一源节点的原操作；结果未知时，修改要求、重新打开或刷新都只查询原回执，不换键补发。占位节点提供“查询原回执”；旧占位节点按原编号只查询，找不到回执也不自动重新调用模型。后端以工作区和操作标识原子领取提交，浏览器断连后继续完成回执保存；领取失败不调用模型，结算失败保留未知状态。复制项目或节点不继承原操作。

图片准备、画布保存等提交前步骤失败，或后端明确拒绝且确认结果不未知时，可按占位节点保存的原图和原要求“重试拆分”；本机拒绝状态无法保存时仍只允许查询。已经发送但回执丢失、损坏或查询不到时，不允许换键提交。

图层分离的结果按顺序横向排布，每张都是独立图片节点。图层分离按一次模型调用入账，不按返回图层数累加。成功回执和恢复回执使用实际模型及原调用渠道去重；失败回执保留已经报告的用量，但不计成功产出。提交时保存统计代次，清空统计后重放旧回执不恢复旧用量；缺少原统计归属的历史操作不补造入账。

画布文本生成和05原片分析在发送前，按工作区、项目和文本节点保存操作标识，并确认节点场景已保存。重新运行、原生协议重试、刷新和跨标签页都先核对原操作；结果未知、响应损坏或回执不存在时只查询，不换键补发。恢复查询先于当前模型和参考素材校验，因此原模型被移除或参考素材失效不会触发新调用。旧节点缺少可核对的操作标识时停止提交。复制项目或节点不继承文本操作。

文本后端保存整次操作、最终结果阶段和05观察阶段的独立回执，同工作区同标识以数据库原子领取。观察阶段结算未确认时不进入改编；浏览器断连后继续完成已领取的操作。最终阶段结果已保存但外层回执结算失败时，可查询恢复最终结果；只保存了观察结果时，返回观察内容和结果未知状态，不自动重新观察或改编。点击「查询回执」后，画布立即查询原操作。回执仍在等待最终结果时，每两秒查询一次，单次等待最多 30 秒。收到最终结果后更新节点正文并保留原生成要求。

上游明确返回 HTTP 401 时，文本请求按鉴权拒绝结束，并提示检查当前模型渠道的密钥。历史上被标成结果未知的同类回执也按原操作核对后解除恢复状态；查询本身不重新调用模型，修正密钥后再手动生成。

07视频提示词优化与视频生成前优化分别保存独立的阶段操作，按工作区、项目、节点及阶段隔离。首次调用前持久化操作标识、原输入绑定与技能版本，并确认场景保存；本机快照不保存渠道凭据。后端复用文本接口的原子领取与整体／最终阶段回执。响应丢失、损坏、结果未知或回执暂不可用时，始终查询原标识，不因修改参数、切换模型、刷新或跨标签页而换键调用。

优化恢复先于当前模型、技能与素材校验。07恢复成功后保存为待确认草稿；视频前优化恢复只取回原稿，不自动提交视频。原输入已变化时不将旧稿绑定为新输入；原操作终态已确认后，用户可再次明确发起当前输入的优化。已完成阶段也会保存本机结果，避免场景写入失败后再次调用模型；场景保存成功后才解除恢复标记。缺少原标识或快照的历史未知操作停止提交；复制项目和节点不继承原操作身份。
