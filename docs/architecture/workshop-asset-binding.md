# 种草工坊：图组绑定与生成规则

## 产品目标

输入真实商品图片，复用资产库中的内容图组，输出能追溯到图组、替换资产和商品图的分镜提示词及成图。

已确认：未手动锁定图组时，按每款商品自动匹配完整图组。默认保留母本逐镜构图、动作、场景及出镜范围；人物、穿搭、场景允许显式整组替换。不得将“未选择替换项”解释为随机抽取资产。

## 资产职责与优先级

1. 商品图：新商品身份、品牌、型号、颜色和外观的依据。母本中的旧商品描述不能作为新商品事实。
2. 图组母本：提供四镜顺序、主体占比、动作/摆放、机位、光线和逐镜出镜范围。
3. 人物资产：仅替换人物镜头中的人物描述，不能将静物或仅手部镜头变成人像。
4. 穿搭资产：仅替换人物镜头中的穿搭，不影响商品本身；服饰类商品需要兼容性检查。
5. 场景资产：用户显式选择后整组覆盖场景及其光照描述，原场景文本不再追加进提示词。
6. 商品拍摄规范：约束商品展示，不应改写母本镜头，也不能用通用首饰规则覆盖手机等商品。

“图组原场景/原人物”是继承内容，不应伪造为资产库中另一个资产 ID。“自动匹配”只适用于选组；其余默认值为“沿用母本”。

## 用户流程

### 1. 入库

解构图片，保留来源图片索引、逐镜结构、出镜类型和可替换项。完整四图组才能进入自动匹配；残组可查看但不可当完整母本执行。图组归类应描述主体商品，避免用桌垫、帽子等道具误判商品类目。

出镜类型分为人物、仅手部、纯静物。has_human 表示需要人物/穿搭资产的人像镜头；仅手部通过 hand_held_only 单独标记。

### 2. 商品与选图

选定本次生产商品和身份锚图。当前实现使用第一张选中的商品图作为每镜生图锚图；其余图片可参与分析。界面应明确主图身份，不能把“勾选多图”宣传为逐镜自动选择最佳正反面。

### 3. 绑定规则

生产设置分两层：
- 图组来源：按商品自动匹配，或为当前批次固定一个完整图组。
- 可选替换：人物、穿搭、场景。提供“全部沿用母本”恢复入口。

固定图组显示四镜摘要。无人物镜头的图组不应用人物/穿搭绑定，并提示原因。自动匹配允许每款商品选不同图组；同等匹配的候选按商品顺序轮换。

### 4. 生成提示词

后端先解析图组和有效替换项，再让视觉模型补充商品接触与受光信息。最终提示词由确定性的图组编译器生成，保留逐镜差异。前端与生图提交阶段不得重新用通用人像模板改写这些提示词。

四镜使用原组结构；八镜在原四镜后追加派生镜头，并保留来源关系。八镜是扩展，不是八张原图的忠实还原。

当前生图输入为“商品图 + 图组编译提示词”。源图组图片用于解构和查看，并未作为生图参考图提交，因此不可标注“逐镜参照原图生成”。若增加原图参考模式，必须独立区分商品身份图和构图参考图，并验证旧商品不会被带入结果。

### 5. 修改、重试与追溯

修改图组/替换资产/商品图，使受影响的旧分镜失效；正在进行的旧分析结果不得回写。仅修改画幅、质量、生成模型时复用已确认提示词。失败重试应使用当次已确认的绑定，不能重新随机匹配。

每款商品应展示实际使用图组、匹配方式与替换项；每镜应展示商品锚图、提示词和来源镜头。已经生成的图片保留历史版本，避免配置改变后失去可追溯性。

## 本次已落实的代码行为

- 自动匹配与手动固定图组；完整性校验；模型 product_sentence 响应支持。
- 默认继承母本，显式替换单项；非人物镜头不读取人物/穿搭锁定项。
- 图组独立提示词编译路径，保留逐镜场景、机位和动作；仅手部不再被纯静物禁止手部的规则处理。
- 生图提交保留编译提示词；显示真实的“商品图 + 图组提示词”输入方式。
- 绑定区分层、四镜摘要、沿用母本入口、人物替换适用范围说明。
- 从资产库载入新绑定后使旧分镜失效，避免继续生成旧提示词。

## 尚待实现的完整产品闭环

以下为实施要求，不能作为当前已完成功能宣传：

1. 分析前的逐商品绑定预览：独立的只读 resolve 接口返回候选组、选择原因、替换项和兼容性错误；与分析使用同一个解析器。
2. 持久化绑定快照：保存图组及资产版本/内容摘要、来源镜头、锚图、匹配原因和配置版本。分析与失败重试使用快照，资产修改不会暗中改变已确认批次。
3. 类目映射：将自定义商品类目 ID 解析为名称/关键词/层级，统一前后端匹配；不能将数据库 ID 直接等同于 digital 等内置类目代码。
4. 兼容性检查：人工锁定跨类目图组、场景与原动作的接触关系冲突、服饰商品与穿搭替换冲突时，在付费分析前给出明确处理入口。
5. 来源图组卡片展示四张原图与完整性/出镜类型；手动“载入图组”显示将应用到的批次与已有替换项。
6. 线上验证：本地代码与截图中的线上版本需明确对应；通过真实商品分别验证静物、仅手部、人物、场景替换、八镜扩展以及配置修改后重试。

## 验收标准

- 手机静物图组不能自动注入模特、私服、首饰佩戴和 85mm 人像机位。
- 仅手部镜头允许手部，禁止添加人脸；不出现“禁止手部”的冲突文本。
- 未替换场景时保留逐镜实际场景；替换场景时不残留原场景和旧光照。
- 更换人物/穿搭不改变静物和仅手部镜头的出镜类型。
- UI 显示的组、替换项、商品图与最终请求一致。
- 未匹配到完整图组时在调用视觉模型前失败；单个失败不计为分析成功。
- 结果可以追溯到绑定配置；旧配置的迟到响应不得覆盖新配置。
