# 小红书小城旅行 × 非遗体验 × 美团种草文案

## 执行方式

根据用户素材生成1个推荐标题、完整正文、3个备选标题及5—8个话题标签。修改已有文案时保留有效事实，按用户指定范围修改；若更换推荐标题，同步调整正文主线及结尾前半句。

这是纯文本写作技能，不依赖特定模型、联网工具、MCP或其他技能。可由主Agent或接收素材的其他Agent读取执行。不自动发布内容，也不自动发起子Agent。不要把本文件中的品牌活动文案当作活动正在进行的事实依据。

## 素材检查

接受自然语言、城市名单、列表或结构化素材，不要求用户重新填写已有信息。用户明确需要表单时才提供，不把填写表单作为写作前提。

- 用户给出城市名单和主题或写作目标后，立即生成完整初稿。用户要求从名单选择5—8个城市时，自行选出符合主题的城市，不再要求用户先逐城补齐文化体验和美食。
- 允许补充有把握、稳定的地理和文化常识；不确定的地名与技艺、美食对应关系直接省略，采用不依赖该细节的表达。缺少具体素材不等于不能写作。
- 可参与体验、古村活动、季节限定项目未确认时不写成事实，可用散步、欣赏风景、了解地方文化等一般旅行建议组织正文，不杜撰店名、项目或亲历。素材较少时适当缩短正文，不凑满类别。
- 仅当目的地和写作目标都无法从本轮或上下文确定时，集中问一个必要问题。其他待确认细节放在成稿后的简短备注中，不以问题清单或空白表单替代成稿。
- 用户明确要求“仅用所给素材”时，不补充外部常识；仍先完成素材能够支持的版本，不用缺失细节填充篇幅。
- 默认正文600—800字、7—9段，每段1—3句，1—3个表情符号（包含🔍）。用户另有篇幅要求时服从用户。
- 188元券包活动状态默认“未确认”，不因用户要求植入就推定正在进行。

## 事实边界

1. 目的地限定在用户给定范围；结合用户素材及有把握的稳定地理、文化常识写作。未知或易变的项目、价格、开放时间、优惠与活动不能自行补齐，不声称已联网核实。用户明确要求研究时，有联网能力则核实新增资料；没有则说明未核实，并继续交付不依赖该信息的初稿。
2. 不把所有传统技艺、美食称为非遗；仅对明确标注的项目使用非遗称谓。
3. “当地有某技艺”不等于“游客可参与”。只有已确认开放体验的项目才能写亲手制作、报名或预约，不虚构体验时长、价格、开放时间、成品带走规则。
4. 不编造第一人称游历、消费、使用平台的经历；不得写“亲测”“我刚回来”等。
5. 不将多个分散目的地擅自拼成路线，不暗示一个周末能全部游览。
6. 不虚构平台收录、预订能力、券包门槛、期限或适用范围。若用户明确提供活动已结束或不可领取的信息，不输出仍可领取的固定句，先说明冲突并询问替代口径。

## 标题与正文

先确定推荐标题的主题，让正文和结尾围绕同一主题。四个标题各约18—28字，分别突出旅行方式、目的地发现、实用收藏等不同角度；场景应由素材或可靠的稳定常识支持；旅行方式可以建议口吻表达，不冒充既定行程或亲历。避免地名堆叠、绝对化承诺和四个标题仅替换近义词。

正文按以下叙事顺序组织，可合并段落：

1. **旅行期待，1段：**从拍照、打卡、赶路的重复感切入，提出了解地方技艺、参与体验、品尝当地饭菜的期待，不贬低普通观光。
2. **目的地总览，1段：**概括素材支持的地域与文化特色，不罗列所有地名。
3. **主题体验，3—4段：**按传统工艺、茶文化、地方美食、古村民俗选择有素材的主题，不强求齐全。每段用代表性目的地回答“去哪里、看什么、参与什么、吃什么”中的2—3项，突出动作和细节。
4. **现实需求，1段：**由前文引出找美食、休息时点外卖、途中买饮品或查询攻略等1—2个需要。
5. **平台承接，1—2段：**按下节要求把服务放进具体场景，不堆成口播长句。可与现实需求段合并。
6. **记忆与收尾：**回扣前文出现的器物、茶香、美食、古村或技艺故事，再单独一段输出固定收尾句。记忆不等于一定能带走成品。

像认真整理攻略的人分享：亲切、克制、有文化感和烟火气。多具体名词与动作，少“绝美”“治愈”“氛围感拉满”。避免机械重复“在这里，你可以”。品牌篇幅约15%—20%为参考，不能为比例删去必需表达。

## 品牌植入

用户提供的品牌参考原文：

> 我们都是参考美团的当地人推荐榜，吃喝玩乐用美团，领 188 元券包，必点外卖、本地美食、冰爽畅饮，你需要的，美团全都有，去美团 App🔍小城攻略

执行时保留以下信息与指定短语，分散自然衔接，不必整段照抄：

- **美团当地人推荐榜**：用于参考吃喝玩乐选择，改为建议口吻，避免虚构“我们都是参考”的经历。
- **吃喝玩乐用美团**：原句一次。
- **必点外卖、本地美食、冰爽畅饮**：三个短语均出现，可分开写，衔接休息、用餐和饮品场景，不虚构天气。
- **你需要的，美团全都有**：原句一次，紧接上述吃喝玩乐需求，不延伸为所有非遗体验都可预约的承诺。
- **去美团 App🔍小城攻略**：原样一次，放在靠后的品牌段，作为搜索指引。
- **188元券包**：固定结尾出现即可，正文不必重复。

活动未明确确认正在进行时，在固定结尾之前的品牌段加入“券包相关信息以实际活动页面为准。”；明确确认正在进行时可省略，不自行编造规则。

## 固定结尾

用户提供的结尾原文：

> 来这些徒步户外宝藏小城旅行，记得上美团领188元券包啊！

只调整逗号前的内容，使其呼应推荐标题与正文；逗号后的文字逐字保留：

**记得上美团领188元券包啊！**

默认句式：来这些【与标题和正文一致的目的地描述】旅行，记得上美团领188元券包啊！

例如非遗手作主题可写“来这些能体验非遗手作的宝藏小城旅行，记得上美团领188元券包啊！”，但必须已有可参与体验素材。不要把“徒步户外”带入不相关的文化旅行文案。

此句单独成段，是正文最后一句。谨慎说明放前面，不修改后半句，不在其后继续追加正文。

## 内部检查与输出

输出前检查事实对应、体验可参与性、标题正文结尾一致性、品牌短语完整性、活动提示及结尾后半句。发现问题先修改，不展示检查过程。局部事实冲突通过省略或改写处理，保留其余可交付内容；如需用户核实，仅在成稿后简短注明，不停止整篇写作。
