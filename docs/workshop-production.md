# 电商图文生产流程

电商图文按「商品资料 → 配图方案 → 图文交付」制作。商品资料页同时处理导入、采集与选图，旧步骤 1、2 分别打开导入区和选图区。旧步骤 3、4 继续打开配图方案和交付。网页入口和历史批次标识保持兼容；工作台的导航、生产设置锁和待分析范围从当前商品内容推导，不使用页面所处步骤判断是否完成。

批次工具提供新建、重命名、历史、参考图库和生产设置。空批次默认展示表格导入，也可切换到链接添加。步骤导航在顶栏，根据当前内容与任务状态开放三个工作区；未满足条件的步骤显示原因。商品资料在左侧导入并切换本批图文，右侧在采集前显示当前配图数量和画幅预览，采集成功后直接选图。配图方案与交付页使用相同的内容列表，保留当前图文。切换步骤只查看已有内容，分析与生图分别由对应操作启动。链接采集使用输入框右下角箭头或 ⌘ / Ctrl + Enter 提交。

## 导入与选图

添加商品默认使用表格导入，支持 xlsx、xls、csv。兼容「任务类目、二级类目、三级类目、商品名称、商品ID、需要数量」表头，也可使用商品链接列。需要数量是该 SKU 总共制作的完整图文条数：5 表示五条内容，每条各有四镜或八镜配图及独立文案，数量不改变镜数。同 SKU 重复行按最大总需求合并，数量冲突及原表行号在预览中显示；不累加、不把数量当序号。空数量、非整数、超过 1–20 范围和无效商品来源逐行提示，超出安全数字精度的 ID 必须在原表以文本重新填写。

导入先预览，可以按商品、SKU 或类目搜索、切换工作表、分页勾选并调整数量，再加入本批。整表保留全部有效行供选择，每批最多 20 款商品、200 条内容，超限阻止加入并提示分批，不截断数据。已存在的内容保留，调高总需求只补充缺少的内容序号。加入后点击「采集商品图片」才调用采集接口；同 SKU 多条内容在同轮共用一次采集请求，失败也不会自动重复调用。

商品采集完成后不自动选图，必须为每条图文手动选择至少一张商品图；辅助分析和历史分镜导入也不会用第一张主图或旧参考图代替人工确认。

「链接添加」保留快捷入口，支持京东、淘宝、天猫、1688；裸数字只接受 7–16 位京东 SKU，不从任意文字中猜商品编号。重复、无效和超出每批 20 款上限的输入会跳过并提示。天猫与旧版淘宝标识下的相同商品编号兼容去重。

「批次工具 → 参考图库」用于整理学习资料，默认展示全部参考图组。左侧商品分类可直接切换大类或细分，无需逐层进入文件夹；右侧展示当前分类的参考图组。创建、改名、移动、删除分类及分类规则集中在「管理分类与规则」；归档分类不删除母本。

同款多条图文各自保留选图与创作方向。可按内容序号跳转或定位首条待选。确认选图后进入配图方案。页面按内容列出状态，一次编辑一条，切换交付时沿用当前选择；批次配置和「管理创作技能」集中在方案页。技能编辑器直接打开在当前制作步骤上，关闭后继续编辑同一条图文。已跳过的图文可在商品导入区恢复制作。

## 生产设置

新批次默认四镜四宫格，一次生成整图后拆成四张。四宫格与单张逐镜在设置顶部直接切换；切入四宫格时统一收敛到四镜，单张模式可选四镜或八镜。模式与镜数随当前批次保存，浏览器本地的旧模式和镜数不作为新批次默认值。新建批次保留模型、画质、画幅与切图尺寸，输出方式回到四宫格；恢复或复制历史批次保留原模式。

商品选图决定本条图文的外观参考。分析配图方案时匹配创作技能，并将实际使用的技能名称、版本及正文保存在本条方案中，分析历史同时记录实际使用的版本。手机生图会把方案中可见的外观特征传给每一镜；整机图确认模组相对机身的位置，局部图确认内部排布。确认生图后，四宫格使用编辑后的整组提示词，逐张生成使用各张配图词。发布文案以采集到的商品名称、属性为事实依据，并结合最多两张有效成图与对应分镜的场景描述。资料不足时可以短写，不补入试穿、洗护或长期使用体验。设置显示技能加载状态；默认按商品标题和类目属性匹配细分技能，有手动技能时可显式选择。参考图组、素材库存、人物/穿搭/场景替换不再是生产设置，也不参与新分析或生图。参考图库中的采集、反推和学习仅用于整理创作技能。

创作技能提供构图、场景、展示节奏、人物与穿搭安排和商品约束；当前商品图提供身份、结构、颜色与材质。自动模式读取匹配细分的当前试用版或正式版；没有匹配技能时使用基础创作技能。学习原图被移除或失效不阻止已启用技能的生产；技能本身为空或不可访问时明确报错。设置显示整图请求尺寸与预计单张交付尺寸，实际尺寸以模型返回和任务保存的切图规则为准。

同款多条内容预先分配不同展示重点、开场、场景和机位节奏。前五条分别从整体设计、细节材质、使用情境、收纳搭配和空间氛围切入；读商品图后按用途调整不适用的场景。规划与同款已完成分镜传入分析，要求至少两个实质维度有差异，不能仅改标题或颜色。不同 SKU 可并发分析，同 SKU 按序分析以利用前一条的实际分镜。选图、分镜和交付中显示内容序号及方向，导出组名也包含内容序号，避免同款多条互相覆盖。该规划是创作约束，实际画面差异仍需审核成图。

## 分镜与生成门禁

`model/workspace/workshopFlow.ts` 统一推导导航、选图数量、步骤完成状态和待分析商品。`model/generation/workshopReadiness.ts` 判断商品图、分镜数量与编号、技能分镜、提示词和恢复任务是否满足生成条件。

问题按修正动作区分：缺图返回选图，缺分析或沿用旧参考分镜时重新分析，空白提示词定位编辑，未核对的上游任务进入交付恢复。仅需编辑提示词的商品不会被自动加入付费分析。已就绪分镜不因其它商品待处理而重算，也不再要求当前资产库满足重新分析的条件。

修改单镜提示词时，同一次状态更新重建四宫格整组提示词，清除旧四宫格原图缓存。对应单镜成图标记为旧版本；来自同一四宫格的切片全部失效。旧图片地址保留，但不计入当前有效交付。分析、生成或待恢复时禁止编辑相关提示词。

批量与单镜分析检查正在进行的采集、文案和生图操作；生成入口再次检查执行状态。分析响应处理异常时解除分析状态并记录错误。批量生成等待自动文案结束后解除运行锁；文案失败原因留在商品卡片中。

## 交付与恢复

交付页分别统计商品款数、图文条数、成图张数和已完成文案条数。可逐条检查，或切换到全部成图按内容方向审核。预览优先按任务记录的交付尺寸展示，旧任务沿用批次画幅。ZIP 和 Excel 按原图号交付采用的配图；有第 5–8 张时扩展图片链接列，四张批次沿用原表头。不采用的配图也不作为发布文案的图片或场景依据。交付页显示有成图但缺文案的条数；批量补全只生成缺少的文案，全部已有文案时会显示重写操作并单独确认。

生成期间允许进入图文交付，查看进度并暂停或停止队列。其它生产步骤在执行中禁止切换。旧版本成图不会单独解锁当前交付步骤；需要核对的旧任务即使商品取消选择也保留交付入口与恢复控件。核对只查询原任务，不因页面跳转重新调用模型。

商品来源沿用原平台链接；无链接时根据真实平台和商品 ID 构建。对本地商品展示类目，不生成电商平台链接。

生产输入与历史素材兼容规则见 [workshop-asset-binding.md](workshop-asset-binding.md)，技能学习规则见 [workshop-reference-generation.md](workshop-reference-generation.md)。

## 批次管理

从「批次工具」可重命名当前批次或进入历史批次。新建窗口支持填写名称；留空按「电商图片 · YYYYMMDD · 六位短编号」自动命名，日期使用北京时间。当前为空白批次时直接复用，避免重复创建。固定展示编号为 `EC-YYYYMMDD-短编号`，以创建时间与原始标识生成，修改名称后编号保持不变。

批次管理采用列表与详情双栏，桌面打开后直接展示最近批次，手机先显示列表。列表仅保留缩略图、批次名称和北京时间的更新时间，长名称最多展示两行，编号收进详情的「信息」中；历史默认名称兼容展示，自定义名称保留。可按名称、编号、商品或 SKU 搜索，筛选有成图、未完成、有失败及空批次，并按最近更新、最早更新、最近创建或名称排序。详情仅显示图片生产进度与紧凑的商品、成图及失败数量。空白历史记录保留，已输入链接但尚未采集的记录归为待采集批次并可复制续做，当前批次单独展示，点击整条可返回工作台。

点击记录只读取快照，不切换当前工作批次、不调用模型；可直接预览商品参考图和逐镜高清成图，通过主操作「查看交付」进入交付页查看和导出。有效成图统计排除已过期版本、缺失结果和刷新后失效的临时图片。选择「复制续做」会创建新批次并保留原历史；运行中的生产任务结束后才允许切换。副本名称不超过 120 字，不叠加重复副本后缀。

「多选」模式点击整条记录即可勾选，选择数量、全选、删除和退出集中在同一工具栏；跨筛选保留选择并显示总选择数，详情中的重命名、单条删除、交付与续做操作在多选时停用或收起。列表支持方向键移动焦点，搜索框内按 Escape 清除搜索，再按可退出多选；手机详情中按 Escape 先返回列表，之后才关闭管理。名称未修改时不重复提交，超过 120 字时就地提示；「管理」提供清理全部空批次及清空全部历史。空批次清理只包含没有商品且没有待采集输入的历史记录。删除单条、选中记录、空批次或全部历史均通过独立弹窗二次确认并展示操作范围，弹窗隔离背景操作、默认聚焦取消，删除过程中禁止关闭；取消后恢复操作焦点。当前批次不能删除，图片文件保留。批量删除逐条执行；部分失败时保留失败记录和选择，明确显示成功与失败数量，自动切换详情不会清除错误提示，可再次选择重试。


## 任务记录

顶栏「任务记录」按当前工作区查询活动和历史批次的生图提交与已持久化的流程记录。四宫格的一次提交显示一条，已有提交回执优先于批次快照；旧快照中的待处理或失败任务也可查询。筛选和分页在服务端执行，详情可查看上游编号、模型、所属批次、错误和结果。旧记录没有时间时显示「—」，不使用批次修改时间代替提交时间。批次新建、历史和设置在顶栏「批次工具」内。
