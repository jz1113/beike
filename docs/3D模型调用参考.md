# 3D 模型调用参考指南

本文档整理当前主流 3D 生成模型（腾讯混元 3D、Tripo 3D、Meshy 等）的官方调用规范、gpt-best 聚合网关（Fal.ai 兼容协议）调用方式、二者核心差异及贝壳云图项目内的集成映射。

---

## 1. 适用模型一览

- **Hunyuan 3D Pro / Rapid**：腾讯混元 3D 旗舰/极速模型，网关模型 ID 对应 `fal-ai/hunyuan-3d/v3.1/pro` 或 `fal-ai/hunyuan-3d-v2`
- **Tripo 3D**：TripoAI 新一代文/图生 3D 网格模型，网关模型 ID `fal-ai/tripo3d`，官方为 `tripo`
- **Trellis / Meshy**：高质量带纹理 3D 资产生成模型

---

## 2. 官方原生调用规范

### 2.1 Tripo 3D 官方 OpenAPI

- **官方文档**：`https://platform.tripo3d.ai/docs`
- **基础端点**：`https://api.tripo3d.ai/v2/openapi`
- **认证方式**：`Authorization: Bearer <TRIPO_API_KEY>`

#### 创建任务（文生 3D / 图生 3D）
```bash
# 提交图生 3D 任务
curl -X POST https://api.tripo3d.ai/v2/openapi/task \
  -H "Authorization: Bearer $TRIPO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "image_to_model",
    "file": {
      "type": "jpg",
      "file_token": "upload_file_token_or_url"
    },
    "model_version": "v2.5-20250123",
    "texture": true,
    "pbr": true
  }'
```

#### 官方响应结构
```json
{
  "code": 0,
  "data": {
    "task_id": "93b4a2d8-5524-4f0f-859a-df59813d10c2"
  }
}
```

#### 查询任务结果
```bash
curl -X GET https://api.tripo3d.ai/v2/openapi/task/93b4a2d8-5524-4f0f-859a-df59813d10c2 \
  -H "Authorization: Bearer $TRIPO_API_KEY"
```
完成时状态为 `success`，返回包含 `.glb` / `.obj` 模型下载链接及渲染缩略图预览。

---

### 2.2 腾讯混元 3D 官方 API

- **官方入口**：腾讯云混元大模型 / 腾讯混元 3D 开放平台
- **协议机制**：基于腾讯云 TC3-HMAC-SHA256 签名规范请求 Action `Generate3D`
- **入参格式**：接收 `Prompt` 或 Base64 编码的图片，返回异步任务 ID，需通过 `Describe3DTask` 轮询模型渲染进度。

## 3. 三方网关（gpt-best / Fal.ai 协议）调用规范

在 `gpt-best` 聚合网关中，3D 模型兼容 **Fal.ai** 开放接口规范，统一将请求路由到 `/fal/` 前缀。

- **网关地址**：`https://{{BASE_URL}}/fal/{{model}}`
- **认证方式**：`Authorization: Bearer {{API_KEY}}`（官方 Fal 原生为 `Authorization: Key {{KEY}}`，此处改为标准 Bearer）

### 3.1 提交任务

```bash
curl -X POST https://{{BASE_URL}}/fal/fal-ai/hunyuan-3d/v3.1/pro \
  -H "Authorization: Bearer your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "input_image_url": "https://example.com/product-sketch.jpg",
    "generate_texture": true,
    "texture_resolution": 2048,
    "remesh": "auto"
  }'
```

#### 网关响应
```json
{
  "status": "IN_QUEUE",
  "request_id": "551a32da-52b2-4be8-bf2f-bfb7cce2b324",
  "response_url": "https://queue.fal.run/fal-ai/hunyuan-3d/v3.1/pro/requests/551a32da-52b2-4be8-bf2f-bfb7cce2b324",
  "status_url": "https://queue.fal.run/fal-ai/hunyuan-3d/v3.1/pro/requests/551a32da-52b2-4be8-bf2f-bfb7cce2b324/status",
  "queue_position": 0
}
```

### 3.2 查询任务结果

将 `response_url` 中的 `https://queue.fal.run` 替换为中转网关基础地址：
```bash
curl -X GET https://{{BASE_URL}}/fal/fal-ai/hunyuan-3d/v3.1/pro/requests/551a32da-52b2-4be8-bf2f-bfb7cce2b324 \
  -H "Authorization: Bearer your-api-key"
```

#### 完成响应
```json
{
  "status": "COMPLETED",
  "model_mesh": {
    "url": "https://v3b.fal.media/files/3d/model_output.glb",
    "content_type": "model/gltf-binary",
    "file_size": 18451200
  },
  "timings": {
    "inference": 18.42
  }
}
```

## 4. 官方 vs 三方核心差异对比

- **鉴权差异**：
  - 官方：各厂商独立机制（腾讯云 HMAC 签名、Tripo 专属 Token、Fal 专属 Key 前缀）。
  - 三方网关：统一使用统一 Bearer 令牌鉴权。
- **端点路由**：
  - 官方：直接访问厂商 API 域名。
  - 三方网关：统一走 `{{BASE_URL}}/fal/{{model}}`。
- **文件传递**：
  - 官方：部分要求先上传换取 `file_token`。
  - 三方网关：直接接收公开可访问的 HTTP(S) 图片链接 `input_image_url`。
- **产物轮询**：
  - 官方：按厂商各自 schema 解析 `status`（如 `success`、`running`）。
  - 三方网关：统一按 Fal 状态机解析（`IN_QUEUE`、`IN_PROGRESS`、`COMPLETED`、`FAILED`），产物链接在 `model_mesh.url`。

## 5. 贝壳云图程序集成规范

- 前端设置项：`src/client/features/settings/model/modalityModelDefaults.ts` 中 `three_d` 模态配置。
- 默认模型：`fal-ai/hunyuan-3d/v3.1/pro`，展示名称为 **Hunyuan 3D**。
- 备选模型：`tripo` (Tripo 3D)。
- 资源后缀放行：确保 `fal.media` 与 `tripo3d.ai` 处于 `src/shared/data/remote-host-suffixes.json` 中，确保 3D `.glb` 资产可被安全加载。
