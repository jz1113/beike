# 视频带货工作室

工作室用同一套制作阶段覆盖各类商品。创作技能决定叙事规则：服饰专属规则仅用于服饰、鞋、包，其余商品使用通用制作流程。

## 操作顺序

1. **商品确认**：采集商品链接，或手动填写资料、补充商品图。直接选择本次需要的商品图，无需手工输入颜色；请选用同一款式、颜色的图片，外观以所选图片为准。确认商品时选择创作技能：服饰、鞋、包使用服饰专属规则，其余商品使用通用制作流程。该规则作用于随后的商品分析与口播；采集不会改写已选技能。
2. **口播脚本**：选择多模态模型，设置目标时长及画幅。默认 15 秒，可选 15、30、60 秒或输入 10–120 的整数。模型分析商品、编写口播和连续分镜，规划必要的人物、场景或关键帧；此阶段无需人物上传，也无需选择视频模型。服饰口播是对镜头说的第一人称：开场用一个场合或一件具体的事开口，把事实嵌进这句话，收尾可以说清怎么穿，也可以征求意见。15秒全片写48–69个汉字，约每秒3.2–4.6个字；每一段至少一句，不必写满同一密度，单段不超过约每秒6个字。标点、数字、字母和省略号不计。只报结构名称，或用精致、百搭、值得入收尾，都不算购买理由。事实仍限于看得见或资料里有的内容。成片提示词按生活实拍架构书写，并要求语速略慢、句间停半拍、嘴型对齐。
3. **素材图片**：选择绘图模型，检查素材设定后明确点击生成。人物、人脸及场景按脚本规划；人脸依赖同一人物，商品上身或手持画面直接引用所选商品图，不为同一商品机械建立平铺图到上身图的串行依赖。图片逐张保存，局部失败只补缺失项。单条制作默认人工看图，点击“图片无误，确认并继续”后进入提示词阶段，不自动调用多模态校验。需要辅助检查时可展开“自动校验（可选）”，记录通过、冲突或无法判断；批量素材准备调用仍默认校验。必要图片未齐或未确认时不能提交视频。
4. **视频定稿**：素材通过后，定稿页显示并允许更换写提示词的多模态模型，它与口播脚本是同一只。再选择视频模型、参考模式和分辨率。检查实际参考图数、精确时长、画幅和口播能力；不兼容时需要主动更换配置。点击“生成视频提示词”，由这只多模态模型查看真实图片，按实际提交顺序编写完整提示词和分镜说明。切换多模态模型或视频模型不会自动生成提示词，也不会使已有有效提示词过期；仅在主动点击“生成视频提示词”或“重新生成视频提示词”时调用多模态模型。新配置的时长、画幅、音频、参考模式和图片数量仍需通过兼容性检查。
5. **生成结果**：明确点击生成整段视频，只提交一个视频任务。分镜是整段时间轴，不是独立生成任务。历史逐镜任务仍可查询和查看。

## 工作区导航与任务恢复

- 五个阶段可随时查看，阶段内展示脚本、素材确认和提示词定稿状态。历史方案入口在工作区顶部，各阶段均可切换；执行任务期间暂不可切换方案。
- 重新编写脚本或定稿失败、取消时保留当前查看阶段，已有内容仍可查看。生成视频期间切换查看阶段，底部仍提供停止入口；停止不取消服务商已经接受的任务。
- 素材页分别展示已生成、已确认、必需素材和失败数量。已有图片任务回执时优先继续查询，无需重新选择绘图模型，也不会重新提交；单张查询只查询对应素材。方案过期不影响查询原图片任务。
- 图片提交结果未确认且没有回执时，显示待核实并阻止直接重投；参考图在创建任务前被明确拒绝的素材可修正后重试。成功查询后，再单独补齐缺失素材或确认图片。

## 出镜说话与口型

台词仍保存在 `voiceover` 字段，声音来源单独由每段 `speechMode` 指定：`on_camera` 表示画内人物现场说话，`voiceover` 表示明确的画外音。新服饰脚本必须输出该标记。创作设置选择服饰技能时默认选中“人物出镜讲解”，也可明确改为商品、手部或背影展示；已保存方案沿用原出镜方式。人物讲解必须包含出镜说话分镜，开场与收尾优先说完整短句；纯商品、手部或背影脚本仍可使用画外音，不强加人脸。时间轴展示声音来源，可展开逐段修改；改动进入定稿内容签名，旧提示词失效，需要检查素材并重新定稿。旧脚本未标注时保持兼容，定稿要求按实际画面判断，界面不会将其伪装成已标注。

出镜段需要同一人物头顶至腰部或大腿的正面或轻微侧面中景素材，嘴唇完整、清楚且无遮挡；静帧不写台词，也不靠夸张张嘴生成口型。可选自动校验检查讲解帧的嘴部条件，无法确认则保持待确认。定稿与固定提交前言明确由画内人物亲口说出，中文发音、唇形开合、下颌与起止逐字同步，停顿自然停嘴，转身、换装或遮嘴动作放在句间。画外音段沿用同一人声线，画内人物不开口。已标声音来源的分镜若在完整或分段提示词中遗漏、改写台词原文，定稿直接失败，不自动补写模型结果。

实拍感通过可执行的节奏控制：稳定手机机位或轻微手持，每句一个简单展示动作，自然眨眼、呼吸、轻重音及视线变化；避免播音腔、持续微笑、磨皮、匀速摆拍、无目的运镜和慢动作口播。视频请求继续开启原生音频，但音频支持和静帧校验不能保证最终口型。成片预览需听看人物是否实际开口、逐字同步、停顿停嘴和转身前说完；返回视频仅表示任务完成，不代表口型已通过，不自动重投付费任务。

## 服饰景别与运镜

商品分析、脚本、素材计划和视频定稿统一默认中景、中全景或全身展示，保留整件商品及穿搭比例。运镜优先固定机位或保持相同距离的小幅横移、轻微跟拍；不默认推近、变焦、数码裁切放大，也不让人物或商品主动贴近镜头。讲领口、面料、刺绣等事实时，用正常距离的手势或姿态展示，不机械插入局部、微距或 logo 特写。旧兼容字段 `product_closeup` 在服饰流程中表示商品展示方式，不要求字面上的近景。

出镜说话使用头顶至腰部或大腿的中景，完整头部、嘴部与主要服装同时入画；通过清晰素材、无遮挡和正面角度兼顾口型，避免为看嘴部而放大人脸或胸前商品。人脸参考用于身份继承，局部商品原图用于事实对照，均不代表成片采用其裁切。logo、小字和五金保持原图位置与自然比例，不要求逐字可读，不改字、删标或人为模糊。中景里标志小不等于错误，有证据的缺失或移位仍须校正；无法判断必要外观时仍待确认。

重新定稿将旧近景、特写或推近改成正常距离的展示动作，保留原台词、声音来源和时间轴；实际素材只有局部、无法支撑中景时需先补充素材，不虚构画外结构。已有草稿、图片、成片和任务回执保留，不自动重生成或产生付费任务。

## 服饰人物选角

服饰人物选角统一设定为东亚成年人，人物、人脸、上身图和视频沿用同一身份及具体年龄；每张有人物的素材名称和提示词写明选角。优先遵循明确的成年目标人群，再综合版型、风格与场合选年龄：潮流校园感可参考18–25岁，简约通勤25–35岁，成熟商务30–45岁，成熟人群款40–60岁，明确银发定位55–70岁。区间允许交叉，只是选角建议；宽泛基础款且无人群线索时采用约30岁的中性选角，不仅凭品牌或颜色判断。童装用成年讲解者手持或静物展示。确认时检查身份及外观年龄是否一致；辅助校验不凭人脸确定真实族裔或精确年龄。旧素材保留，修改设定后需按需重生成、确认及定稿，不自动提交付费任务。完整规则见 [服饰带货技能](../.agents/skills/fashion-video-sales/SKILL.md)。

## 商品图选择

- 完整图库和主图、规格图、详情图分类继续保留，选择和取消不会删除原图，也不会改变原始目录编号。
- 平台实际返回的规格元数据随缓存和商品存储往返保留。新采集商品不自动选图，由用户直接选择本次需要的图片。
- 图库提供“全部图片 / 已选 / 未选”和大图预览；缩略图下方及大图内均可选择或取消，无需填写颜色。
- 生成仅使用已选且可读取的图片。旧草稿已确认的图片和有效规格关联选择继续保留；首次直接调整选图时转为显式图片选择并清除旧颜色约束，避免与新选择矛盾。新接口同样检查允许编号和引用。
- 当前单次创作请求最多接受 40 张允许商品图，脚本最多 40 个分镜；超限明确报错，不静默丢图或截断分镜。完整采集图库不受此请求限制。
- 每张商品素材单独保存 `productImageIndexes`，使用允许且模型实际看过的商品目录原始编号，按目标正面、背面或局部选择，不再共用视频分镜的一组选图。缺失或不可用引用会在生图前阻断。旧计划没有该字段时，生图带入全部已选商品图，不把某个分镜的背面图当成唯一正面依据。
- 单张绘图只注入该素材的名称、提示词与有序参考用途，不混入整段分镜中的正反动作。前置人物或场景图只继承身份、空间和光线，商品外观以原图为准。模型按领口、门襟、口袋、接缝和标志位置区分正反；正面要求生成成背面、图案缺失或移位、多视图拼图均应校验冲突，无法辨认时保持待确认。这是多模态辅助校验，不能承诺生成模型绝不出错。
- 请选用同一款式、颜色的商品图。视觉校验只能提供辅助证据，无法判断时应保持待确认，不代表颜色和外观的绝对保证。

## 商品分析失败

口播脚本开始前，系统使用当前多模态模型分析所选商品图，商品颜色和外观以实际图片为准；兼容读取的旧草稿若有已确认颜色，也随分析传入。Claude 走 Anthropic 官方 Messages 接口（`/v1/messages`），配置里保存的旧兼容地址也会在发送前规范化到该接口。失败提示会区分缺少配置、图片无法下载或格式不受支持、鉴权失败、限流、服务不可用、调用超时、模型输出被截断、返回不是有效 JSON，以及没有可用卖点。商品分析、口播、选图、素材校验与定稿请求统一显式设置输出预算，避免完整 JSON 被网关默认上限截断；输出在对象闭合后仍被标为长度上限时，仍采用这份完整结果。多批图片会标明批次，汇总失败会单独标明。提示不包含密钥、图片地址、签名参数或模型原文。脚本生成使用包含 `deliveryMode`、`assets` 与正确字段类型的完整当前流程示例；解析时忽略不会使用的字幕设定，并将空字符串素材依赖视为空数组，其他不合法依赖仍拒绝。上游调用成功后的解析错误会区分 JSON 语法、脚本数量及具体字段类型，不能将调用成功等同于脚本可用；普通解析错误不自动重发模型请求。素材校验和视频定稿沿用同一套失败分类，并标明所处阶段。Claude、Gemini 的原生内嵌图片链路与 OpenAI 的 data URL 会先生成视觉输入副本：原图受 25 MiB、4000 万像素和单边 32768 的安全限制，副本等比缩放至最长边 2048、按需压缩至二进制不超过 4 MiB；保留原始素材、不裁切商品，JPEG 重编码时应用原图 EXIF 方向，避免丢失拍摄方向信息。OpenAI 远程 URL 继续原样透传，由上游获取，不转成大段内嵌数据；路径以 `.octet-stream` 结尾的地址会先下载，并按文件头转成 JPEG、PNG、GIF 或 WebP 的 data URL。整次模型请求仍受 32 MiB 限制。声明类型与字节不一致时，只要内容实际是 JPEG、PNG、GIF 或 WebP，就按字节格式制作副本；`image/jpg`、空类型和 `application/octet-stream` 同样以字节为准。下载远程图片时使用与页面预览相同的浏览器标识，并为淘宝、京东等图床带上对应来源页，不主动索取 AVIF，避免防盗链页面被当成不受支持的格式。连接中断时会优先改走 IPv4 再试一次；返回明确的 HTTP 错误则不再重试。损坏、伪造的非图片内容或超过安全上限的图片明确失败，不会静默丢弃。官方协议失败不会改成占位分析。

## 输出截断恢复

- 各文字阶段默认允许最多 16384 个输出 token，并要求紧凑 JSON，减少重复说明，保留完整字段、分镜、素材、口播和精确时长。预算是上限，不代表每次都会消耗完。
- 只有上游明确返回长度上限且 JSON 对象不完整（包括正文为空）时，自动重新生成一次完整结果，预算最多提高到 32768。恢复保留原始事实和图片，不拼接残缺 JSON，不缩短口播或静默丢弃分镜；恢复后仍执行原有时长、素材依赖和图片编号校验。
- 若服务商以 HTTP 400/422 明确说明输出参数超过其上限，则按返回的明确上限调整一次。已确认的较小上限继续用于恢复，不反复请求超限额度。上下文不足、普通解析失败、鉴权、限流、网络故障和超时均不触发此恢复。
- 初次调用与自动恢复共用五分钟等待期限，停止会中断后续恢复。截断恢复可能额外消耗一次文字模型费用，成功响应累计本次各次调用的 token；多批商品分析也累计全部批次与汇总。该机制仅用于文字结果，不自动重新提交图片或视频生成任务。
- 恢复后仍截断时，提示具体失败阶段，并建议缩短目标时长或切换支持更长输出的模型。

## 失效、费用和恢复

- 商品、所选图片、资料、时长或画幅改变后，旧方案标为过期；切换视频模型、多模态提示词模型、参考方式或清晰度时保留已有有效提示词、脚本和图片，不再强制重新生成提示词。模型切换引起的参数自动调整同样遵循此规则；配置不兼容时阻止视频提交，并提示具体配置原因，不将提示词误标为过期。已经过期或未完成的提示词不会因切换模型被重新认可。
- 脚本或素材设定改变后需重新确认素材并更新视频提示词。成功且输入一致的素材可复用；同一图片设定最多提交 3 次，已有回执的查询不增加提交次数。生成单张素材时只提交该素材及其尚未完成的前置依赖，不提交互不依赖的其他缺失素材；必要素材未齐时不会把局部结果当成整体确认完成。
- 图片齐备后可以展开“自动校验（可选）”并点击“仅重新校验已有图片”，只调用多模态校验，不调用绘图模型、不重投生图任务；适合下载失败后的恢复。绘图参考超过 8MB、且不超过 25MB 时，提交前会生成不超过 8MB 的 JPEG 传输副本，不覆盖已保存图片。视觉校验本身仍可能产生模型费用，人工确认不调用模型。
- 已有图片或视频任务回执优先查询，不因刷新、停止或改配置重新提交。视频查询沿用提交时的模型和渠道，并携带原输入快照。付费提交前先把稳定提交标识写入本地项目；保存失败则不会提交。响应丢失后按该标识核对服务端记录，找到任务后再查询，不会另建计费任务。
- 停止操作只停止后续提交或查询，不能保证取消服务商已接受的任务。提交结果未知且没有提交标识时阻止自动重投，应先核对服务端生成记录。当前流程不再新建逐镜视频；历史逐镜结果仍可查询、播放和下载。
- 单项重新生图和再次生成已完成视频会提示费用。历史方案、成片和回执保留在结果阶段；清空商品仍需确认。
- 旧草稿可读取，旧提示词需重新定稿，缺少参考图选择时需补选。模型调用遵循现有模型路由与凭据配置。

## 布局

桌面商品面板默认 480px，分隔线可拖动或用方向键调整，Shift 加大步长，Home / End 到边界，并记忆宽度。进入后续阶段后，商品资料默认收为摘要，可按需展开编辑。窄屏沿用同一套五步导航，只显示当前阶段内容；编辑商品后可返回原来的创作阶段。素材图片按该图实际宽高比显示，高度不超过预览上限，不把画面拉满卡片、也不预留两侧空白。

全页底部只有一个阶段主操作区，依次引导编写脚本、确认素材、定稿和生成。有效定稿后，付费生成成为主操作，重新定稿为次操作；定稿不会自动提交视频。缺少资料、方案过期、提交被阻断和任务恢复的原因直接显示在操作区附近。

创作技能放在创作设置最上方并常显。品牌在商品资料中直接显示，采集属性不放在商品确认页；价格不展示，口播也不出现价格或金额。图库分批展开，保留完整预览及直接选图。商品确认页不展示采集来源说明。脚本以口播和画面时间轴为主，绘图提示词默认收起，失败及冲突素材的编辑区自动展开。视频定稿的完整提示词直接展开为纯文本，并按提交顺序标出实际参考图。结果区区分提交、查询、未知和失败，有回执时明确提供仅查询入口。

“带货规则”只在页头保留一个入口，商品设置保留一次紧凑规则说明，空状态不再重复展示。弹窗只展示已接入的服饰专属规则，概览为单张紧凑卡片。查看详情在当前弹窗内切换到技能正文，顶部可返回，并保留完整技能原文阅读与 `SKILL.md` 复制。创作设置仍可选择通用制作流程，非服饰品类继续使用该流程。工作台和弹窗均支持浅色、深色及键盘焦点。

## 等待、续做与前置检查

分析和脚本按输入保存阶段结果，后续失败重试只继续未完成阶段。只选一张商品图时直接匹配，不额外调用选图模型。多图上传最多并行3张，部分失败保留成功项，只需补传失败图片。商品大图支持上一张、下一张及左右方向键；当前创作步骤随草稿保存，刷新后恢复到原步骤。

运行时显示已等待秒数，生图显示已生成数量，自动校验单独显示当前阶段，不同时显示待生成的静态拦截提示。采集、上传、脚本、素材、自动校验、提示词和视频查询均有停止入口；停止会中断本次等待，不能保证取消服务商已接受的任务。生图停止后保留提交标识，按原标识核对回执，不重新提交。

创作设置提供可选成片模型预检，在生图前提示已选模型的时长、画幅和声音不兼容；仍可到视频阶段再选择模型。结果区错误集中显示一次，并显示可复制的提交标识、上游任务ID和原提交模型，便于核对。

没有上游任务ID的未知提交，在人工向渠道明确核实没有创建任务后，可展开人工核对入口，确认后另建待提交草稿；原未知记录、脚本和提示词仍保留在历史中。这一步不提交视频，后续仍需单独点击生成。有上游任务ID时不提供此入口，只查询原任务。

脚本要求使用效果有商品资料的明确依据，不能由罗纹、材质比例或图片外观推断“不闷”“不往上滑”等实测结论。界面对未在所提供资料中出现的常见体验断言给出人工核实提醒，不静默替换口播。

## 提交诊断

Comfly的万相官方格式使用其文档指定的`/qwen/api/v1/services/aigc/video-generation/video-synthesis`及对应查询路径。原生百炼渠道保持原生路径，其他渠道保持既有安全回退规则。提交失败保存脱敏原因、上游HTTP状态与端点尝试数，按原提交标识查询时继续返回原原因。5xx、网络故障或成功响应缺少任务ID仍视为未知，不据此自动重投。历史未知记录不能补造当时没有保存的诊断。
