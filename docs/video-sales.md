# 视频带货工作室

工作室用同一套制作阶段覆盖各类商品。创作技能决定叙事规则：服饰专属规则仅用于服饰、鞋、包，其余商品使用通用制作流程。

## 操作顺序

1. **商品确认**：采集商品链接，或手动填写资料、补充商品图。直接选择本次需要的商品图，无需手工输入颜色；请选用同一款式、颜色的图片，外观以所选图片为准。确认商品时选择创作技能：服饰、鞋、包使用服饰专属规则，其余商品使用通用制作流程。该规则作用于随后的商品分析与口播；采集不会改写已选技能。
2. **口播脚本**：选择多模态模型，设置目标时长及画幅。默认 15 秒，可选 15、30、60 秒或输入 10–120 的整数。模型分析商品、编写口播和连续分镜，规划必要的人物、场景或关键帧；此阶段无需人物上传，也无需选择视频模型。服饰口播是导购：开场用场合带出第一条卖点，中段对着一个看点说穿着后果，收尾用另一条事实说明怎么穿。15秒全片写70–100个汉字，每一段按同样密度写满，5秒写23–33个字；标点、数字和字母不计。只报结构名称、停在问号上，或用精致、百搭、值得入收尾，都不算购买理由。事实仍限于看得见或资料里有的内容。
3. **素材图片**：选择绘图模型，检查素材设定后明确点击生成。人物、人脸及场景按脚本规划；人脸依赖同一人物，商品上身或手持画面带入所选商品图。图片逐张保存，局部失败只补缺失项。多模态模型查看实际图片，记录通过、冲突或无法判断；必要素材未通过时不能提交视频。
4. **视频定稿**：素材通过后，定稿页显示并允许更换写提示词的多模态模型，它与口播脚本是同一只。再选择视频模型、参考模式和分辨率。检查实际参考图数、精确时长、画幅和口播能力；不兼容时需要主动更换配置。这只多模态模型查看真实图片，按实际提交顺序编写完整提示词和分镜说明。更换它只要求重新定稿，不重写脚本、不删除已有图片。
5. **生成结果**：明确点击生成整段视频，只提交一个视频任务。分镜是整段时间轴，不是独立生成任务。历史逐镜任务仍可查询和查看。

## 商品图选择

- 完整图库和主图、规格图、详情图分类继续保留，选择和取消不会删除原图，也不会改变原始目录编号。
- 平台实际返回的规格元数据随缓存和商品存储往返保留。新采集商品不自动选图，由用户直接选择本次需要的图片。
- 图库提供“全部图片 / 已选 / 未选”和大图预览；缩略图下方及大图内均可选择或取消，无需填写颜色。
- 生成仅使用已选且可读取的图片。旧草稿已确认的图片和有效规格关联选择继续保留；首次直接调整选图时转为显式图片选择并清除旧颜色约束，避免与新选择矛盾。新接口同样检查允许编号和引用。
- 当前单次创作请求最多接受 40 张允许商品图，脚本最多 40 个分镜；超限明确报错，不静默丢图或截断分镜。完整采集图库不受此请求限制。
- 每张商品素材单独保存 `productImageIndexes`，使用允许且模型实际看过的商品目录原始编号，按目标正面、背面或局部选择，不再共用视频分镜的一组选图。缺失或不可用引用会在生图前阻断。旧计划没有该字段时，生图带入全部已选商品图，不把某个分镜的背面图当成唯一正面依据。
- 单张绘图只注入该素材的名称、提示词与有序参考用途，不混入整段分镜中的正反动作。前置人物或场景图只继承身份、空间和光线，商品外观以原图为准。模型按领口、门襟、口袋、接缝和标志位置区分正反；正面要求生成成背面、图案缺失或移位、多视图拼图均应校验冲突，无法辨认时保持待确认。这是多模态辅助校验，不能承诺生成模型绝不出错。
- 请选用同一款式、颜色的商品图。视觉校验只能提供辅助证据，无法判断时应保持待确认，不代表颜色和外观的绝对保证。

## 商品分析失败

口播脚本开始前，系统使用当前多模态模型分析所选商品图，商品颜色和外观以实际图片为准；兼容读取的旧草稿若有已确认颜色，也随分析传入。Claude 走 Anthropic 官方 Messages 接口（`/v1/messages`），配置里保存的旧兼容地址也会在发送前规范化到该接口。失败提示会区分缺少配置、图片无法下载或格式不受支持、鉴权失败、限流、服务不可用、调用超时、模型输出被截断、返回不是有效 JSON，以及没有可用卖点。商品分析与口播、定稿请求同一输出长度，避免完整 JSON 被网关默认上限截断；输出在对象闭合后仍被标为长度上限时，仍采用这份完整结果。多批图片会标明批次，汇总失败会单独标明。提示不包含密钥、图片地址、签名参数或模型原文。脚本生成使用包含 `deliveryMode`、`assets` 与正确字段类型的完整当前流程示例；解析时忽略不会使用的字幕设定，并将空字符串素材依赖视为空数组，其他不合法依赖仍拒绝。上游调用成功后的解析错误会区分 JSON 语法、脚本数量及具体字段类型，不能将调用成功等同于脚本可用，也不会自动重发模型请求。素材校验和视频定稿沿用同一套失败分类，并标明所处阶段。Claude、Gemini 的原生内嵌图片链路与 OpenAI 的 data URL 会先生成视觉输入副本：原图受 25 MiB、4000 万像素和单边 32768 的安全限制，副本等比缩放至最长边 2048、按需压缩至二进制不超过 4 MiB；保留原始素材、不裁切商品，JPEG 重编码时应用原图 EXIF 方向，避免丢失拍摄方向信息。OpenAI 远程 URL 继续原样透传，由上游获取，不转成大段内嵌数据；路径以 `.octet-stream` 结尾的地址会先下载，并按文件头转成 JPEG、PNG、GIF 或 WebP 的 data URL。整次模型请求仍受 32 MiB 限制。声明类型与字节不一致时，只要内容实际是 JPEG、PNG、GIF 或 WebP，就按字节格式制作副本；`image/jpg`、空类型和 `application/octet-stream` 同样以字节为准。下载远程图片时使用与页面预览相同的浏览器标识，并为淘宝、京东等图床带上对应来源页，不主动索取 AVIF，避免防盗链页面被当成不受支持的格式。连接中断时会优先改走 IPv4 再试一次；返回明确的 HTTP 错误则不再重试。损坏、伪造的非图片内容或超过安全上限的图片明确失败，不会静默丢弃。官方协议失败不会改成占位分析。

## 失效、费用和恢复

- 商品、所选图片、资料、时长或画幅改变后，旧方案标为过期；视频模型、视频参数或多模态定稿模型改变只使定稿过期，不删除有效图片。
- 脚本或素材设定改变后需重新校验和定稿。成功且输入一致的素材可复用；同一图片设定最多提交 3 次，已有回执的查询不增加提交次数。生成单张素材时只提交该素材及其尚未完成的前置依赖，不提交互不依赖的其他缺失素材；必要素材未齐时不会把局部结果当成整体校验通过。
- 图片齐备后可以点击“仅重新校验已有图片”，只调用多模态校验，不调用绘图模型、不重投生图任务；适合下载失败后的恢复。绘图参考超过 8MB、且不超过 25MB 时，提交前会生成不超过 8MB 的 JPEG 传输副本，不覆盖已保存图片。视觉校验本身仍可能产生模型费用。
- 已有图片或视频任务回执优先查询，不因刷新、停止或改配置重新提交。视频查询使用提交时保存的模型和输入快照。
- 停止操作只停止后续提交或查询，不能保证取消服务商已接受的任务。提交结果未知且无回执时阻止自动重投，应先核对服务端生成记录。
- 单项重新生图和再次生成已完成视频会提示费用。历史方案、成片和回执保留在结果阶段；清空商品仍需确认。
- 旧草稿可读取，旧提示词需重新定稿，缺少参考图选择时需补选。模型调用遵循现有模型路由与凭据配置。

## 布局

桌面商品面板默认 480px，分隔线可拖动或用方向键调整，Shift 加大步长，Home / End 到边界，并记忆宽度。进入后续阶段后，商品资料默认收为摘要，可按需展开编辑。窄屏沿用同一套五步导航，只显示当前阶段内容；编辑商品后可返回原来的创作阶段。素材图片按该图实际宽高比显示，高度不超过预览上限，不把画面拉满卡片、也不预留两侧空白。

全页底部只有一个阶段主操作区，依次引导编写脚本、确认素材、定稿和生成。有效定稿后，付费生成成为主操作，重新定稿为次操作；定稿不会自动提交视频。缺少资料、方案过期、提交被阻断和任务恢复的原因直接显示在操作区附近。

创作技能放在创作设置最上方并常显。品牌在商品资料中直接显示，采集属性不放在商品确认页；价格不展示，口播也不出现价格或金额。图库分批展开，保留完整预览及直接选图。商品确认页不展示采集来源说明。脚本以口播和画面时间轴为主，绘图提示词默认收起，失败及冲突素材的编辑区自动展开。视频定稿的完整提示词直接展开为纯文本，并按提交顺序标出实际参考图。结果区区分提交、查询、未知和失败，有回执时明确提供仅查询入口。

“带货规则”只展示已接入的服饰专属规则，概览为单张紧凑卡片。查看详情在当前弹窗内切换到技能正文，顶部可返回，并保留完整技能原文阅读与 `SKILL.md` 复制。创作设置仍可选择通用制作流程，非服饰品类继续使用该流程。工作台和弹窗均支持浅色、深色及键盘焦点。
