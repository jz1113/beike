# 电商视频

当前工作室仅接入服饰专属技能，适用于服饰、鞋、包。新项目默认服饰技能及“人物讲解”呈现方式；创作设置与规则弹窗展示同一项真实可用技能，不提供未接入的通用技能。历史其他品类方案仍可查看和查询原任务，继续创作前需明确选择服饰技能并更新脚本；不自动改写历史商品及方案。

## 操作顺序

1. **商品采集**：采集商品链接，或手动填写资料、补充商品图。采集成功后商品名称、品牌和采集属性作为只读资料展示，不提供商品名称编辑入口；采集只保存商品资料，不调用商品分析模型。手动上传商品图片的流程保留商品名称输入，仍需填写名称后继续生成。直接选择本次需要的商品图，无需手工输入颜色；请选用同一款式、颜色的图片，外观以所选图片为准。创作技能仅提供服饰专属规则，适用服饰、鞋、包；其他品类暂未接入。该阶段只负责准备商品事实、SKU 和参考图。
2. **卖点与脚本**：选择多模态模型，设置目标时长及画幅。模型先查看商品图并提炼卖点、已知事实和信息点，再生成一套完整脚本：包含口播台词、连续分镜、每镜画面提示词和所需素材清单；也可在选图后手动预览商品分析，输入未变时写脚本会复用该结果。口播是脚本的一部分，不单独作为一个制作阶段。此阶段无需人物上传，也无需选择视频模型；服饰口播仍遵循现有字数、事实和口型规则。
3. **素材补齐**：选择绘图模型，按脚本清单生成缺少的人物、场景或关键帧。商品上身或手持画面直接引用所选商品图，不为同一商品机械建立平铺图到上身图的串行依赖。图片逐张保存，局部失败只补缺失项。单条制作默认人工看图，点击“图片无误，确认并继续”后进入视频生成；必要图片未齐或未确认时不能提交视频。
4. **视频生成**：素材通过后，选择视频模型、参考模式和分辨率。系统使用同一多模态模型查看已确认的真实素材，把脚本中的分镜提示词与真实素材合成为完整视频提示词；检查参考图数、精确时长、画幅和口播能力后，再单独确认并提交整段视频。提示词合成和视频提交仍是两个明确动作，避免误触产生计费任务。
5. **生成结果**：查看整段视频任务、查询状态和成片。分镜是整段时间轴，不是独立生成任务；历史任务仍可查询和查看。

## 工作区导航与任务恢复

- 页头不展示编号步骤条，工作区直接展示当前内容。底部主操作推进制作，返回入口按当前内容提供：脚本页头返回商品资料、素材页底部返回脚本、视频页头返回素材、结果页底部返回视频。已有任务或成片时，页头提供“查看生成结果”。历史方案入口在工作区顶部，执行任务期间暂不可切换方案。
- 重新生成脚本或视频提示词合成失败、取消时保留当前查看阶段，已有内容仍可查看。生成视频期间切换查看阶段，底部仍提供停止入口；停止不取消服务商已经接受的任务。
- 素材页分别展示已生成、已确认、必需素材和失败数量。已有图片任务回执时优先继续查询，无需重新选择绘图模型，也不会重新提交；单张查询只查询对应素材。方案过期不影响查询原图片任务。
- 图片提交结果未确认且没有回执时，显示待核实并阻止直接重投；参考图在创建任务前被明确拒绝的素材可修正后重试。成功查询后，再单独补齐缺失素材或确认图片。

## 出镜说话与口型

台词仍保存在 `voiceover` 字段，声音来源单独由每段 `speechMode` 指定：`on_camera` 表示画内人物现场说话，`voiceover` 表示明确的画外音。新服饰脚本必须输出该标记。创作设置与底栏统一使用“呈现方式”，提供“人物讲解”（默认）和“商品展示＋旁白”两项；后者由脚本安排商品、手部、背影或不露脸上身展示。旧的手部或背影展示、商品混剪统一显示为“商品展示＋旁白”，保留已保存的原始模式值及方案签名，不因打开页面而改写历史方案；主动切换呈现方式时继续通过原有参数绑定更新脚本。人物讲解必须包含出镜说话分镜，开场与收尾优先说完整短句；纯商品、手部或背影脚本仍可使用画外音，不强加人脸。时间轴展示声音来源，可展开逐段修改；改动进入视频提示词内容签名，旧提示词失效，需要检查素材并重新合成。旧脚本未标注时可查看，界面显示“声音未标注”；继续创作需更新脚本，禁止自动推断声音来源。

出镜段需要同一人物头顶至腰部或大腿的正面或轻微侧面中景素材，嘴唇完整、清楚且无遮挡；静帧不写台词，也不靠夸张张嘴生成口型。人工确认时检查讲解帧的嘴部条件，无法确认则先更新素材。视频提示词和固定提交前言明确由画内人物亲口说出，中文发音、唇形开合、下颌与起止逐字同步，停顿自然停嘴，转身、换装或遮嘴动作放在句间。画外音段沿用同一人声线，画内人物不开口。已标声音来源的分镜若在完整或分段提示词中遗漏、改写台词原文，视频提示词合成直接失败，不自动补写模型结果。

实拍感通过可执行的节奏控制：稳定手机机位或轻微手持，每句一个简单展示动作，自然眨眼、呼吸、轻重音及视线变化；避免播音腔、持续微笑、磨皮、匀速摆拍、无目的运镜和慢动作口播。视频请求继续开启原生音频，但音频支持和人工静帧确认不能保证最终口型。成片预览需听看人物是否实际开口、逐字同步、停顿停嘴和转身前说完；返回视频仅表示任务完成，不代表口型已通过，不自动重投付费任务。

## 服饰景别与运镜

商品分析、脚本、素材计划和视频提示词合成统一默认中景、中全景或全身展示，保留整件商品及穿搭比例。运镜优先固定机位或保持相同距离的小幅横移、轻微跟拍；不默认推近、变焦、数码裁切放大，也不让人物或商品主动贴近镜头。讲领口、面料、刺绣等事实时，用正常距离的手势或姿态展示，不机械插入局部、微距或 logo 特写。旧兼容字段 `product_closeup` 在服饰流程中表示商品展示方式，不要求字面上的近景。

出镜说话使用头顶至腰部或大腿的中景，完整头部、嘴部与主要服装同时入画；通过清晰素材、无遮挡和正面角度兼顾口型，避免为看嘴部而放大人脸或胸前商品。人脸参考用于身份继承，局部商品原图用于事实对照，均不代表成片采用其裁切。logo、小字和五金保持原图位置与自然比例，不要求逐字可读，不改字、删标或人为模糊。中景里标志小不等于错误，有证据的缺失或移位仍须校正；无法判断必要外观时仍待确认。

重新合成视频提示词会将旧近景、特写或推近改成正常距离的展示动作，保留原台词、声音来源和时间轴；实际素材只有局部、无法支撑中景时需先补充素材，不虚构画外结构。已有草稿、图片、成片和任务回执保留，不自动重生成或产生付费任务。

## 服饰实拍表演与连续性

未明确开箱且无必要换装时，服装默认采用直接上身的生活穿搭；已明确选择的开箱、生活穿搭或鞋包展示保留。默认固定手机机位，变化来自人物有目的的展示，不通过故意晃动、失焦、曝光抽动、噪点或粗糙肤质模拟真实。先准备同一人物在目标空间穿着或拿着商品的可用讲解帧，空景、人脸和其他视角按脚本需要增加。

每个语义段围绕一项可见事实安排一个主要动作，写明起始姿态、接触部位、结果与收势。手先接触才带动衣料，松手后按材质和重力回落；脚先承重再换重心，避免脚滑、穿模与衣物无故飘动。嘴部无遮挡时可边说边做小手势，大幅低头、转身和换装仍放在句间。半拍是自然换气，不能让每句都等长停顿或逐字拖腔。

分镜表示语义时间段，不要求每段都切镜；同一固定机位可连续覆盖多个段落。短片压缩展示目的和动作数量，不照搬长参考片的多款、多色、换装和全部手势。参考片分析记录文件与时间点，区分实际观察、设备与光位推断、未听辨的声音项目。背景差分只给剪辑候选，声音频谱不能证明台词、语速或口型。提示词规则不等于程序已检测动作质量；必须用实际成片复核。

比较优化效果时先固定 SKU、时长、画幅、模型和参考图，只更换提示词；再单独比较素材改进。模型支持且已提供种子时可沿用，不虚构种子或声称随机性已消除。按商品与身份、接触与承重、背景稳定、表情节奏及口型记录问题秒数；付费对比生成需要用户明确要求，不能把技能更新当作成片质量已提高。

## 服饰人物选角

服饰人物选角统一设定为东亚成年人，人物、人脸、上身图和视频沿用同一身份及具体年龄；每张有人物的素材名称和提示词写明选角。优先遵循明确的成年目标人群，再综合版型、风格与场合选年龄：潮流校园感可参考18–25岁，简约通勤25–35岁，成熟商务30–45岁，成熟人群款40–60岁，明确银发定位55–70岁。区间允许交叉，只是选角建议；宽泛基础款且无人群线索时采用约30岁的中性选角，不仅凭品牌或颜色判断。童装用成年讲解者手持或静物展示。确认时检查身份及外观年龄是否一致；不凭人脸确定真实族裔或精确年龄。旧素材保留，修改设定后需按需重生成、确认及定稿，不自动提交付费任务。完整规则见 [服饰带货技能](../.agents/skills/fashion-video-sales/SKILL.md)。

## 商品图选择

- 完整图库和主图、规格图、详情图分类继续保留，选择和取消不会删除原图，也不会改变原始目录编号。
- 平台实际返回的规格元数据随缓存和商品存储往返保留。新采集商品不自动选图，由用户直接选择本次需要的图片。
- 图库提供“全部图片 / 已选”和大图预览；点击图片即可选择或取消，卡片内的放大镜独立打开大图；有颜色 SKU 时可用颜色快捷项一次选择同色图片，无需填写颜色。
- 生成仅使用已选且可读取的图片。旧草稿已确认的图片和有效规格关联选择继续保留；首次直接调整选图时转为显式图片选择并清除旧颜色约束，避免与新选择矛盾。新接口同样检查允许编号和引用。
- 当前单次创作请求最多接受 40 张允许商品图，脚本最多 40 个分镜；超限明确报错，不静默丢图或截断分镜。完整采集图库不受此请求限制。
- 每张商品素材单独保存 `productImageIndexes`，使用允许且模型实际看过的商品目录原始编号，按目标正面、背面或局部选择，不再共用视频分镜的一组选图。缺失或不可用引用会在生图前阻断。旧计划没有该字段时标记过期，需更新脚本；不自动猜测或带入全部已选图。
- 单张绘图只注入该素材的名称、提示词与有序参考用途，不混入整段分镜中的正反动作。前置人物或场景图只继承身份、空间和光线，商品外观以原图为准。模型按领口、门襟、口袋、接缝和标志位置区分正反；人工看图需核对正反视角、图案缺失或移位、多视图拼图，无法辨认时先补充素材再确认。
- 请选用同一款式、颜色的商品图。人工确认不代表生成模型能绝对保证颜色和外观，成片仍需复核。

## 商品分析失败

口播脚本开始前，系统使用当前多模态模型分析所选商品图，商品颜色和外观以实际图片为准；兼容读取的旧草稿若有已确认颜色，也随分析传入。Claude 走 Anthropic 官方 Messages 接口（`/v1/messages`），配置里保存的旧兼容地址也会在发送前规范化到该接口。失败提示会区分缺少配置、图片无法下载或格式不受支持、鉴权失败、限流、服务不可用、调用超时、模型输出被截断、返回不是有效 JSON，以及没有可用卖点。商品分析、口播、选图与定稿请求统一显式设置输出预算，避免完整 JSON 被网关默认上限截断；输出在对象闭合后仍被标为长度上限时，仍采用这份完整结果。多批图片会标明批次，汇总失败会单独标明。提示不包含密钥、图片地址、签名参数或模型原文。脚本生成使用包含 `deliveryMode`、`assets` 与正确字段类型的完整当前流程示例；解析时忽略不会使用的字幕设定，并将空字符串素材依赖视为空数组，其他不合法依赖仍拒绝。上游调用成功后的解析错误会区分 JSON 语法、脚本数量及具体字段类型，不能将调用成功等同于脚本可用；普通解析错误不自动重发模型请求。视频定稿沿用同一套失败分类，并标明所处阶段。Claude、Gemini 的原生内嵌图片链路与 OpenAI 的 data URL 会先生成视觉输入副本：原图受 25 MiB、4000 万像素和单边 32768 的安全限制，副本等比缩放至最长边 2048、按需压缩至二进制不超过 4 MiB；保留原始素材、不裁切商品，JPEG 重编码时应用原图 EXIF 方向，避免丢失拍摄方向信息。OpenAI 远程 URL 继续原样透传，由上游获取，不转成大段内嵌数据；路径以 `.octet-stream` 结尾的地址会先下载，并按文件头转成 JPEG、PNG、GIF 或 WebP 的 data URL。整次模型请求仍受 32 MiB 限制。声明类型与字节不一致时，只要内容实际是 JPEG、PNG、GIF 或 WebP，就按字节格式制作副本；`image/jpg`、空类型和 `application/octet-stream` 同样以字节为准。下载远程图片时使用与页面预览相同的浏览器标识，并为淘宝、京东等图床带上对应来源页，不主动索取 AVIF，避免防盗链页面被当成不受支持的格式。连接中断时会优先改走 IPv4 再试一次；返回明确的 HTTP 错误则不再重试。损坏、伪造的非图片内容或超过安全上限的图片明确失败，不会静默丢弃。官方协议失败不会改成占位分析。

## 输出截断恢复

- 各文字阶段默认允许最多 16384 个输出 token，并要求紧凑 JSON，减少重复说明，保留完整字段、分镜、素材、口播和精确时长。预算是上限，不代表每次都会消耗完。
- 只有上游明确返回长度上限且 JSON 对象不完整（包括正文为空）时，自动重新生成一次完整结果，预算最多提高到 32768。恢复保留原始事实和图片，不拼接残缺 JSON，不缩短口播或静默丢弃分镜；恢复后仍执行原有时长、素材依赖和图片编号校验。
- 若服务商以 HTTP 400/422 明确说明输出参数超过其上限，则按返回的明确上限调整一次。已确认的较小上限继续用于恢复，不反复请求超限额度。上下文不足、普通解析失败、鉴权、限流、网络故障和超时均不触发此恢复。
- 初次调用与自动恢复共用五分钟等待期限，停止会中断后续恢复。截断恢复可能额外消耗一次文字模型费用，成功响应累计本次各次调用的 token；多批商品分析也累计全部批次与汇总。该机制仅用于文字结果，不自动重新提交图片或视频生成任务。
- 恢复后仍截断时，提示具体失败阶段，并建议缩短目标时长或切换支持更长输出的模型。

## 失效、费用和恢复

- 商品、所选图片、资料、时长或画幅改变后，旧方案标为过期；切换视频模型、多模态提示词模型、参考方式或清晰度时保留已有有效提示词、脚本和图片，不再强制重新生成提示词。模型切换引起的参数自动调整同样遵循此规则；配置不兼容时阻止视频提交，并提示具体配置原因，不将提示词误标为过期。已经过期或未完成的提示词不会因切换模型被重新认可。
- 脚本或素材设定改变后需重新确认素材并更新视频提示词。素材页提供绘图模型选择和各素材绘图提示词编辑。修改提示词或重生成前置图片后，依赖素材必须更新后才能确认；已有图片和未完成的回执保留供核对。成功且商品参考编号、前置素材和提示词均一致的素材可复用；同一图片设定最多提交 3 次，已有回执的查询不增加提交次数。生成单张素材时只提交该素材及其尚未完成的前置依赖，不提交互不依赖的其他缺失素材；必要素材未齐时不会把局部结果当成整体确认完成。
- 素材必须人工看图确认；历史自动校验通过的标记不能代替本次人工确认。旧 `validate-assets` 操作返回 HTTP 410，不调用模型。绘图参考超过 8MB、且不超过 25MB 时，提交前会生成不超过 8MB 的 JPEG 传输副本，不覆盖已保存图片。人工确认不调用模型。
- 已有图片或视频任务回执优先查询，不因刷新、停止或改配置重新提交。视频查询沿用提交时的模型和渠道，并携带原输入快照。图片和视频付费提交前先把稳定提交标识写入本地项目并确认可读回；保存失败则不会提交。批量生图逐项沿用模型专属渠道凭据，并按素材 ID 对齐结果，缺项或重复结果标为待核实，不把其他素材的图片误配过来。响应丢失后按该标识核对服务端记录，找到任务后再查询，不会另建计费任务。
- 停止操作只停止后续提交或查询，不能保证取消服务商已接受的任务。提交结果未知且没有提交标识时阻止自动重投，应先核对服务端生成记录。当前流程不再新建逐镜视频；历史逐镜结果只可查询、播放和下载，不新建逐镜任务或自动拼接；旧拼接地址返回 HTTP 410。
- 单项重新生图和再次生成已完成视频会提示费用。历史方案、成片和回执保留在结果阶段；清空商品仍需确认。
- 旧 v2 草稿继续读取。旧人物／人脸／场景上传、静帧提示、字幕和数字人参数归档至 `historicalData`，保留原素材与回执，不参与新创作。旧提示词需重新定稿，缺少声音来源或商品素材参考编号时需更新脚本，缺少参考图选择时需补选。模型调用遵循现有模型路由与凭据配置。

## 布局

商品采集阶段采用 42% / 58% 的等高双栏，工作区填满页头与底栏之间的剩余高度。左侧依次放商品链接、完整名称、当前 SKU 与商品规格、参考图库；采集名称保留原文并自动换行，只读展示且不标记“必填”；手动上传流程保留名称输入框及必填提示，下方仅展示当前 SKU 及颜色、尺码等对应规格，不展示材质、版型等通用参数。原始采集属性继续保留，用于卖点提炼与脚本生成。未关联 SKU 的主图、详情图不会清空采集身份；SKU 优先取结构化数据，旧记录可从京东链接或明确的 SKU 查询参数补读。规格优先取当前 SKU 与采集属性，仅对已采集商品使用标题末尾明确的颜色和尺码作展示兜底，不回写商品参数；切换到其他 SKU 时不沿用原 SKU 的标题规格。链接与图库标题固定，商品资料和图库各自滚动；图库支持只看已选、上传、清空重选及大图预览，未选图片降低透明度与亮度，悬停或选中时恢复。右侧只显示可编辑的脚本卖点及提炼依据，卖点按双列卡片展示，依据和场景通过标签页切换并独立滚动。窄屏改为上下排列，保持商品资料和卖点均可访问。

后续创作阶段沿用可记忆宽度的商品摘要侧栏，分隔线支持拖动、方向键、Shift 加速和 Home / End。全页不显示顶部步骤条；页头提供返回与结果入口，编辑商品后可返回原来的创作阶段。素材图片按该图实际宽高比显示，高度不超过预览上限，不把画面拉满卡片、也不预留两侧空白。

全页底部只有一个阶段主操作区，依次引导生成卖点与脚本、补齐素材、合成视频提示词和生成视频。提示词合成与付费生成保持两个明确动作；商品名称为空时，主按钮禁用，原因通过悬停或键盘聚焦提示；其余方案过期、提交阻断和任务恢复原因仍显示在操作区附近。时长通过 15 / 30 / 60 秒和自定义分段按钮选择，自定义时才出现数字输入；采集完成后的采集按钮及提炼完成后的重新提炼按钮降为次级样式，已就绪的阶段主操作使用琥珀色。

视频生成阶段的提示词模型、视频模型与参数统一放在底部工具栏，窄屏可展开设置。右侧不再重复展示阶段说明和素材列表；完整提示词内的图片编号显示为带缩略图的 @图片 标签，可打开对应原图，编号与实际提交顺序一致。复制、编辑及提交保留原始提示词文本，未绑定的图片编号保留原文。

创作技能放在创作设置最上方并常显。商品资料沿用原有参数清理规则，价格不展示，口播也不出现价格或金额。图库默认完整展开，在左侧滚动区域中直接选择，保留完整预览及独立放大镜。卖点与脚本阶段以商品分析、口播和画面时间轴为主，绘图提示词默认收起，失败及冲突素材的编辑区自动展开。视频生成阶段展示合成后的完整提示词，并按提交顺序标出实际参考图。结果区区分提交、查询、未知和失败，有回执时明确提供仅查询入口。

“带货规则”只在页头保留一个入口，商品设置保留一次紧凑规则说明，空状态不再重复展示。弹窗只展示已接入的服饰专属规则，概览为单张紧凑卡片。查看详情在当前弹窗内切换到技能正文，顶部可返回，并保留完整技能原文阅读与 `SKILL.md` 复制。创作设置只列服饰专属规则；历史其他品类显示待选择状态，查询已提交任务不受影响。工作台和弹窗均支持浅色、深色及键盘焦点。

## 等待、续做与前置检查

分析和脚本按输入保存阶段结果，后续失败重试只继续未完成阶段。分析结果记录商品事实与所选图片的签名；修改商品、卖点、属性或选图后不复用旧分析与旧脚本检查点，只改时长或画幅可复用有效商品分析。没有已选图时不发起分析，不再自动使用图库前四张图。只选一张商品图时直接匹配，不额外调用选图模型。多图上传最多并行3张，部分失败保留成功项，只需补传失败图片。商品大图支持上一张、下一张及左右方向键；当前创作步骤随草稿保存，刷新后恢复到原步骤。

运行时显示已等待秒数，生图显示已生成数量，不同时显示待生成的静态拦截提示。采集、上传、脚本、素材、提示词和视频查询均有停止入口；停止会中断本次等待，不能保证取消服务商已接受的任务。生图停止后保留提交标识，按原标识核对回执，不重新提交。

创作设置提供可选成片模型预检，在生图前提示已选模型的时长、画幅和声音不兼容；仍可到视频阶段再选择模型。结果区错误集中显示一次，并显示可复制的提交标识、上游任务ID和原提交模型，便于核对。

没有上游任务ID的未知提交，结果区以待核对卡片说明情况，原始诊断收在“技术详情”中。若在渠道后台按提交标识找到了任务，可填入上游任务ID，经 `POST /api/generate/video/bind` 绑定到原记录后继续查询；该接口只接受仍为未知且没有任务ID的记录，不重新提交。人工向渠道明确核实没有创建任务后，可直接在卡片中另建待提交草稿；原未知记录、脚本和提示词仍保留在历史中。这一步不提交视频，后续仍需单独点击生成。有上游任务ID时不提供这两个入口，只查询原任务。

脚本要求使用效果有商品资料的明确依据，不能由罗纹、材质比例或图片外观推断“不闷”“不往上滑”等实测结论。界面对未在所提供资料中出现的常见体验断言给出人工核实提醒，不静默替换口播。

## 提交诊断

渠道端点、字段映射与素材上限统一见[视频生成接入](视频生成模型调用参考.md)，图片传输与协议见[图像接入](生图与图像编辑模型调用参考.md)。工作室保存脱敏失败原因、上游 HTTP 状态与端点尝试数，按原提交标识查询时继续返回原原因。首个端点的提交等待上限为 180 秒，后续端点 20 秒，避免慢响应渠道被误判为未知。5xx、网络故障或成功响应缺少任务 ID 仍视为未知，不据此自动重投。历史未知记录不能补造当时没有保存的诊断。
