# 电商视频工作台

首页侧栏的「资产库」（`?view=asset_library`）和电商视频顶部的「打开资产库」进入同一套文件夹与素材卡片。分镜中的人物、场景、声音和动作快捷入口会打开相应文件夹。首页资产库预览中可选用素材。从制作页进入时，也可在有对应工作区记录的卡片上直接点击「用于视频制作」并返回分镜。「动作」按脚本列卡，每条脚本只出现一次；「人物」「场景」仅显示图片，「声音」仅显示音频。画布也从同一份素材索引取用媒体。

右上角工具随文件夹切换。动作分类提交视频后调用「参考视频拆解」；人物和场景分类支持单项生成、批量导入图片和导入文件夹，子分类作为初始人物分类或空间分类。各分类的「技能设置」与电商视频提示词管理共用当前工作区的同一份配置。

「设置 → 资产库」提供两个独立的工作区开关：首页侧栏入口默认显示，跨工作区共享默认关闭。隐藏入口后仍可从设置中恢复。开启共享后，工作区向其他参与工作区提供素材，也可以搜索它们的素材。关闭开关会停止新的对外共享和导入，已加入的副本继续可用。点击「加入我的工作区」后即可在制作时选用。共享范围包括人物、场景、动作、人声、配乐和已确认脚本。加入时保存独立副本，同时复制素材引用的本地媒体；重复加入会复用已有副本。来源工作区管理原件，后续编辑各自独立。生成历史、商品草稿、提示词配置和本机资产按原范围保存。

视频制作沿用浅色与深色灰阶主题、48px 顶部导航及「商品资料 → 分镜脚本 → 生成成片」流程。桌面左侧商品区默认宽 560px，可拖动分隔线调整，已有宽度偏好继续生效。右侧文字阅读宽度最大 936px。图库与文字区各自滚动，商品资料阶段左右底部操作栏均为 72px，正文保留底部留白。商品卡只展示缩略图、两行省略的名称及规格/分类/受众摘要；「商品设置」使用居中弹窗，名称支持多行编辑，品类与适用人群并排展示，修改即时生效。SKU 等商品详情与来源折叠收纳，更新采集与换商品链接集中放在商品操作区，清空商品独立放在底部并沿用确认流程；窄屏或低高度窗口只滚动弹窗正文，保持关闭和完成操作可见。图库随可用宽度显示两至四列，统一 4:5 缩略图并完整显示原比例图片。

- **① 商品资料**：左侧选择参考图，右侧固定为「商品卖点」工作区，标题旁显示待识别、待提炼、已提炼或处理进度。商品图未选时以原亮度显示，选作参考图后压暗并显示序号。青绿色 OCR 标记表示已加入识别队列。右侧上方显示识别图片，下方用一个文本框编辑补充资料和当前队列的识别文字。提炼完成后原文收纳到默认折叠的「查看识别原文」。参考图与 OCR 图片独立保存，原始识别文字、用户修订及最终卖点分别保留。右侧底栏从左到右为模型选择、OCR 识别、文字样式的「跳过，进入分镜」和主按钮「提炼卖点」；模型与 OCR 组成工具组，窄栏分两行显示。没有识别图片时 OCR 位置提供「添加详情图」，全部识别完成后显示禁用的「OCR 已识别」，新增图片后可继续识别。提炼成功后后两项变为「重新提炼」和主按钮「下一步：分镜脚本」。任务说明只在工作区显示。
- **② 分镜脚本**：左栏为分镜编辑表格（`# / 商品图 / 时间·镜头 / 画面动作 / 台词 / 字幕 / 姿态 / ⋯`）。单元格直接编辑画面动作、口播台词（实时显示字数、语速及 `> 4.5 字/秒` 偏快橙色预警）与 SRT 字幕草稿，表情与段落衔接收纳在行尾 `⋯` 展开区；点击商品图或姿态格弹出更换选单（支持 `正 / 斜 / 侧 / 俯 / 仰` 多机位预览）。右栏选择脚本、人物、场景、声音和动作参考，调整成片参数、选择改写模型并进入下一步。尚未选图时，底部提供商品图库。在分镜页确认选图后，图库和缩略栏一起隐藏。点击「下一步：准备成片脚本」后，按钮先显示分镜核对或改写进度，再显示成片脚本准备进度。已有自动稿或手工稿会保留，需要时可主动重新改写。
- **③ 生成成片**：左侧播放器按画幅显示视频，支持导入、版本切换和下载，待生成时可预览本次商品参考图，右侧可分段阅读和复制实际生成提示词。底栏左侧按 1、2、3 的顺序标记素材，缩略图随数量和可用宽度紧凑排列。右侧选择模型和最终 BGM，并提供「生成视频」与「音频视频核查」。

单选、批量选图或切换商品规格后，浏览器自动用本地 BlazeFace 检测所选商品图的人脸并生成马赛克副本。选图库预览、渠道校验和视频生成使用同一张副本，无人脸的图片沿用原图。自动处理无需逐张确认，失败可点击「重试打码」。需要补框或避开眼镜、耳饰时，点击选图区「调整人脸打码」或成片素材区「商品图人脸打码」，选择对应图片、调整范围并应用。人物参考图（包括兼作商品参考的同一张图）保留原貌。草稿保存每张图的框选和副本地址，OCR 仍读取原商品图。模型和 WASM 随前端部署，检测无需 API Key。[BlazeFace 全距离模型（固定版本）](https://storage.googleapis.com/mediapipe-models/face_detector/blaze_face_full_range/float16/1/blaze_face_full_range.tflite)

视频预览在实际载入可播放画面后才显示就绪；载入失败会区分后台服务不可用、访问过期、文件失效和格式问题，并可原地址重试加载。音色与配乐统一使用可重试的试听播放器，切换声音重置播放进度，多个音频试听互斥。远程音视频通过流式代理读取，保留分段请求及长度信息，单次响应上限 200 MiB；本地音频按实际扩展名返回音频类型，支持浏览器读取时长和拖动进度。
- 编辑标签切换只改变可见内容，保留制作控制器、草稿及进行中的请求。任务期间进度和停止等待入口跨编辑标签可见，暂时锁定换商品、选图、返回首页、进入模型设置及切换到资产库；任务结束或停止等待后恢复。返回视频制作时刷新脚本和素材目录，清理已删除资产的失效引用，保留上传文件、分镜编辑与生成结果；资源读取与生成任务的取消和状态独立管理。

## 后台任务记录

顶栏「任务记录」汇总当前工作区的视频分析、生成、合成及人物和场景资产任务。可按提交日期、类型、模型渠道和状态筛选，按任务编号、上游编号、名称、模型或错误搜索，并按页浏览。点任务名称展开模型、素材、失败原因和结果预览。失败或部分完成的视频任务沿用原任务入口继续处理。打开记录期间每五秒刷新。耗时优先从实际开始时间计算，缺少开始时间时使用提交时间；费用与未记录的进度百分比不作推算。

## 后台任务与成片交付

制作页右上角的「后台任务」显示当前工作区最近 100 项参考分析、视频生成和混音记录。文件上传并收到服务端存储地址后，再提交处理请求。收到 HTTP 202 和任务编号即可关闭页面；批量队列中尚未上传或提交的其他文件仍需保留页面。后台固定本次输入、已保存的分析提示词和渠道，单 API 进程最多同时执行 2 项媒体任务，最多接收 32 项执行中或排队任务。人物与场景补图沿用独立资产任务区。

视频接管后在服务端查询原渠道任务，获取结果后解码并保存到工作区，检查视频尺寸、请求时长和所需音轨，再发布可下载的 MP4。相同输入的活动请求共用一个任务。源媒体可按内容验证时，可以复用已归档的原片。网络故障、下载失败和服务中断时，继续原任务先核对已有渠道回执。取消已提交的视频只停止后续等待与处理。重启后中断记录在任务中心显示，手动重试时使用相同渠道，API 密钥不保存在媒体任务表中。

配音、选择配乐与合成仍有各自的确认操作；提交合成后由后台执行 FFmpeg。旁白超过有效画面时间窗时返回两者的实测时长，保留原片和配音供调整。字幕仍可单独导出 SRT，镜头时间属于脚本时间窗。成片不会将脚本时间窗标为音频实测时间戳。

## 提示词管理

「电商视频 → 提示词管理」通过七个入口管理十一套提示词。商品文案下是「商品卖点提炼」；分镜脚本下是「参考视频拆解」「商品分镜改编」「口播设置」。口播设置分为编写和验收。视频生成下的「最终视频生成」分为纯分镜版和深度视频版。资产生成下的「人物生成」「场景生成」分别提供绘图和补图。每个子项有独立的保存状态，点击子项即可切换。每个环节可复制、编辑和保存；默认直接使用本次发布的最新模板。补图模板需保留布局和视角顺序以配合裁切；最终模板需保留摄影、声音、素材和分镜资料占位符。读取、保存失败或版本冲突时标记待核对，保留编辑并重新读取；保存回执必须与提交的环节和正文一致。切换提示词环节或返回视频制作会保留未保存修改，离开整个工作台前确认放弃；从未编辑的初始模板不触发离开确认。

保存到当前工作区后，下一次执行对应环节使用保存的提示词，刷新、重新打开或重启后端后仍可读取。自定义编辑只在当前模板版本内有效；发布新版时，该环节自动切换并清除旧稿。已有文案、脚本、分镜和已提交的图片任务继续保留；要按新规则生成结果，需要手动再次执行。人物与场景视角任务在首次提交时固定提示词及版本，继续查询原任务、重试裁切或恢复缺失裁片不会重新生成。

带口播或旁白的分镜自动改写前，核对商品改编、口播适配与语义验收规则。后台缺少相应环节时提示重启服务；环节被明确停用时，可从错误提示点击「去配置提示词」直达该项，保存后返回原分镜重试。进入配置前保存当前商品草稿，配置页不自动执行改写，也不替换原分镜或手工修改。

每个环节只显示一份当前正文，读取和执行使用相同版本。新版拆解在主体和衔接中记录开合、连接、接触的初始与结束状态；视频模板约束拉链、扣件等由对应的可见操作改变，避免把向外撑或双手合拢直接变成开合。此为可编辑生成规则，不能替代成片逐帧验收。

背景成像规则也通过可编辑模板维护：两种最终视频模板要求人物、商品与场景统一透视、光照、曝光及环境反射，中景和全身展示优先保留邻近空间可辨，失焦按物距连续变化，避免沿人物轮廓整层糊化。原片的浅景深是待适配观察，人物、商品参考图的棚光或背景虚化不作为本片摄影依据；深度视频的前背景分区仅用于动作定位，不作抠像或散焦蒙版。场景绘图及补图的空间全景保留前中后景结构与材质，局部近景可有自然景深。拆解将可见的轮廓突变、光边和纹理涂抹列为待核实缺陷。发布后新任务自动使用更新后的模板。

新增人物先用图片理解模型从上传参考图反推外观、实际妆容、发型和衣着，提示词采用 iPhone 前置自拍、滑动变焦取景和自然光的摄影描述。生图模型同时接收该描述、原始参考图和已保存的「人物补图 · 三视图」，只生成一次。白底电商横幅按一行四列依次展示正面全身、左侧 90 度全身、背面全身及正面脸部特写。三张全身照统一机位与脚底基线，保留年龄、身形与自然皮肤纹理。新任务直接使用同步后的人物模板。

视频生成的肤质规则由两套最终模板明确执行：保留当前人物的年龄、妆容、肤色与身份，补图不覆盖主图肤质，皮肤细节与部位、年龄和景别相符，转头及说话时纹理、高光连续；不继承原片美颜、磨皮和抹平肤质的柔焦，也不靠新增毛孔、皱纹、瑕疵或噪点制造真实感。拆解将原片处理与柔和照明分开记录，改编不把处理观察转成目标肤质。摄影事实仍保留来源描述供已保存模板解释，程序不暗中删词或追加规则。重新生成即可使用新版；若主图本身已缺失自然细节，应先检查并更换或重新生成人物主图及补图，不能承诺视频能恢复真实纹理。验收需对照原主图、补图和新成片的同景别画面，不能仅凭远景看不到毛孔判断磨皮。

提示词是完整的当前环节指令，参考视频拆解只需填写逐镜分析要求，应用内调用随视频传入分镜 JSON 字段。其他文案和脚本模板需保留对应 JSON 输出结构。商品资料、原视频和参考图以数据另行加入，程序不在执行时追加摄影、身份、动作、声音或负面创作规则。最终视频模板按人物、道具、商品、场景、可选的深度视频、情绪风格、分镜顺序编写。人物、商品、场景、深度素材分别使用 `personaFacts / productFacts / sceneFacts / depthFacts`，兼容原合并素材块 `referenceFacts`。摄影与声音资料在开头展开，`timelineFacts` 在文末填入真实分镜；管理页阅读时按选择的声音模式显示中文模板，有制作脚本时在下方预览其画面分镜；仅替换原模板占位，不递归解释资料内文本。不配置、缺块或未知占位会停止生成。最终模板可用行首标记 `【仅无口播】`、`【仅有口播】`、`【仅后期旁白】` 编写三种声音开场；只展开当前模式的正文。参考视频拆解在总览标记分场和造型，各真实镜头分别记录拍摄视角、必要同框关系、动作和收势；分镜改编将这些关系写入当前素材对应的主体与动作。“拍摄场景”默认为“沿用分镜场景”，不会自动用推荐第一项覆盖脚本地点。未替换场景时，动作段保留本镜环境；绑定场景后使用所选空间与光源。不同镜头的自拍、旁观和空镜机位按段呈现，商品明确不入画的段不插入重点商品图号。若主体或动作仍明确要求进入与所选场景冲突的地点，成片页提示对应镜号及动作段。生成页可查看本次完整展开提示词；保存模板后返回制作页重新读取，每次提交前再次核对保存版本。程序保留字段结构、素材归属、时间轴、模型参数和事实来源校验，独立 SRT 文本不进入视频事实块。

两版最终生成模板按拍摄、素材、声音和分镜四块展开。仅描述本次绑定素材的用途，深度版在素材块绑定动作视频一次，在各段标题保留对应源片时间。同一镜头内相同的主体状态、商品参考、景别和机位只写一次，有变化时重新标出。声音块只说明当前模式，口播台词或后期旁白节点只在对应动作段出现一次。完整旁白及 SRT 仍独立导出。原片空间、排除项原词、处理记录和与当前画面无关的全量卖点保留在来源资料中，不进入最终请求。

组装事实时，动作里的已知商品槽位先展开为保守的简短商品或部位指代，不重复嵌入完整电商标题，未知双花括号占位会在提交前报错，不递归执行资料内的事实块占位。`speech` 使用当前人声音频作为音色、韵律与停顿的参考，不把人声资产的试听稿写成人声说明；原片表情里的发音口型与口播语速记录不作为本片嘴形要求，眼神、头手及非发音表情保留。Seedance 2.0 系列按镜头和动作顺序组装，原时间仅作动作定位，不要求每句台词精确卡秒；深度参考的源时间仍用于定位原动作。场景图确定当前空间和光源关系，参考只提供与其相容的成像质感及既有镜头关系，不把来源地点或旧灯位重新写入执行稿。

仅按脚本制作时，超过模型可用时长不再等比压缩全片，按顺序保留容得下的完整动作段，界面明确本次保留与未生成的段数；台词、字幕与动作参考范围同步按保留段适配。纯分镜和深度制作实际剔除后续动作段时，最终稿省略最后保留段指向后续镜头的衔接，以该段自身动作和表情收势；原记录及手工衔接不改写，换回完整脚本可恢复。只裁掉尾部留白时保留原有最终收势。明确选定的成片时长保留，剩余时间自然收势；未指定时长则选择能容纳保留段的最短支持时长。原脚本及后续手工修改保留，换用更长模型后主动增加时长可恢复后续动作段。视频制作未设置分辨率时优先 720P，保留用户明确选择且模型支持的分辨率。

以下人物、摄影与动作要求属于可编辑初始模板的内容，保存后的工作区模板决定其是否执行，程序不在后台另行补入这些规则。

参考画风通过「拆解 → 商品改编 → 最终组装」连续传递。拆解在现有 `visualSpec.styleSummary / lighting / cameraFeel` 中记录色调、反差、纹理与柔化程度、光向、曝光、机位俯仰、主体占比和空间纵深，动作段记录幅度、快慢、停顿、视线、材质随动与衔接。未知内容留空或写入 `review`，不以通用「电影感、高清写实、自然柔光」补齐。

商品改编接收完整 `visualSpec` 及每段 `subject / scene / expression / transition`，只绑定当前商品、人物与场景并改写台词；动作由深度视频与动作提示词共同驱动，仅按脚本模式沿用动作提示词，不根据商品品类、款式、材质或卖点修改动作。服务端从输入保留 `refAction / expression / transition`，仅替换或剥离原片专属实体，模型重写的动作、表情和衔接不覆盖源内容；输入缺少动作提示词的旧请求保留兼容。手工修改的主体、动作提示词、表情与衔接独立保留，重新自动改写台词及刷新草稿后继续生效；明确清空的主体不恢复原脚本，改过动作后不再提交界面已隐藏的旧主体、表情或衔接；历史自动改编的动作不作为新的动作来源。表情按视线、眼睑、嘴唇嘴角、头部变化的起止与回落描述，区分垂眼与闭眼、轻微张唇与连续说话式口型；手型保留掌心朝向、腕部弯折与伸指状态。衔接记录末姿势和表情如何延续，结束段不新增原片没有的前倾、挤眼或大笑；生成时长补足部分延续末姿势与自然呼吸。无口播不等于全程紧闭嘴唇，也不把每个动作配成持续甜笑。

保留原动作以商品结构兼容为前提。改编调用模型前核对源动作，返回后再次核对当前主体及实际保留的动作、表情与衔接：内胆、内衬需有当前商品名称或原始事实的明确依据，并且该段已绑定对应的 `detail` 结构细节图。单冲、无内胆或待确认的资料不能支持内胆，内衬不能代替内胆；单冲仍可展示有资料支持的普通内衬。拆下内胆还需明确可拆卸依据。没有明确对象的「内部配件」和涉及接触、指向或操作的含混部位指代需先绑定具体部件。独立的「展示／呈现／展现商品细节部位」及对应占位词表示通用外观展示，比心、歪头等人物手势可原样保留，不要求为此新增具体部件；其他分句中的触碰、拆卸等操作仍单独校验。占位词展开只描述商品外观细节，不猜测具体结构。普通整理衣襟、展示口袋、背面或外壳内侧不因此被要求提供内胆证据。缺证据、否定或冲突时按具体动作段停止，不自动重编动作，也不把原片内胆替成当前内搭或外壳下摆。

商品证据只使用名称和当前原始采集/OCR 修订事实；生成的概括、买点、推荐文案、候选口播和原片口播不构成事实来源，旧客户端附在 `facts` 尾部的「最终卖点文案」等生成稿会剥离，避免稿件证明自身承诺。上述结构和事实校验独立于可编辑的创作提示词执行。更新初始模板不会修改数据库已保存的用户正文；若要使用新版拆解、改编或最终生成创作规则，需要在提示词管理中检查对应初始模板并明确保存，再重新执行对应环节。已有分镜和任务不会被批量覆盖。

口播改写每稿先做基础校验，再由独立的「口播语义验收」检查整片句意、连续性、事实、参数、字幕与计划画面对应。审稿规则单独保存在工作区，未配置即停止，不回退内置规则。审核返回的摘要须绑定本次稿件及事实、动作和时间上下文；错误结构、缺项、矛盾结论、旧稿摘要或渠道失败不视为通过。正常拒绝将具体问题交回改写，最多三稿，全部失败时保留原分镜。

每次写稿和验收分别使用最多 120 秒，整次口播请求最多 6 分钟，避免写稿耗尽后续验收时间。验收遇到超时、网络或上游临时故障时，失败回执可携带独立的 `pendingReview` 候选稿；候选不视为验收通过，不替换当前分镜。当前工作台只在内存中暂存已完成的商品分镜及待审台词，再次改写时先重新读取提示词版本，输入、模型与规则均未变才继续原字验收，保留原写稿版本。语义驳回后重新写口播；修改商品、分镜、手工台词或制作设置、切换模型或规则、主动停止、成功完成及离开工作台都会使对应暂存失效，刷新页面后从头执行。

分镜页文案区展示按当前分镜顺序串联的「当前逐镜口播／旁白」，编辑下方台词时同步更新，生成前仍需校验。商品提炼长文单独标为「商品口播参考稿」，有逐镜台词时折叠展示；参考稿仅供选取内容，不直接作为成片台词，无声音模式不展示逐镜口播预览。

口播写作与验收模板允许在普通商品展示中介绍有原始资料依据的材质、功能及合理的日常使用或搭配建议，不要求每个功能逐镜实验，也不要求商品资料逐字列出通勤、散步等生活场景。画面对应重点核对明确的部位指示、声称正在发生的演示及实际冲突；不因缺少泼水镜头而否定已核实的拒水介绍。具体效果结果、性能升级、部件、个人经历与专业适用性仍须有独立依据。规则在当前工作区保存后生效，既有自定义正文不会随模板更新被自动覆盖。

`POST /api/sales/spoken-copy` 的 `reviewOnly: true` 只验收当前稿，原样保留手工台词和字幕，不自动改字；未通过返回 422，审核异常返回 502，通过才返回 `reviewPromptVersion`。自动稿保存 `spokenReviewPromptVersion / spokenReviewSourceKey`，审核来源包含当前台词、字幕、动作、原始事实、介绍方式与时间。任何变化均需重验，生成视频与后期旁白 TTS 提交前核对本次稿和当前保存的审核版本；手工稿同样验收，纯画面与中性音色参考不执行口播审稿。审核回执在当前制作任务成功后保存，取消或过期任务不会覆盖当前草稿。此验收针对文本与画面计划，不声称已看过商品图片、实际成片或验证真实口型。

商品、人物和场景资产负责实体外观与布局，参考脚本负责可迁移的摄影基线。绑定新场景后以当前场景图及已记录的场景光线为准，剔除源场景的室内外、天幕、暮色、建筑等描述，保留兼容的纹理、反差和运动成像；无场景光线记录时只沿用清理后兼容的参考信息，不凭空指定新灯位。缺失画风时不拿段落地点补作全局画风。一镜到底仅约束不切镜，不自动添加推拉、摇移或跟拍，多动作段保留所属真实镜头边界。更换商品只更新商品外观绑定与商品实体，不重新编排动作或改写材质随动；姿态、轨迹、手型、幅度、快慢、停顿和收势由深度视频与动作提示词确定。制作时不引用原视频。摄影基线、机位、运镜、景别、构图、眼神表情和声音来自分镜文字及各自配置；深度视频仅提供前景主体动作，包括姿态、轨迹、手型、幅度、节奏、停顿、接触与动作时序，不提供运镜、景别、构图、身份、商品外观、背景布局、色彩、光线、摄影风格、表情或声音。深度画面中的人物移动不作为镜头运动依据，主体相对距离仅用于动作关系，不用于重建原片空间。模型清晰度等设置不能补回缺失的表情，也不在提示词中编造焦距、ISO或表情强度等控制值。既有脚本和改编结果继续保留，需重新执行相应环节才能补齐新信息；旧改编缺少独立表情或衔接时，不把可能残留旧场景的原字段直接拼回。

妆容与表演分开：眉眼、唇色、肤色及妆容浓淡以当前人物原图为准，人物三视图只补充角度与身形，清晰的派生脸图不能覆盖原图妆容或加重磨皮。表情字段只描述视线与肌肉变化，普通眨眼闭合后复睁，垂眼不等于长闭眼；仅按明确记录保留持续闭眼，不因微笑额外挤眼。仅手部与纯商品脚本不注入人脸表演指令。拆解将原房间、门墙和家具留在 `scene`，不写成必须复制的摄影属性；改编替换所有旧地点，最终全局绑定唯一所选场景，光线关系适配该空间，不为复制原背景而重建另一个房间。旧脚本中的美肤滤镜等来源观察保留为数据，是否执行由已保存的完整模板决定；最新最终模板明确不执行这些肤质处理，不把来源记录当作二次磨皮要求。

`GET /api/sales/prompts` 读取十一项及 `configured` 状态；`prompt` 为当前生效的正文，未自定义时与本版模板一致。`PUT /api/sales/prompts/{id}` 按版本核对保存完整文本到按工作区隔离的 `SalesPromptOverride`；`prompt: null` 只清除配置，不恢复默认执行。两套最终视频模板保存时均校验对应模式所需的事实占位符及双花括号格式，拒绝未知或缺失占位符；校验失败不覆盖已保存正文。执行读取缺失项返回 `400 / sales_prompt_unconfigured`，存储失败明确停止，不自动初始化或回退。脚本分析缓存及中断恢复均按实际提示词版本区分，不仅按视频地址复用；历史记录继续保留。已经完成但待保存的分析只重试保存，已有脚本仅补深度时也不重新调用分析模型。摄影、场景、主体、动作、表情和衔接字段提供错误类型、null 或超长文本时明确报错，动作和动作模板均为空时不能保存，不在规整时静默丢弃；不合规缓存不参与自动复用。提示词读取禁用缓存，读取或存储故障明确停止执行，不退回内置初始模板。

## 操作流程

1. 左侧粘贴京东、淘宝、天猫、1688 或拼多多商品链接；京东也支持商品编号。也可上传或拖入本地图片、文件夹补充素材。图片区顶部仅保留「商品图片 + 数量 / 上传 / 收起」和「全部 / 主图 / 详情 / 已选」两行；SKU 图片仍可从全部中查看。
2. **点击左侧图片主体**选择或取消参考图，选中采用细描边并按点击顺序编号。右下角放大按钮只打开预览，不改变选择。左底栏统一显示「已选 X 张参考图」、批量操作和次级「确认选择」；确认保存当前选择并保持展开，标题处的收起按钮独立控制侧栏。批量菜单提供「将当前分类全部选为参考图」「清空参考图选择」「识别当前分类文字」及失效图片重试。分类批量选择和识别仅作用于当前分类，清空参考图不改变 OCR 来源。
3. **从左侧拖图片到右侧编辑区**，仅加入识别输入，不改变参考图选择。右侧「添加详情图」默认添加前 6 张尚未加入的详情图，不足时按实际数量添加；无详情图则使用可用商品图，无候选时打开本地上传。空态高度约 200px，显示添加入口、默认数量说明并支持本地图片或文件夹拖放。实际识别图片及数量在横向队列中展示，可增删、单张识别或重试；重复加入不会产生重复项。
4. 将文字图片加入后，点击底部「识别文字」统一处理。识别时仍可在左侧点选参考图；采集、上传和识别队列暂时锁定，避免更换正在处理的来源。可停止后继续，或只重试失败图片；成功结果不重复处理。服务繁忙或未安装环境会停止本批次并保留已完成结果。
5. 「商品卖点」用一个文本框展示补充资料和按图片顺序合并的识别文字，可直接输入、修改或粘贴。原始 OCR 返回可单独展开查看，用户修订与原文分别保留。提炼使用当前队列中的有效文字及补充内容；其他尚未识别图片不阻塞已有文字，重新识别失败后仍可使用保留的有效文字。失效来源、空白文字和队列外历史文字不进入当前提炼。文本框上方可复制全部商品文字，保留不同数字与百分比。
6. 右底栏集中显示模型选择、OCR 操作和分镜入口，主按钮从「提炼卖点」切换到「下一步：分镜脚本」。有可用文字即可提炼，包括纯文字输入。识别或提炼时主按钮显示进度并禁止重复提交，保留对应停止入口。提炼完成后「重新提炼」为文字操作；未提炼时可通过「跳过，进入分镜」继续。参考图数量只在左底栏显示，识别数量只在右侧工作区显示。
7. 队列缩略图关闭按钮移出单张，「清空识别图片」移出全部；只改变本次识别与提炼范围，参考图选择、识别记录和文字编辑继续保留。重新加入时复用已有结果，已移出队列的历史原文仍可回看，但不用于当前提炼。左侧商品区常驻商品名称、品类与适用人群，页首右侧显示本机保存状态。

商品资料主界面不再展示重复的商品属性表单或长段流程说明。右侧只保留一套工作区，正文最后一行可完整滚动到底栏上方。已采集资料、旧草稿及兼容的已确认文字继续保留，当前操作不删除原始素材、服务端缓存或数据库。洗护图形等非文字内容不做语义解释；数字、成分比例和说明文字需人工核对。

## 商品文字与 OCR 卖点提炼

模型选择沿用主页的文字对话渠道、模型家族和版本菜单，支持纯文字模型，直接展示在右下角底栏，向上展开，切换模型在当前页完成。显式选择保存在 `summaryModel`，切换标签、刷新、重新采集或更换商品时继续使用该选择；不在商品草稿中另存 API Key。

商品卖点、分镜口播改写及首次无稿进入成片前的自动改写共用完整的已配置对话模型列表，包含多模态设置中新增的自定义模型和纯文字模型；新增、删除或修改模型后同步更新。同名模型保留各自渠道，选择保存具体配置条目，调用继承该渠道的凭据和接口协议。视频脚本分析仍单独筛选支持视觉的模型。

「商品卖点」共用一个阅读宽度受限的内容区，按处理阶段展示识别引导、可编辑文字或最终卖点。提炼成功后展示最终卖点，原文收纳在默认折叠的「查看识别原文」中，两份内容各自保存。卖点提炼为可选步骤，没有明确卖点或只做商品展示时可通过底部「跳过，进入分镜」继续，不发起卖点模型调用。

在底栏选择模型并点击「提炼卖点」。商品名称、品牌、属性和用户补充文字作为 product-meta 来源，当前 OCR 队列中的修订文字按 ocr-N 标记。一次输出事实卖点、消费者价值、自然表达、成稿与依据编号、冲突及待确认项。只有商品文字也可以提炼。参考图的勾选独立于 OCR 和文字提炼。OCR 入口独立于提炼按钮，补充文字或已有提炼结果时仍可识别新增图片；识别期间该入口原位变为「停止识别」。

提炼按所选文字模型渠道计费，手动触发；仅上述 OCR 文字发送到该渠道。免费本地 OCR 不变。后端不读取、转换或下载任何提炼原图；旧版请求中的图片字段也不会发送给模型。提炼不设图片张数限制，单条 OCR 文字最多 40000 字、合计最多 60000 字；超限显示在固定底栏，不静默截断，也不使用已移出队列的历史文字。文字和原图的关联仅留在本机供回看来源，不随提炼请求提交。

最终卖点以条目和短段落展示，一句话概括、各条标题/依据/表达以及推荐文案均可直接编辑；可复制全部或单独复制推荐文案，来源链接可打开对应原图。OCR 原文不随结果编辑而改变。草稿允许编辑期间暂时清空字段并原样恢复，保留字段长度及结构约束，接口对新生成结果仍进行完整校验。提炼规则要求列明 OCR 文字之间的事实冲突，未核实内容不用于成稿；保留数字、主体与局部成分、使用限制，不将低比例成分写成主材，不虚构实测、亲肤或显瘦等承诺。语义约束由模型执行，使用前仍需复核。

界面先展示买家的购买理由，再列对应商品事实和来源。成稿由同一次模型请求从已提炼买点中选最有说服力的 1—3 点展开，有效买点少则少写；`copyPointIndexes` 记录所选编号，服务端检查存在性、重复和数量。推荐文案直接介绍商品与具体用途，不把“我会先看参数”“资料里写着”“放进候选名单”等选购过程作为买点，也不编造买过、用过或实测经历。精确参数保留在商品依据 `feature`，使用及养护条件保留在 `cautions`；一句话概括、买点、自然表达和推荐文案不复述检测数值、工程单位、成分百分比、尺寸容量、型号代码或技术缩写，也不换成中文数字继续念。普通数量或结构表述仍可保留，不机械删数字；省去参数不能改成未经证实的性能或体验承诺。写作规则随当前工作区已保存的完整提示词执行，不增加二次润色请求。源码初始模板更新不会改变已保存正文；在「提示词管理 → 商品卖点提炼」可展开「查看最新商品文案模板」，载入编辑框、检查并保存后，下一次手动提炼才使用新规则。载入不自动保存，已有文案及手动编辑继续保留。

推荐文案初始模板改为通常1—3个简短句子，不设最低字数，一句话说清就不扩写，不强凑场景开头、功能中间和搭配结尾。商品文案、分镜改编与口播适配的模板均要求模型检查词语搭配、动作对象、指代和条件变化前后的用法关系；意思含糊时整句重写或删减，不只替换近义词。防泼水或拒水不能在润色时改成防水。这些语言要求随已保存提示词执行，不能由结构校验代替。

修改当前 OCR 文字或队列后提示上次结果已过期；选图、原图可用性、采集属性或补充文字的变化不影响仅基于 OCR 的卖点结果。旧版图文提炼结果保留，按新输入规则提示重新提炼。重新提炼由用户触发，处理期间保留当前文字或已有结果，按钮显示加载状态；成功后才更新结果并默认显示最终卖点。失败、停止和返回内容不完整时保留已有内容并提供底部重试，不自动重试、不自动换模型。接口校验结构与来源编号，不用本地套话替代失败结果。更换商品和清空草稿会清除提炼结果，原始素材与服务端数据保留。结果、条目修改及用户编辑的推荐文案跟随当前草稿保存在本机。

## 交互与等待

卖点请求按「OCR 文字及来源校验 → 按所选渠道协议调用文字模型 → JSON 与来源校验 → 常见无依据效果检查 → 保存」处理。模型只看到 `ocr-N` 来源 ID 与对应文字，只能根据文字内容提炼，不得声称看过原图或补写未提供的信息；无法确认的 OCR 内容列为待确认项。原始 skill 文件保持完整，应用约束补充成稿检查，规则版本同时覆盖 skill、输出契约和检查版本；规则更新后旧结果保留并提示重新提炼。

检查会拦截常见的无依据版型保证、耐用承诺、身体修饰效果，以及资料未提供的服装触感、重量和保暖说法；这不能替代全部语义和图文核对。禁止模型擅自选择冲突资料的一方用于成稿，不把字段简写与完整成分表自动当作冲突。「使用与养护」单独展示模型提炼及已识别标签中的明确限制，如手洗温度、不可干洗；这些限制不包装成卖点。

失败响应区分模型鉴权/路由/参数/配额、渠道服务、超时、返回 JSON 和成稿检查阶段，并提供请求编号及上游状态。服务日志仅记录模型、协议、阶段、数量与脱敏错误，不记录 API Key、原图数据或整份商品正文。不自动换协议、重试或重放付费请求。

上游 403 若包含 `Verify your account`，提示渠道账号需要验证；这类问题需由渠道账号所有者处理，不能当作 skill 未加载或普通密钥填写错误。保留当前资料和上次结果，验证后由用户重新提交。

选图和编辑立即更新页面；草稿按 250 毫秒合并，在浏览器空闲时写盘，最长空闲等待 1 秒。页面隐藏、离开工作区及清空商品时刷新最后一份待保存草稿，存储失败保留当前页内容及待保存快照。图片库使用远程缩略图、按需加载和异步解码，缩略图失败时回退原图；大图预览、OCR 和视频模型输入继续使用原始图片来源；卖点提炼使用商品资料及 OCR 修订文字。

本机保存失败时，页首提供「重试保存」，无需另改内容即可重新写入最后的完整草稿。通过页首返回首页前先尝试保存，失败则留在当前页；关闭或刷新浏览器时也先刷新待保存草稿，仅在仍有未保存内容时请求浏览器提示。浏览器是否展示提示由其自身策略决定。采集或上传期间仍接收独立的制作参数和模型偏好更新，避免后台返回或编辑被静默丢弃。

原图不可用或重新识别失败时，已有 OCR 原文和编辑内容继续展示，并可使用保留的修订文字继续提炼；不依赖原图重新读取。识别成功但没有文字的图片显示「未识别到文字」，可直接补充文字或留空跳过。

OCR 批次仍按顺序执行，可停止、继续及只重试失败项。卖点提炼单独管理取消状态，等待模型时保留当前内容并允许回看原文或结果，编辑和识别操作暂时锁定；OCR 文字或队列更新会立即取消旧提炼，不让晚到结果覆盖新资料。单独改变参考图保留正在进行的提炼，修订商品依据则停止旧提炼。采集、上传或重新识别时同样停止旧提炼。模型入口不自动发起付费调用，重复点击不并发提交。提炼请求只包含文字，服务端没有图片读取或并发下载步骤。

新增 Go 接口后，运行中的本地 API 需要更新到相应构建；旧服务的 404 会明确提示重启服务，不显示无法判断的「接口不存在」。

## 参考脚本库（P0 结构化拆解与入库）

电商视频使用统一资产库。顶部入口浏览全部文件夹，分镜快捷入口定位到对应分类。选用已确认的动作脚本后，返回制作页继续编排当前分镜。商品资料、视角选择与生成结果保留在制作草稿中。

1. **视频联合导入**：
   - 提交后默认分析脚本并生成深度动作视频，取消「同时生成深度动作视频」时只分析脚本（动作捕捉风格、标准质量）。转换提交前保留恢复标识，刷新或取消等待后继续查询原任务，避免重复提交。失败时仅处理未完成项，已完成脚本和视频不重跑。分析完成但保存失败时在本机保留正文，重试仅补保存。可先保留脚本、稍后处理深度，也可暂存未完成导入并继续导入其他视频；恢复时显式继续未完成步骤。
   - 分析及可选的深度转换结束后删除导入的原视频，失败也清理；未提交的上传会过期清理，重启时清除遗留原片。保留文字分镜和深度视频，不保存原片预览帧。需要重新分析时重新选取本地文件。
   - **上传参考视频自动拆解**：通过 `POST /api/sales/script-video` 上传本地 MP4、MOV 或 WebM（≤64 MiB）至当前工作区存储，由 `ffprobe` 读取真实时长、画面比例与音轨状态；再调用 `POST /api/sales/script-analysis`（需 Gemini 原生视频协议模型，单视频直传 ≤16 MiB）输出结构化脚本，以实测时长和比例校验分镜。模型需要的采样帧仅在分析期间使用。素材字节、工作区、模板、实际模型、渠道、协议和思考强度相同才复用已有拆解记录。
2. **结构化模板与防串货剥离**：
   - 采用 `shots`（真实切镜）+ `beats`（镜内推拉/动作段）双层时间轴，兼容一镜到底连续运镜与多机位切镜剪辑。
   - 模板固定保存全局视觉基调 `visualSpec`、后续资产需求槽位 `assetSlots`（商品视角、人物双锚点、场景空间与动线、口播/旁白语速与 BGM 情绪）、去商品化动作模板 `actionTemplate`、可复用台词句式 `linePattern` 以及原片专属剥离清单 `sourceExclusions`（原商品、品牌招牌、原模特外貌、私人配饰、未证实话术）。
3. **预览与选用**
   - 动作详情左侧播放深度动作视频，按分镜定位，右侧按「镜号、时间 / 时长、画面与动作、镜头方式」列出脚本。总览分别统计真实切镜和表格行数；连续动作保留原镜的小数编号。新分析按实际地点、造型或叙事阶段分段，旧脚本缺少段名时按原顺序显示。点击行可定位左侧画面，起止时码、可见动作以及有记录的表情、台词、字幕和衔接直接显示，全片相同的主体、字幕等只列一次。选中分镜后，播放器下方同步显示该段的复用动作。
   - 动作卡片打开双栏详情：左侧按时间排列分镜，右侧随选择显示动作、镜头、台词与字幕。卡片删除按钮删除对应的脚本记录。
   - 导入分析以实测视频时长校验时间轴。脚本分析成功后自动确认入库，深度转换的进度和结果单独保存。已有草稿仅供预览，已确认脚本才提供「用于视频制作」。
   - 脚本模板保存在 SQLite 的 `SalesReferenceScript`。视频制作将选中的 `selectedScriptId` 随当前商品草稿保存，使用次数单独更新。

## 资产匹配、提示词组装与配乐成片

新建制作方案默认使用 `wan3.0-video`，已有草稿保留显式选择的模型及渠道；未配置该模型时须先选择可用渠道，不自动切换到其他供应商。

每次实际组装 `referenceFacts` 都包含素材用途边界，已保存的最终提示词模板也会获得这些事实：商品图仅参考款式、颜色、结构、材质与穿搭关系，不继承模特身份、背景、布景、光线或摄影风格；人物图只提供人物身份及可见外貌。背景、空间和现场光源由当前场景图确定，场景文字只补充同一空间；无场景图时明确使用当前场景文字，不从商品图、人物图或动作视频补取背景。衣物在中景和近景之间保持颜色、结构、层次与开闭状态，内外层不互换，没有可见操作不自行开合、换装或增加部件。这些约束参与生成，不代表已自动验收成片。

人物和场景绑定只使用明确选中的资产，选中资产失效时保留选择标识并提示重新选择，不静默换成推荐第一项；已选场景没有可用主图时停止生成，补充场景图后继续。自定义人物与人物库互斥：只上传人脸或主体图也不会补入旧人物库的另一张图；重新选人或智能匹配会切回所选库人物并解除自定义引用。商品图只提供商品结构和材质，其中的模特、场景人物及原视频人物不参与出镜身份；摄影风格迁移不改变所选人物的五官和辨识特征。

自动改编记录当时的提示词版本及商品、当前有效最终卖点（含条目和推荐文案编辑）、人物、场景、参考脚本内容来源。生成前实时核对改编提示词版本，版本缺失、变化或读取失败时停止提交；修改最终卖点、更换人物或有效场景、修改同一脚本的动作、表情、衔接等内容后保留既有分镜和手工编辑，但须重新适配，避免旧描述覆盖新选择。仅调整分辨率、配乐等无关设置不触发重新适配；纯商品脚本不检查无用的人物字段，无自动来源记录的手工分镜保持兼容。需要人物出镜的脚本若实际引用中没有人物图，会在提交前阻止生成，不以商品模特或动作视频代替人物参考。仅有人脸图时可锁定脸部，但身形没有独立参考；纯商品脚本不因残留人物选择而新增模特。

选用脚本后，动作参考仅有「仅按脚本」与「脚本＋深度视频」两种方式，默认仅按脚本；两种方式都使用所选商品、人物和场景图片。深度视频须关联当前脚本，实际进入最终引用清单与视频模型请求，并与分镜时间对应；未就绪时不可选择。两种模式分别调用已保存的 `final-video`（纯分镜版，保留原标识）与 `final-video-depth`（深度视频版），独立编辑、保存和核对版本，缺失时停止，不跨模式回退。纯分镜版动作完全来自文字，不提交深度视频、原视频、历史逐段动作视频或姿态图，时间轴不输出动作视频编号和源片对应时间；深度版只提交当前脚本明确关联的深度视频，不回退使用原视频或历史逐段动作素材。旧绑定保留在草稿中，不作为执行依据。制作设置不再提供原参考视频和逐镜手动动作，旧记录中的这些模式读取时回到仅按脚本，保留已有分镜编辑、绑定数据和产出媒体。切换脚本会重置关联引用与过期生成结果。

从资产库的「动作」文件夹点击右上角「导入视频分析」或「导入文件夹」，可选择或拖入 MP4、MOV、WebM，每批最多 30 个，单个最多 64 MiB、10 分钟。队列按所选模型逐个分析。可同时生成深度动作视频；超过 35 MiB 或 30 秒的视频仅保存脚本。失败项可以单独重试；复用已保存的脚本和深度任务回执，需要原片时重新上传。

自建目录保存到 SQLite `SalesScriptTaxonomy`，接口为 `GET/POST /api/sales/script-taxonomy`、`PATCH/DELETE /api/sales/script-taxonomy/{id}`，按当前工作区隔离。`taxonomy.categoryId` 和 `taxonomy.styleId` 保存稳定编号，重命名立即更新展示且不改分镜；移除目录时在事务内清除当前工作区全部关联脚本（含归档记录）的对应编号，动作素材只移除目标分类编号，保留其余分类及其他工作区。任一步骤失败均回滚，脚本内容、另一项归类及商品业务元数据保留；成功后同时刷新脚本与动作目录。历史记录、缺失目录或已移除编号在页面归入未分类或未设风格，保存时拒绝失效编号。

资产库按素材文件夹浏览。场景细分室内和室外，人物按性别和年龄分类，声音分为人声与 BGM。动作文件夹展示参考视频、深度视频及独立动作素材，相同媒体地址只显示一次。

新上传图片统一以 JPG 保存，保留原尺寸，透明区域填充白色，已有 JPG 不重复有损编码。裁图接口 `POST /api/sales/asset-view-grid` 读取当前工作区存储图、公网图片或 data URL，视角原图最多 64 MiB、4000 万像素，支持超过 20 MiB 的高分辨率 PNG，内联请求同步预留 base64 编码空间；手动上传与 OCR 仍沿用各自限制。单格两边至少 256 像素，场景与历史裁切任务按实际尺寸整数等分，不缩放，边缘余数像素不会丢失。读取请求前限制并发，裁切复用单格像素缓冲区。裁片以当前工作区与原图内容散列确定路径，重复裁切复用同一组文件，已齐全时不再解码完整原图。模型返回成功后保留原图地址，裁切/保存失败只重试处理原图；超出大小限制返回明确错误并保留原图，不反复查询原任务。远程原图下载先尝试常规连接，遇到连接或传输中断时自动换用独立的 IPv6 优先连接，保留 IPv4 回退与公网地址校验；两次下载分别最多 20 秒、60 秒，整个处理仍受 90 秒总时限约束。下载失败保留原图地址，继续补全直接重试下载与裁切，不重复提交生图或无效轮询成功回执。移除视角后可「恢复已有视角」，更换或移除主图才清空旧视角图缓存。人物与场景的表单、主图、补充视角和视角图任务按当前工作区及资产分别暂存在本机；关闭或刷新后重新打开同一编辑窗口会恢复草稿。提交生图前保存原请求标识，提示词、任务编号、原图地址和裁片结果逐步保存，继续补全复用原任务。创建或保存到资产库成功后自动清除对应草稿；「暂存关闭」、关闭按钮和 Esc 在本机暂存失败时保留窗口并提示先保存资产。关闭弹窗或离开页面只停止本地等待，已受理的后台任务继续执行，完成后自动保存到对应资产；资产被删除时不重新创建，生成期间主图变化时不把旧视角挂到新主图。开发页面热更新不重置当前分类的编辑弹窗，真正切换分类时才关闭。人物名称、音色与分类及场景空间分类随资产保存；场景新增和编辑不再提供标签输入，历史标签、旧参考图与描述保留。弹窗标题下以简短状态区分尚未入库、草稿已暂存、已恢复草稿与已入库；新建主操作为「保存到资产库」。有草稿时可确认放弃，仅清本机草稿，不删除图片文件或已有资产。编辑老年或儿童人物分类保留既有性别；明确保存的场景空间类型优先于名称关键词。

`POST /api/sales/asset-view-jobs` 保存基础资产及持久化任务，`GET /api/sales/asset-view-jobs` 返回当前工作区进度。后台任务独立执行，资产页显示简短进度，完成后刷新资产。新建资产另保存绘图提示词及主图的任务编号和结果地址，视角处理失败时沿用已生成主图；更换参考图后清空本机旧结果，以新请求标识生成，继续更新同一资产。裁切或保存失败可「继续处理原任务」，沿用固定提示词、模型、原任务编号和已生成原图，不重新付费生图。服务重启后将中断任务明确标出，用户可继续处理；模型凭据不写入任务记录，恢复时重新读取原渠道配置。已受理的任务以工作区及请求标识去重，保存回执丢失时同标识核对原任务。上传主图或单视角仍显示上传状态；生成期间主图和已有手动视角保持原样，只有空位被补齐。新接口需运行更新后的 Go API，启动时执行任务表迁移。

声音素材可在「声音」文件夹试听。电商视频从关联的工作区记录选用人声或配乐，成片页也支持上传当前商品的配乐。

人声样本单个源文件最多 32 MiB，在新建或替换音频时由服务端检测实际时长，超过 15 秒自动保留前 15 秒，不足或等于 15 秒保留原长度，不补长、不变速。裁切另存新文件并保留上传原件，入库的 `audioUrl` 与 `sampleAudioUrl` 同步指向裁切结果，声音库试听与视频生成共用该样本；处理失败不保存新的声音引用。只编辑名称、说明或合成音色编号时保留已有音频。人声自动裁切不影响 BGM 的时长选项。

`GET /api/sales/studio-bgms/builtin` 读取可选短配乐；`POST /api/sales/studio-bgms/import` 接收 `audioUrl`、`videoUrl`、`builtinId` 三种来源中的一种，以及可选名称、起点与截取时长。导入最长 600 秒；本地来源核对工作区，远程来源沿用公网媒体读取限制，重复请求复用同来源、同截取范围的已保存资产。新接口需运行更新后的 Go API。

素材目录查询失败返回错误并提供重试，不伪装成空库；视频制作仅在目录成功刷新后清理失效引用，读取失败时保留现有素材绑定。已选人声失效时保留原 voiceId 并提示重新选择，不自动改用推荐第一项或默认女声。真人口播和画外旁白均须明确选择有效人声；画外旁白模式下，当前台词尚无有效配音时不能提交最终混音。Grok 1.5 真人口播改为显式选择 Grok 官方预置音色，选择独立保存，不替换声音库绑定；普通 Grok 账号不能直接参考库中的自定义声音文件，界面明确说明这一限制，选定官方音色后按 `<AUDIO_0>` 绑定口播并传入独立 `voice_ids`，最高 720P。

在「资产库」保存好脚本及素材后，返回电商视频的「视频制作」，在制作页选用已确认的参考脚本、人物、场景、动作与声音，完成分镜选择与台词改编、素材核对、视频生成及最后的配音/配乐合成。制作页保留当前素材搭配及重新智能匹配入口：

制作区按「商品资料 → 分镜脚本 → 生成成片」组织。已有有效商品参考图时，进入分镜页直接隐藏底部商品区。需要重选时可返回「商品资料」。进入成片页后隐藏商品选图区。分镜页左侧的内联表格集中展示时间、景别、用图与姿态，画面动作、台词与字幕直接单元格编辑，主体、表情与衔接收纳在行尾「细节」。文本按内容自动增高，当前有效的脚本动作与细节直接显示并可精修，动作留空后恢复沿用脚本；表情与衔接可以明确清空，已改写或更换场景后不重新显示已失效的原脚本细节。单独修改主体也会进入生成提示词。语速按每段实际时长计算，字数与成片汇总使用相同规则。商品图、姿态与细节弹层点击外部或按 Escape 收起，底部空间不足时向上展开。分镜页右栏集中展示素材、成片参数、改写模型和下一步操作，已有分镜可重新改写。窄窗口将设置排列在分镜表格下方。成片页左侧播放器按实际画幅居中，支持导入、版本切换与下载；右侧提示词可独立滚动、复制和收起。下方左侧展示素材，右侧集中模型选择、模型设置、最终 BGM 和成片操作。窄屏时依次排列视频、提示词和制作设置。操作区保留「生成视频」和「音频视频核查」。生成或导入视频后，点击核查会自动解码最终成片，只有原片时检测原片。窗口分别报告画面能否解码、是否全片接近黑场、音轨是否存在及是否静音，并显示实测尺寸与时长。有可混入的音频时可在此合成，再核查新成片。

1. **四大资产规则打分推荐与人工锁定**：
   - `GET /api/sales/studio-assets` 只返回当前工作区的人物、场景、动作与音色，配乐目录默认为空；不为人物自动关联预置音色。人物支持全身主体 `fullBodyUrl` + 人脸 `faceUrl` 双参考锚点，人声分别记录音频样本 `sampleAudioUrl` 与可选合成音色编号 `voiceId / ttsVoice`。新建或编辑人声可填写、回显和保存合成音色编号；有样本而未填编号时保持空值，不假定已完成声音克隆。无样本、无编号的旧默认创建流程继续兼容，历史已保存非空编号不自动改写。自有配乐可上传并绑定当前商品；历史内置配乐 URL 保持可访问，兼容已生成内容。
   - 动作资产分为图片、视频、深度图片、深度视频。历史文字模板与参考图按图片分类兼容读取；新增动作支持上传四类媒体。资产库 → 动作素材 →「更多素材操作」可单独转换图片或视频，也可上传已有深度素材；已有普通动作素材可在详情发起转换。转换调用现有 Go 深度接口，支持动作捕捉、原始灰度、伪彩色与快速/标准/高清质量，预览原素材与结果后保存到工作区动作库，保留原素材地址。图片上限 20MB；视频上限 35MB、30 秒，分辨率由所选质量控制。环境安装见[部署说明](deployment.md#深度图片与视频环境)。
   - 深度任务提交前保存当前工作区的任务标识、原素材和转换参数；离开或刷新页面后，在转换面板继续查询原任务，不自动重新提交。保存失败时保留转换结果以便重试。制作时仅使用当前脚本关联的深度视频，按分镜时间段参考动作，不再从动作库逐镜绑定其他媒体；历史绑定数据仍保留。深度视频只约束姿态与空间关系，最终输出正常彩色商品视频。所选模型不支持参考视频时提交前提示换模型。切回「仅按脚本」后，深度视频不进入提示词或生成请求；切换脚本会重置动作参考选择。
   - 深度转换的首次恢复信息保存失败时不发起提交；提交响应丢失后继续核对原标识。自动查询或同源转换只尝试一次，失败后由用户重试，保存完成后不会再次自动转换同一素材。后续本机存储失败保留内存中的任务和结果。
   - `src/shared/domain/sales/assetRecommendation.ts` 结合 `src/shared/domain/sales/productClassification.ts` 按当前商品适用年龄人群（`productAudience`）、脚本 `assetSlots`、商品类目、双锚点完整度、空间类型、光线和 BPM/情绪标签自动打分推荐 Top 1 资产并展示推荐理由（年龄人群严格匹配的人物额外加分置顶，不匹配年龄段的人物自动降权并折叠在底部选单的「展开其他人群」中，防止如女童童装误绑成年模特），同时支持自定义上传替换人物全身图、人脸图、实景图和 BGM。
   - 各动作段按 `requiredView` 自动绑定对应视角的已选商品图，缺省视角自动以主参考图兜底并给出缺失提醒。
2. **分镜动作与口播/旁白台词改编**：
   - 点击底栏「下一步：准备成片脚本」或顶部「生成成片」（含键盘切换）时，已有自动稿或手工稿直接保留台词、字幕和画面编辑，不因缺少历史来源标记、切换模型或修改制作设置自动重写。来源或动作时间窗失配时，生成按钮上方显示具体原因。可在成片页点击「按当前设置重新改写分镜」，也可返回分镜调整。改写成功后单独点击「生成视频」；仅更换模型或调整分镜结束后的留白时长可复用当前稿，生成前按实际时长验收原文。尚无制作稿且已配置改写模型时，先按当前商品、人物、场景、声音和时长自动改写，完成后用最新分镜组装最终成片脚本，正文可用才进入成片核对页；失败或停止改写时保留原稿和当前页面，不提交视频。页面持续显示可关闭的结果提示：成功明确告知已更新分镜，失败展示原因并说明原稿保留，主动停止时提示已停止改写；再次执行会清除旧提示，过期任务不报告成功。未配置模型时继续支持手工编辑后进入成片。连续点击只执行一次，等待期间选择其他页面后不因旧任务完成自动跳转。
   - 分镜底栏先选择「成片模型」及生成时长，与成片页共用当前模型、渠道、参考方式和分辨率。顶部显示原脚本时长、模型上限、本次生成时长和适配说明。切换模型时优先保留当前有效生成时长，避免从短模型换到长模型时重新展开原脚本后半段；新模型不支持该时长时重新规划并提示核对。自动按模型支持的时长规划本次分镜，不改写资产库原脚本：纯分镜和深度模式均按原时序保留开头连续的完整动作段，不加速、不在动作中间截断。单个首段已超出可用时长时提示换模型或先拆分动作段。
   - 深度模式同时计算输出与参考视频时长约束：Seedance 2.0 动作参考最长 15 秒，2.5 最长 30 秒；Wan 3.0 参考视频最长 15 秒，且参考视频与输出合计不超过 30 秒。进入成片核对页时通过 `POST /api/sales/video-clip` 生成当前工作区原视频的无声片段，按本次保留动作的结束时间截取，保持原速度与原文件。预览、素材校验和最终提交使用同一片段；准备失败可重试，不提交付费生成。生成时长多出的部分按最后姿势收势。
   - `POST /api/sales/plan-adapt` 结合当前商品已核实资料、已提炼买点、锁定的人物/场景与声音模式（`speech` 真人口播、`voiceover` 画外旁白、`none` 纯 BGM），保留原动作提示词、表情时序与衔接，仅绑定当前主体并生成自然口语台词，拦截未经证实的虚假承诺词，并实时检测总字数是否超过自然语速上限（防止 TTS 加速显得生硬虚假）。剥离词保留 `term / type`，只有原商品词替换为当前商品，人物外貌、地点、招牌等其他原片词剥离，避免把旧地点替换为商品名；兼容旧字符串列表。
   - 选择「真人口播」或「画外旁白」后，在尚无制作稿时点击「下一步：准备成片脚本」，或主动点击「按商品重新改写」，已保存的分镜和口播编写规则共同生成一份初稿，再调用 `POST /api/sales/spoken-copy` 验收。时长或语义被拒绝时保留画面，只修复口播。编写时结合当前商品推荐文案、已核实买点、分镜动作与表达用途、原片话术参考、视频总时长和每段时间轴，重新取舍并组织适合当前画面的自然台词，按段写入口播与字幕，不改变画面动作及分镜时间。买点由模型根据画面相关性选择，不按分镜编号轮流强配。口播规则独立保存在「分镜脚本 → 口播设置 → 编写规则」（`spoken-copy`），执行前必须保存；纯画面展示跳过此步骤。模型响应未通过字数、结构或内容校验时，服务端带回校验问题、上一稿和完整原始输入自动纠错，最多调用三次；上游请求失败或用户取消时停止。全部通过后统一写回台词和分镜，最终仍失败则保留原稿。调整长文案依靠取舍和重写，不截断句子，也不靠提高语速塞满原文。初始提示词模板更新不覆盖工作区已保存的自定义正文。
   - 口播适配同时传递真实镜头编号、景别、运镜、当前主体及商品视角信息。全局规则先识别本段可见部位和正在发生的动作，再选有依据的买点写本段短句，最后检查相邻段落衔接；不能先写整篇广告再按字数分配。原片台词及句式与当前画面冲突时舍弃，参考图视角不证明镜头已经完成某个动作或效果实测。没有对应买点可短过渡或留白；精简重试不能把内容移到无关镜头。最终视频按各段既定台词和时间执行，不重新编词或为台词增加动作、道具及效果演示。
   - 口播与旁白采用连贯的日常述句，字幕单独提炼关键词，不直接朗读买点标题、参数列表或营销口号。分镜改编与口播适配的初始模板均要求台词、字幕不复述检测数值、成分配比、尺寸容量等商品规格，不从事实或旧稿中重新补回参数，也不换写成更强的性能承诺；参数仍随商品事实输入供核对，普通数量或结构表述及重要使用限制的准确含义保留。同一镜头内的连续动作段可用前后承接的自然分句，但每段仍在原时长内完成，具体事实与指示语仍对应本段画面；不拆词、不借用其他段的时长。短段少讲一个重点或留白，保留必要的主体和动词，不通过删掉语法、堆语气词、虚构亲测体验或提高语速制造“口语感”。输出前连读全片核对衔接，再分别提炼字幕；超长反馈只报告字数与时长问题，改写方法由已保存的提示词决定。模板修改或保存不直接覆盖已有分镜台词，需重新执行按商品改写后才使用新稿。
   - 待审核或已归档的脚本不能发起分镜改编和视频生成；已选脚本在资产库修改后返回制作页会重新核对状态。改编使用当前队列最新编辑的 OCR 文字、采集属性与有效最终卖点：概括及各条标题/依据/表达从当前 `result` 读取，推荐文案优先读取 `editedCopy`，用户主动清空时不回退旧文案，全空条目不形成占位输入。当前队列存在未识别、失败或不可用图片，以及合计超过 20000 字时明确阻止提交；不要求额外确认收录，也不截取前半段资料。过期卖点保留供查看但不参与改编，不强制重新提炼。成功改编保存当前资料与最终卖点的来源标记；卖点过期时按新资料适配成功即可继续生成，旧改编、改编失败或资料再次变化时阻止使用未核对台词出片。服务端核对动作段编号、时间轴与模型完成状态，拒绝截断、缺号、重号及越界结果，按编号恢复模型返回的乱序分镜。
3. **素材核对、视频生成与最终配乐合成**：
   - `src/shared/domain/sales/promptAssembler.ts` 依次收集有效的人物原图、人物全身、人脸、商品、场景与动作参考；所有已选商品图按图库顺序纳入核对和生成，分镜绑定只指定该段的重点商品图，未直接绑定的已选图作为全片商品补充参考。同 URL 去重，不存在的锚点不占槽位。动态输出即梦 `{{Mixed N}}` 引用及站内按媒体类型分别编号的 `@图片N / @视频N`，与实际提交顺序一致；不固定原图、脸图或商品的数字编号。组装时剔除 `sourceExclusions` 中的原片商品/招牌/配饰词。
   - 最终创作要求全部位于当前模式已保存的 `final-video` 或 `final-video-depth` 模板，代码仅提供资料和占位映射。深度版明确深度视频只参考动作，其他信息按对应图片、分镜文字与声音设置；纯分镜版不依赖动作参考视频，人声音频仍按声音模式独立绑定。初始模板包含身份及场景优先级、动作连续、摄影兼容和结尾要求，用户可在管理页修改这些规则；程序不再用硬编码补齐或清理创作描述。Sales 视频请求启用 `preserve_prompt` 保留展开正文，适配层不追加 MiniMax 静音文案并关闭 Wan 自动提示词扩写。
   - 人物资料同时传入当前资产的描述、风格标签与单独标注的原分镜人物风格；自定义人物不继承此前库中人物的设定。自动改写优先读取人物原始主图，缺失时依次使用主体图、人脸图，与分镜一起交给所选图片理解模型；同一次请求返回 `personaVisualProfile`，独立记录原图的视觉气质及可见依据、视线、表情、姿态与观察限制，再融合进出镜主体状态。分析只描述可见表现，不从静态图片推断内在性格、连续动作或不可见信息；手部出镜仅分析手部，近景不补造全身体态。图片读取或视觉分析失败时保留原稿并提示，不静默退回年龄标签。
   - `personaVisualProfile` 随本机商品草稿保存，并绑定实际原图地址与出镜范围；更换人物原图或人物出镜范围后，要求重新改写以更新分析，旧分析不进入最终提示词。最终视频模型同时接收人物图和上述具体观察，以原始主图保留身份与神态气质，补图提供角度与体态；观察具体内容优先于年龄、性别分类标签。模板要求把气质体现在目光回应、眉眼嘴角、头颈肩背姿态及动作收放中，沿用原分镜的表情变化、停顿与收势，不随机换性格或统一微笑、热情、提速。商品决定款式与使用关系，当前场景决定空间与现场光；摄影按分镜记录，固定镜头不再叠加统一的自拍抖动与变焦。
   - 生成成片页展示实际提交的商品、人物、场景、动作素材及人声音频用途，图片和视频可放大，人声音频可试听；核对并确认后才可生成，引用内容变化后需重新确认；「提示词」展示实际展开正文。视频模型按 Agent 的模型家族与版本选择方式展示，画幅、分辨率、时长等参数使用当前模型能力约束。分镜页与成片页均可选择模型支持的完整时长范围（Seedance 2.5 为 4–30 秒），当前分镜时长不作为选择下限；缩短后按上述完整动作段规则重新规划并核对口播，默认仍优先容纳完整脚本。配乐选择、试听和上传放在视频步骤之后，生成或导入视频后再合成成片。素材、画面动作、口播或生成参数变更使旧画面结果失效；更换口播人声、样本或参考音频时使旧原视频与待恢复任务失效；旁白只更换合成音色或完成配音时保留原画面。仅编辑独立 SRT 字幕时保留已有视频、配音和成片；更换配乐使旧混音成片失效，避免导出与当前选择不符的内容。
   - 真人口播（`speech`）优先用所选人声的声音样本作为 `audios` 参考；只有 TTS 编号而无样本时，由用户点击「生成音色参考」，以固定中性试听句生成短样本。编辑本片台词时继续使用同一份参考，不要求重新合成；更换音色或合成模型时清除不匹配的临时参考。完整口播台词不截断，仍逐段写入最终提示词。样本仅提供音色与说话特征，不提供台词、配乐、环境声或额外说话人，画面人物按本次分镜台词同步口型；深度视频不提供声音。声音名称、说明、标签及 `音频1` 写入 `audioFacts`，与实际提交的 `audios[0]` 对应。纯画面模式忽略所有已存人声与音频引用。
   - 人声参考实际进入已接入的 Seedance 2.0 / 2.5、MiniMax-H3、Wan 3.0 或 Vidu Q4 全能参考请求；其他模型、首帧/首尾帧等不兼容方式在提交前明确提示，不默默丢弃人声。本地样本核对工作区、大小、真实时长与格式，M4A、AAC、OGG、FLAC、OPUS 等既有格式转换为 WAV；Vidu Q4 则转为 MP3，每段要求 3–12 秒，最多 3 段。H3 使用 MP3/WAV，最多 3 段，每段 2–15 秒、总长不超过 15 秒；官方与秘塔请求写入 `content.audio_url` 并标记 `reference_audio`，Comfly 渠道使用 `audioUrls`。超长本地样本从开头自动截取提交副本；有音频总长限制时按输入顺序分配，并为每段保留最低时长，不丢音频或改变编号。处理后再次检测实际时长，声音库原文件与试听不变，不变速或补静音。短于最低时长仍明确提示更换样本；声音设置按所选模型展示时长与自动截取规则。随后按对象存储配置上传，以可访问的 HTTP(S) 链接提交，Q4 音频写入 `sounds`。Seedance 音频不自动注册为 `Audio` 素材，也不复用此前自动注册的音频素材缓存，避免部分渠道对音频 `asset://` 返回 1007 错误；显式传入的 `asset://` 仍沿用原验证路径。图片与视频预检保持原有规则。远程与供应商素材元数据仍由上游校验，详见[视频模型调用参考](视频生成模型调用参考.md)。
   - 画外旁白（`voiceover`）用所选人声的有效 TTS 编号生成完整台词，再通过混音加入成片，不给视频模型发送人声参考、不要求人物连续说话。只有样本而无可用合成编号时提示配置或改选，不把样本试听当作 TTS 克隆。真人口播后期混音保留模型原声，只叠加配乐，不以旁白覆盖来冒充口型同步。
   - 支持直接调用 `POST /api/generate/audio` 用所选音色库合成旁白试听、调用 `POST /api/generate/video`（全能参考多图输入）在站内出片或上传外部即梦生成好的原片，再通过 `POST /api/sales/audio-mix` 调用内置 `ffmpeg` 自动循环裁剪所选背景音乐、在有人声口播或旁白时自动压低背景乐音量（智能闪避），导出可下载的最终 MP4 成片。合成支持当前工作区本地文件及公网 HTTP(S) 音视频，包括对象存储签名地址；远程视频最多 128 MiB、单份音频最多 32 MiB，每次下载最多 45 秒，临时文件在失败或完成后清理。WebM 和 MOV 输入转为 H.264 后输出 MP4，兼容 VP8 与 ProRes 等无法直接封装的编码。
   - 商品和人物图默认按全能参考语义提交，不因两张图片而改用首尾帧；用户可在模型支持范围内切换参考模式，模式不兼容现有素材时阻止提交，不静默丢弃素材。提交前检查模型支持的参考图数量、参考视频、画幅和时长。更换模型、参考模式或分辨率时，当前有效时长在新参数下仍受支持则继续保留，不按原始脚本重新取整；同时保留分镜、台词、字幕和人声选择。时长和实际动作时间窗兼容时直接复用，只有原稿来源或动作时间窗失配时才提示重新适配，旧分镜和手工修改保留。仅改变结尾留白时长不重写台词或重新合成相同时间窗的旁白；当前台词在生成前单独验收，验收回执独立保存，即使后续视频或配音生成失败也可复用。相同内容和验收规则下重试或换模型不重复验收，修改台词、事实、时间窗或验收规则后重新核对。模型选择保存具体渠道，提交与轮询使用同一渠道；最终提示词保留十分之一秒的镜头时间。
   - 制作任务同一时间只执行一个，重复点击不会重复提交。取消、切换商品或调整方案后，旧任务的结果、进度和错误不覆盖当前编辑；停止等待不保证渠道任务撤销，已提交视频可在历史记录核对。收到任务号后将原任务、模型、渠道与本次输入标识保存在当前商品草稿；刷新或重新进入制作页时，仅恢复与当前方案匹配的原任务查询，完成后自动显示视频预览，不重新提交生成。不保存渠道密钥，不将历史中未关联的任务自动挂到当前商品。手动取消或不可重试错误后，本次页面会话不自动重启等待；更换方案或导入已有视频后清除旧关联。视频任务（包括较慢的 Wan3）持续查询原任务直到完成、明确失败或用户停止等待，无固定总等待时限。正常每 3 秒查询，等待超过 2 分钟后改为每 10 秒；网络、408、429、5xx 或可重试的查询故障按 6、12、24、30 秒退避并持续重试，恢复正常查询后重置退避，页面显示实际已等待时长。权限等不可重试查询错误立即提示原任务编号，不自动重新提交。配乐音量为 0 时保持静音，只有未提供音量时才使用默认值。
   - 「卖点介绍」根据分镜生成字幕文本，可在生成成片页下载 UTF-8 SRT 文件，保留动作段的毫秒时间。当前 MP4 混音不烧录字幕，需将视频与 SRT 一起导入剪辑软件后添加字幕；纯画面模式不生成字幕文件。

制作预设的保存与默认项切换在同一事务内完成；失败保留已有默认项，编号冲突明确返回错误，不能通过预设接口覆盖配乐资产。

人物与场景的新建草稿按原任务标识和资产 ID 核对后台回执，不按名称猜测归属。后台已入库的草稿显示为原资产的暂存编辑，继续编辑时沿用该资产并恢复已完成的主图和视角，保留本机后续字段修改及手动视角；关联资产已删除时保留本机内容并明确提示，不能当作未入库人物再次打开。用户可确认放弃当前本机草稿，资产、后台任务和图片文件不受影响；确认期间草稿发生变化则保留新内容并要求重新确认。任务区只显示当前人物或场景类型的记录，已删除资产的完成与失败记录不再作为当前资产展示，尚在执行的任务仍保留进度。

## 免费本地识别

使用 CPU 版 RapidOCR（`rapidocr-onnxruntime==1.4.4`，内含中文 ONNX 模型），无需 OCR API Key 或付费模型。首次安装依赖需要网络；识别在运行 Go API 的机器完成。远程原图仍需从商品 CDN 下载，本地上传图片不发送到 OCR 云服务。

服务运行用户在项目根目录执行（Python 3.9–3.12）：

```bash
pnpm setup:ocr
```

默认创建用户数据目录下的 `ocr-runtime` 虚拟环境；`OCR_SETUP_PYTHON` 可指定创建环境用的 Python（Windows 默认 `python`，其他平台默认 `python3`）。已有解释器可用 `OCR_PYTHON` 指定，安装与后端均读取此变量。若服务设置 `AZHUO_DATA_DIR`，安装时也需使用同一目录。直接启动 Go 且自定义 `DATABASE_URL` 时，需同时指定 `AZHUO_DATA_DIR` 或 `OCR_PYTHON`，确保安装位置一致。生产环境需部署 `tools/scripts/ocr` 全目录，并以实际服务用户完成安装。

识别读取原图，长图和宽图按 1400 像素区块加重叠边缘处理，按文字框中心归属去重。返回原图坐标、置信度和文字；中文、数字及英文由同一引擎识别。单图最多 12 MiB、4000 万像素、5000 行/10 万字符；全服务同时执行一张图，单次最多 120 秒，远程取图最多 30 秒。仅支持已上传素材或公网 HTTP(S) 图片；本地文件需属于当前工作区。

结果按工作区、图片内容和引擎版本缓存于用户数据目录 `ocr-cache`（非公开素材目录），有效期 7 天，每工作区最多 200 条，写入时清理过期与超量 OCR 缓存；失败不缓存。该缓存不包含原图。

## 代码与存储

商品采集沿用 `POST /api/catalog/collect`，后端在 `src/backend/internal/catalog`，上传沿用公共接口；文字识别为需认证的 `POST /api/sales/ocr`，后端在 `src/backend/internal/sales`，请求响应契约在 `src/shared/contracts/sales.ts` 和 OpenAPI。采集映射与 SKU 规则见[商品采集](product-collection.md)。

前端在 `src/client/features/sales`，共享层 `src/shared/domain/sales` 承载商品目录、品类与适用年龄人群推断（`productClassification.ts`）、属性整理、参考图视角选择及参考脚本模板校验、分镜资料导出与受限模板资料填充。当前商品草稿仅在本机保存，工作台不再静默同步商品档案或累计商品成片计数。SQLite `SalesProduct`、迁移 `20261101_04_sales_products`、接口 `GET/POST /api/sales/products` 与 `GET/PATCH/DELETE /api/sales/products/{id}`，以及契约 `src/shared/contracts/salesProducts.ts` 保留兼容，已有商品记录不清理。用户手动修改品类或人群后，`categorySource / audienceSource` 置为 `manual`，后续更新采集保留手动分类。资料整理使用 `POST /api/sales/summary`，参考脚本拆解与资产库使用 `/api/sales/script-*` 与 `/api/sales/scripts`；Go 后端将维护的 `product-selling-points.md` 与 `reference-script-analysis.md` 嵌入构建产物，复用模型网关适配，不读取开发机器上的绝对路径。契约在 `src/shared/contracts/salesSummary.ts`、`src/shared/contracts/salesScripts.ts` 和 OpenAPI；结果记录模型及提示词版本，便于追溯。

采集草稿使用 `beike.video_sales.collection.v1`，分别保存参考图与文字识别队列、逐图识别结果和编辑文字，以及 `productSummary.result` 与推荐文案修改 `editedCopy`；旧草稿中的已确认文字兼容保留。原文和最终卖点切换不改写两份数据，最终编辑字段暂时为空时仍保存整份结果。首次打开可以从旧 `beike.video_sales.draft.v4/v3/v2` 提取商品资料，后续只写新草稿，旧草稿不覆盖。同一采集链接再次点击「更新采集」时绕过采集缓存获取最新图片，失败保留原草稿；成功后保留手动商品资料、上传图片、原有图片编号、两组选图和 OCR 编辑，仅补充新图片并更新采集状态；不同链接开始一件新商品，清空商品则重置当前草稿，不删除服务端历史、素材、数据库或采集缓存。

采集草稿记录 `collectedProductUrl` 以区分正在输入的链接与已采集来源；旧草稿按原商品链接兼容读取。本机保存失败时保留当前页面内容并明确提示，成功保存后恢复正常状态。

旧草稿中的 `step` 仅兼容读取，不再控制页面显示；已有商品图选择、文字队列和 OCR 编辑会同时恢复到工作区。
