# Agent 技能包维护

## 存放与真源

内置 Agent 运行技能统一存放在 `src/shared/domain/assistant/skills/packages/<skill-id>/`。每个技能的 `SKILL.md` 是执行正文的唯一维护入口，详情阅读器和发送给 Agent 的正文均由它生成，不再分别维护长文展示版和短版执行提示词。创作示例仍保留在 `builtinCreationSkills.ts`，不自动加入运行技能目录。

- `SKILL.md`：名称、触发用途、输入决策、执行步骤、失败恢复、输出与验收。
- `agents/beike.json`：稳定 ID、中文展示名称、版本、实际工具等应用元数据。
- `agents/openai.yaml`：兼容的界面展示信息，不代表应用实现了其他运行环境的工具。
- `references/`：按需读取的规范与细分模式；主文件明确何时读取哪些路径。
- `assets/`：可直接用于交付的文本模板。
- `scripts/`：有实际用途时才添加；上传脚本不授予终端权限，也不会自动执行。

不为凑目录创建空资源，不编造许可证。维护技能时保留已有 ID、路由与持久化标识，避免破坏历史消息和收藏。

修改包后运行 `pnpm skills:build`，生成浏览器安全的 `compiledSkillPackages.json`。`pnpm check:skills` 校验主文件、元数据、真实工具名、引用资源及编译结果同步，已纳入 `pnpm check`。不要直接编辑生成的 JSON。编译器位于 `tools/scripts/skills/build-skill-packages.mjs`，主正文超过 10,000 字符时要求拆分参考资料。

## 界面和自定义技能

技能页的 Agent 视图使用分类双列列表。详情页分为使用指南、技能文件和执行能力；文件阅读器支持目录、Markdown 阅读、源码和复制，可从详情导出当前包的全部文本文件 ZIP。

顶部「技能文件」入口说明包目录和实际存储方式，并支持选择本地文件夹；「创建技能」保留 ZIP/Markdown 导入与手动编辑。自定义技能沿用当前工作区的服务端技能库持久化，不在用户机器上静默创建第二套目录，也不修改个人 `.codex/skills`。本地源码文件修改不会自动更新已导入数据库的副本，需重新导入或编辑保存。

当前导入支持 Markdown、TXT、JSON、YAML、Python、JavaScript、TypeScript、Shell 和 CSV 文本文件；单文件上限 256 KB、整个包上限 1 MB。图片、字体等二进制素材会明确提示跳过，不能把导出称为对这些原始二进制素材的备份。需要二进制素材时保留原始文件夹。

「通过 Agent 创建」将需求带入实际 `skill-creator` 对话，由用户确认发送，不再用本地固定模板冒充模型生成。当前 Agent 没有安装技能的写入工具，因此交付文件内容后仍需在技能工作室导入或保存；本地兜底只能标为「起草模板」。

## 执行与资源读取

详情中的「本次指定」不是全局启用开关。选用后发送正文、工具上限和资料快照；不选用时 Agent 根据目录匹配，先 `read_skill` 再读取必要的 `read_skill_file`。创作模板仅在用户选用后注入。资源读取必须来自已读技能或本次消息快照，不能访问本机任意文件。

`read_skill_file` 使用 `skill_id` 与包内相对 `path` 定位。同名路径出现在多个已读技能中而未提供 `skill_id` 时返回歧义错误，不互相覆盖。消息已固定的资料不受当前目录中同 ID 新版技能影响。

长文件使用 `offset` 和 `length` 分段，默认每段 8,000 字符、最大 12,000；有 `hasMore` 时按 `nextOffset` 继续。偏移按 Unicode 字符计算，不按 UTF-8 字节或 JavaScript UTF-16 代码单元推算。长主指令改由 `SKILL.md` 资源完整读取，不在注入时简单丢掉末尾。

本轮载荷仍有资源保护上限：每技能最多 24 个资源、每资源 40,000 个 JavaScript 字符，超长文件带明确截断提示；技能目录最多 16 项、正文和资料合计预算 120,000 字符。分页只能读已携带的内容，不能恢复超出载荷的部分。超大技能应拆分为聚焦的参考文件，不能声称任意大小均能完整执行。

## 能力与验收

现有 13 项运行技能均声明具体的任务边界、真实工具流程和可检查交付。`trigger_generate` 只准备单张草稿，不表示已生图；批量生成只接受当前清单的真实 sourceId/entryIds。工具回执、实际生成结果和视觉质量分开报告。关键词审核不假装当前 JS 沙箱具备写入 XLSX 的能力；视频拆解区分画面观察、实测和推断。

回归测试覆盖正文同源、全部内置技能的目录预算、包内路径与 ZIP 导入、同名资源隔离、消息快照不被覆写及中文长文件续读。测试通过只说明这些实现约束成立，不代表真实模型每次都能正确选用技能或生成高质量内容；线上仍需用真实任务核对交付和工具回执。
