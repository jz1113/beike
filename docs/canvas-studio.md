# 贝壳云图项目画布

## 视频复刻流程模板

首页画布项目库提供「新建深度视频复刻」和「新建W3 视频复刻」。每次创建独立项目，包含可编辑的流程文本节点和顺序连线，沿用现有本机 IndexedDB 保存。它们是制作与接入说明，没有接通自动执行，不上传素材、不创建生成任务或扣费。

深度路线参考 NGGAIGC `ngg-depth-dance-copy 0.2.3`：参考片与目标人物 → 媒体和本机预检 → 连续深度与主图 → 分段报价 → 画面生成与原声合成 → 电商验收。W3 路线参考 `w3-video-copy 0.1.37`：参考片与商品 → 台词/声音/字幕 → 免费分析与商品分镜 → 整片方案 → 素材准备与持久接续 → 合成归档。商品、人物、场景、脚本与动作可复用电商视频及资产库；模型和任务按各路线真实合同执行。

后续可选贝壳原生编排（复用已有深度任务、分镜、模型网关和合成）或 NGGAIGC 受信本地执行桥。后者仍需独立账户、验签入口和完整任务恢复协议；不向浏览器迁移系统凭据，也不将总入口文件当成服务端编排实现。模板实现为 `features/canvas/model/videoWorkflowProjects.ts`（相对于 `src/client/`）。

从创作首页选择「画布」，点击「新建项目」。双击空白处添加节点，拖动节点端口建立连接。点击顶部「首页」回到创作首页的生成页签，点击项目菜单中的「项目库」回到首页的画布页签。点击顶部项目名称可展开故事板、创作档案、画布设置和画布助手。左上角切换浏览器与画布，右下角打开画布对话。桌宠在项目中使用独立位置，首次默认显示在右侧中部。从故事板选择镜头可回到画布并定位对应节点。连线、网格、小地图、节点显示及删除确认偏好在同一浏览器的项目间共享。已有旧版节点数据的项目继续用原编辑器打开。

## 项目与资源

CanvasWorkspaceView 按项目数据选择编辑器。StudioWorkspace 打开当前贝壳云图项目的画布，画布与宿主通过带项目 ID 的消息传递场景。宿主将节点、边、组、文本框、笔迹及视口保存到现有项目数据库。项目素材缓存按项目 ID 分隔。故事板按画布上从左到右的顺序排列图片和视频，音频节点不单独占用镜头。顺播时可以暂停并从当前位置继续。新画布的「编辑节点」会返回对应镜头，选中节点后可在原面板调整参数和生成。

## 桌宠与项目库

在「画布设置 → 画布功能 → 桌宠」调整大小、预览动作或单独关闭画布桌宠。点击桌宠可打开当前画布助手，右键可直接进入设置。「仅生成」跟随当前项目的任务，「全开」也响应新增节点与连线。首页按最近修改时间排列画布，纯笔迹和文本框也会作为项目保存。

## 素材库

首页侧栏的「资产库」与画布左下角的「素材库」使用同一媒体索引。可以按文件夹、类型或关键词浏览参考素材、本机资产、画布媒体和有媒体的工作区资产。生成任务的输出可在主导航的「生成历史」查看。工作区和共享资产按内容合并浏览。目录旁的数字是该目录及其子目录的去重素材总数；同一场景的多个视角只计一项。场景按室内、室外划分，人物先选男或女，再选青年、中年、老年或儿童，声音分为人声和 BGM。多视角场景使用一张卡片，点击主图下方的缩略图即可切换视角，预览、收藏和放入画布使用当前选中的图片。

导入文件夹会上传所选媒体并记录相对目录。本机素材清单与收藏夹保存在当前浏览器；文件夹导入是一次性操作。首页的「放入画布」可选择已有画布或新建项目，项目内也支持将卡片拖到目标位置。素材卡片上的垃圾桶删除对应来源的资产记录。同一媒体属于多个来源时，可选择要删除的记录。画布节点和生成任务中的引用由原项目管理。点击任一文件夹右侧的「＋」可在该位置新建子分类；顶部按钮也可在选中目录下新建子分类，选中「全部文件夹」时则保存到「我的文件夹」。在素材预览或动作脚本详情中选择目标分类，点击「加入文件夹」即可收藏。素材卡片上的「移动到…」可调整单项素材的分类；勾选多张卡片或「全选当前结果」后，点击批量栏的「移动到分类…」可整批移动。目标分类按所选素材类型过滤。文件夹内移动只替换该目录及其子目录中的归属，其他分类归属保留；「全部文件夹」内移动会统一归入目标分类。分类调整保存在当前浏览器，原始媒体和工作区资产的预览、视角与使用能力保留。自建分类右侧的「…」提供重命名、移动到其他文件夹和删除；重命名或移动会同步更新全部子分类及收藏关系。移动不能选择自身或子分类，同名分类会提示冲突，含素材的分类不能移入类型不符的目录。删除自建分类会同时移除其子分类和其中的收藏关系，原始素材仍保留。电商视频的素材入口打开同一个资产库，动作参考视频也能在画布内预览和插入。

## 模型

画布与创作页共享贝壳云图的模型目录及网关，无需在项目中设置 API Key。图片和视频节点提交到现有生成队列，结果按任务 ID 写回原节点。同一节点再次出图或出视频时可查看历史版本，项目素材库也收录其中有持久地址的结果。视频生成可连接图片或视频参考，支持范围由所选模型决定。GPT Image 节点设置的低、中、高画质随任务提交。旧项目保留内容和连线；旧模型名称优先匹配当前渠道，匹配不到时使用同类型的默认模型。文字节点和画布对话使用后台画布文本接口；语音合成使用后台音频接口。音乐与 3D 尚无对应的画布生成接口，不回退到第三方直连。

## 维护入口

宿主入口在 src/client/features/canvas/components/editor/StudioWorkspace.tsx，模型适配在同一功能的 model/studioGeneration.ts。发布版画布与媒体资源在 src/client/public/canvas-studio，host.js 管理浏览器存储范围及任务消息。渲染资源来自本机「桥豆麻衣酱」1.0.0 发布包，保留作者标识与随包使用说明。

画布 iframe 以 `/canvas-studio/` 为基地址加载 `host.js`，收到项目初始化消息后动态导入渲染主包。主包按需启动 PDF、双底色透明图、深度视频和会话 Worker。深度视频 Worker 使用 ONNX 的 WASM 模块。发行包另带两份 ONNX bundle，分别供普通和 WebGPU 运行时在 `file:` 分支启动线程，HTTP 模式复用当前模块。更新发行包时，运行 `pnpm check:reachability` 核对这些脚本的引用。
