# 音乐生成模型调用参考指南

本文档全面梳理当前主流音乐生成模型（Suno v4/v5、MiniMax Music、ElevenLabs Music）的官方调用机制、gpt-best 聚合网关对接规范、二者核心差异以及在贝壳云图系统中的集成映射。

---

## 1. 适用模型目录

| 模型 ID | 厂商 / 架构 | 创作模式 | 支持时长 | 歌词与纯音 | 推荐场景 |
| --- | --- | --- | --- | --- | --- |
| `suno-v4.5` | Suno 架构 | 灵感 / 自定义词 | 最大 4 分钟 | 支持 / 支持纯音乐 | 电商带货短视频 BGM、卡点音乐 |
| `suno-v4` | Suno 架构 | 灵感 / 自定义词 | 最大 4 分钟 | 支持 / 支持纯音乐 | 经典商业广告旋律、活动片头 |
| `suno-v3.5` | Suno 架构 | 灵感 / 自定义词 | 最大 2 分钟 | 支持 / 支持纯音乐 | 极速配乐草稿与灵感试听 |
| `music-01` | MiniMax | 歌词驱动生成 | 最大 4 分钟 | 支持伴奏与人声 | 华语流行、说唱风格定制音乐 |
| `elevenlabs-music` | ElevenLabs | 描述词驱动 | 15s~60s | 纯器乐 / 环境音 | 高端品牌氛围音乐、转场微音效 |

## 2. 官方原生机制与规范

### 2.1 Suno 机制说明

Suno 官方（`suno.com`）目前主要面向个人订阅用户提供 Web 界面与移动端体验，**官方尚未开放无门槛的公共商业 REST API**。
工业界中针对 Suno 的程序化对接普遍基于 **GoAmz / Suno API 标准**（模拟 Session / Token 桥接协议），通过任务队列对外暴露统一的 HTTP 接口。

---

### 2.2 MiniMax 官方 Music API

- **官方文档**：`https://platform.minimaxi.com/document/music_generation`
- **基础端点**：`POST https://api.minimax.chat/v1/music_generation`
- **鉴权**：`Authorization: Bearer <MINIMAX_API_KEY>`

#### 官方调用示例
```bash
curl -X POST https://api.minimax.chat/v1/music_generation \
  -H "Authorization: Bearer $MINIMAX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "[verse]\n秋意渐浓微风凉\n落叶纷飞映斜阳\n[chorus]\n心中的歌声在回荡",
    "voice_id": "male-qn-qingse",
    "lyrics": "[verse]\n秋意渐浓微风凉\n落叶纷飞映斜阳\n[chorus]\n心中的歌声在回荡",
    "is_stream": false
  }'
```

### 2.3 ElevenLabs Sound & Music API

- **官方文档**：`https://elevenlabs.io/docs/api-reference`
- **端点**：`POST https://api.elevenlabs.io/v1/sound-generation`
- **鉴权**：Header `xi-api-key: <ELEVENLABS_API_KEY>`

## 3. 三方聚合网关（gpt-best）调用规范

gpt-best 支持通过标准的 Suno / 音频任务端点进行音乐生成与查询。

### 3.1 提交音乐生成任务

- **端点**：`POST https://{{BASE_URL}}/suno/submit/music` 或 `POST https://{{BASE_URL}}/v1/audio/generations`
- **认证**：`Authorization: Bearer {{API_KEY}}`
- **Content-Type**：`application/json`

#### 灵感模式（自动作词与编曲）
```json
{
  "model": "suno-v4.5",
  "prompt": "轻快律动的咖啡馆爵士乐，萨克斯与钢琴交织，温暖阳光感",
  "make_instrumental": true,
  "mv": "chirp-v4-5"
}
```

#### 自定义歌词模式（Custom Mode）
```json
{
  "model": "suno-v4.5",
  "prompt": "[Verse]\n阳光洒在橱窗前\n一杯冰美式带走疲倦\n[Chorus]\n轻快脚步穿过大街\n迎接崭新的一天",
  "tags": "pop, acoustic guitar, cheerful, female vocals",
  "title": "阳光漫步",
  "make_instrumental": false,
  "mv": "chirp-v4-5"
}
```

#### 提交成功响应
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "task_id": "suno_task_20261015_77192",
    "clip_ids": [
      "clip_88291a_01",
      "clip_88291a_02"
    ]
  }
}
```
*注：Suno 默认单次任务会并行生成 2 首风格迥异的变体歌曲，分别对应两个 `clip_id`。*

---

### 3.2 轮询音乐生成进度

- **端点**：`GET https://{{BASE_URL}}/suno/feed/{taskId}` 或 `GET https://{{BASE_URL}}/suno/task/{taskId}/fetch`
- **认证**：`Authorization: Bearer {{API_KEY}}`

#### 轮询完成响应
```json
{
  "code": 200,
  "data": [
    {
      "id": "clip_88291a_01",
      "status": "complete",
      "audio_url": "https://filesystem.site/cdn/20261015/music_output_01.mp3",
      "image_url": "https://filesystem.site/cdn/20261015/cover_art_01.jpg",
      "duration": 182.4,
      "title": "阳光漫步",
      "tags": "pop, acoustic guitar, cheerful",
      "prompt": "[Verse]\n阳光洒在橱窗前..."
    }
  ]
}
```

## 4. 官方 vs 三方核心差异对比

- **接口可获得性**：
  - 官方：Suno 官方无开放 REST API，直接对接不可行。
  - 三方网关：提供稳定合规的封装，具备标准化任务创建与状态回调。
- **音频产物持久化**：
  - 原生环境：临时直链有效时长往往有限（24~48 小时）。
  - 三方网关：输出音频由网关自动镜像备份至 CDN 对象存储，提供长期有效下载直链。
- **双轨候选与变体挑选**：
  - 三方网关完整保留 Suno 标志性的“双曲齐发”（一次扣费生成 A/B 两个版本），供创作者挑选最契合节奏的版本。

## 5. 贝壳云图程序集成规范

### 5.1 前端模型配置与模态管理
- 在 `src/client/features/settings/model/modalityModelDefaults.ts` 中维护 `music` 模态：
  - 默认模型：`suno-v4.5`（显示为 **Suno v4.5**）。
  - 备选模型：`suno-v4`、`suno-v3.5`、`music-01`。
- 服务商管理页 `ApiServicesTab.tsx` 支持动态测试音乐模型连通性。

### 5.2 安全资源白名单
- 确保音乐 CDN 域名（如 `audiocdn.site`、`filesystem.site`）已加入安全下载白名单。
- 前端播放器通过 `LazyVideoCover` / 音频波形组件进行流式预加载，避免大体积 MP3 导致界面卡顿。
