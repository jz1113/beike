# 生图与图像编辑模型调用参考指南

本文档全面梳理当前主流生图与图编辑模型（OpenAI GPT Image 系列、Google Nano Banana、火山引擎 Seedream、阿里百炼通义千问、BFL Flux、xAI Grok Image、Midjourney）的官方调用规范、gpt-best 网关标准对接方式、二者核心差异以及贝壳云图系统中的参数适配逻辑。

---

## 2. 官方原生调用规范

### 2.1 OpenAI Images API (DALL·E 3 / GPT Image)

- **官方文档**：`https://platform.openai.com/docs/api-reference/images`
- **基础端点**：
  - 文生图：`POST https://api.openai.com/v1/images/generations`
  - 图生图编辑：`POST https://api.openai.com/v1/images/edits`
- **鉴权**：`Authorization: Bearer <OPENAI_API_KEY>`

#### 官方 Edits 特性
官方原生 Edits 接口要求使用 `multipart/form-data` 格式，必须通过文件字段上传原始 PNG/JPG 图片（及可选蒙版 `mask`），参数包含 `image`, `mask`, `prompt`, `n`, `size`。

---

### 2.2 火山引擎即梦 Seedream API

- **官方文档**：`https://www.volcengine.com/docs/82379`
- **基础端点**：`https://ark.cn-beijing.volces.com/api/v3/images/generations`
- **鉴权**：`Authorization: Bearer <ARK_API_KEY>`

---

### 2.3 千问 / DashScope 文生图与图像编辑

- **官方文档**：`https://platform.qianwenai.com/docs/developer-guides/image-generation/text-to-image`
- **服务地址**：`https://maas.qianwenaiapi.com`，也可使用 `https://dashscope.aliyuncs.com`
- **鉴权**：`Authorization: Bearer <DASHSCOPE_API_KEY>`
- **Qwen-Image（含参考图编辑）**：同步 `POST /api/v1/services/aigc/multimodal-generation/generation`。提示词放在 `input.messages[].content[].text`，参考图放在同级 `image`。尺寸用 `parameters.size`，格式为 `宽*高`。`qwen-image-3.0` 与 `qwen-image-2.1-pro` 可传 `prompt_extend` 和 `enable_thinking`。
- **Wan 2.6 / 2.7**：异步 `POST /api/v1/services/aigc/image-generation/generation`，请求头 `X-DashScope-Async: enable`，再用 `GET /api/v1/tasks/{task_id}` 查询。`wan2.7-image` 与 `wan2.7-image-pro` 使用 `thinking_mode`，不接受 `negative_prompt`。`wan2.7-image-pro` 支持 4K，其余千问图像模型最高 2K。
- **Wan 2.5 及更早版本**：仍是 `input.prompt` 旧接口，当前适配器会直接返回「该万相版本暂未适配」。
- **对话**：同一密钥走 `POST /compatible-mode/v1/chat/completions`，模型目录走 `/compatible-mode/v1/models`。
- 图片 URL 约 24 小时后失效，结果需要尽快转存。

---

### 2.4 Midjourney 原理说明

Midjourney 官方原生仅通过 Discord 机器人对话交互，**官方未向公网开发者提供独立开放的 REST API**。
目前开发者使用的所有 Midjourney HTTP 接口（包括 gpt-best、GoAmz 等）均为基于 Discord 协议或逆向协议封装的第三方代理（Midjourney-Proxy）。

## 3. 三方聚合网关（gpt-best）调用规范

gpt-best 抹平了厂商繁杂的协议差异，统一使用 OpenAI DALL-E 风格规范作为基石，并针对高并发生产场景提供了异步轮询机制。

### 3.1 文生图与图生图提交

- **端点**：`POST https://{{BASE_URL}}/v1/images/generations?async=true` 或 `POST https://{{BASE_URL}}/v1/images/edits?async=true`
- **认证**：`Authorization: Bearer {{API_KEY}}`
- **Content-Type**：`application/json`

#### 请求参数结构
```json
{
  "model": "gpt-image-2",
  "prompt": "电商服饰白底实拍，冷白皮超模穿搭高定真丝连衣裙，真实光影与细节微距",
  "size": "1024x1536",
  "quality": "high",
  "n": 1,
  "image": [
    "https://example.com/dress-reference.jpg"
  ]
}
```

#### 异步提交成功响应
```json
{
  "id": "task_img_20261015_901234",
  "task_id": "task_img_20261015_901234",
  "status": "IN_PROGRESS"
}
```

### 3.2 异步任务结果轮询

- **端点**：`GET https://{{BASE_URL}}/v1/images/tasks/{taskId}` 或 `GET https://{{BASE_URL}}/v1/images/generations/{taskId}`
- **认证**：`Authorization: Bearer {{API_KEY}}`

#### 完成响应
```json
{
  "status": "SUCCESS",
  "data": [
    {
      "url": "https://filesystem.site/cdn/20261015/image_result.png",
      "revised_prompt": "..."
    }
  ]
}
```

### 3.3 特殊模型参数映射

1. **Grok Image (`grok-4.1-image` / `grok-4.2-image`)**：
   - 不支持 `size` 和 `quality` 参数，**必须**使用 `aspect_ratio`（可选值：`1:1`, `2:3`, `3:2`, `9:16`, `16:9`）。
2. **通义千问编辑 (`qwen-image-edit`)**：
   - 仅支持传递 1 张参考图；多图参考需升级到 `qwen-image-edit-2509` 或改用 `doubao-seedream-5-0`。
3. **Midjourney**：
   - 提交端点：`POST /mj/submit/imagine`
   - 查询端点：`GET /mj/task/{taskId}/fetch`

## 4. 官方 vs 三方核心差异对比

- **垫图介质与格式**：
  - 官方：OpenAI Edits 需要上传表单本地文件二进制流 (`multipart/form-data`)。
  - 三方网关：统一为 JSON 传输，`image` 字段支持直接填公网 HTTP(S) 图片链接或 Base64 Data URL。
- **长连接超时保护**：
  - 官方：很多官方端点为同步 HTTP 连接，耗时超过 60 秒时极易被反向代理（如 Cloudflare/Nginx）断开报错 504 Gateway Timeout。
  - 三方网关：通过 `?async=true` 立即返回任务 ID，客户端定时轮询 `/v1/images/tasks/{taskId}`，从架构上彻底避免长连接超时中断。
- **多图参考能力**：
  - 官方：部分模型官方接口仅支持单图。
  - 三方网关：如 Seedream 5.0、Nano-banana 支持直接在 `image` 数组传入多张参考图进行交叉特征融合。

## 5. 贝壳云图程序集成规范

### 5.1 数据准备与签名
- 前端在 `generationTaskSubmitter.ts` 中收集主图、工坊商品图与人脸图，统一压缩超大 Base64 垫图。
- 涉及私有 OSS / S3 / R2 存储资产时，调用 `setPresignedUrlSigner` 为垫图生成带过期签名的临时公共下载链接，使网关能无密码直取图片。

### 5.2 后端分发与防重机制
- Go 后端在 `src/backend/internal/generate/image_submit.go` 与 `image_run.go` 中按协议适配器提交：
  1. 显式 `customProtocol=template` 使用请求模板；`dashscope` 或千问 / DashScope 域名使用原生生图；其余走 OpenAI 兼容 `/v1/images`。聚合网关上的 `qwen-image` 不会因为模型名被改成原生协议。
  2. OpenAI 兼容协议里，Grok 系列改为 `aspect_ratio`，不发送 `quality`。有参考图的 GPT Image 与 `qwen-image-edit` 走 `edits`。
  3. 千问原生协议把界面分辨率和推理强度映射成 `宽*高`、`prompt_extend` / `enable_thinking` 或 `thinking_mode`，不发送 OpenAI 的 `quality`。
  4. 提交成功后立即写入任务记录，前台使用 `taskId` 定时轮询，任务幂等防止重复扣费。

## 6. 协议适配器与请求模板

新增平台时在 `src/backend/internal/generate` 增加一个 `imageProtocol` 实现，并在 `resolveImageProtocol` 注册。适配器负责提交、轮询和把上游结果整理成任务号或图片地址。

| 协议 | 选择方式 | 生图行为 |
| --- | --- | --- |
| `openai` | 默认 | `/v1/images/generations` 或 `/v1/images/edits` |
| `dashscope` | 服务商类型，或 `maas.qianwenaiapi.com`、`dashscope*.aliyuncs.com` | 第 2.3 节的原生接口 |
| `template` | 服务商类型为「自定义请求模板」 | 按保存的 curl 模板渲染 |

请求模板保存在浏览器的服务商配置里，提交时放在 `requestTemplate`，轮询时放在 `x-request-template`。可用占位符：`{{model}}`、`{{prompt}}`、`{{size}}`、`{{width}}`、`{{height}}`、`{{n}}`、`{{images}}`、`{{negativePrompt}}`、`{{taskId}}`。`{{apiKey}}` 只能出现在请求头。模板地址必须是公网 HTTPS，不能设置 `Host` 或 `Cookie`，整体不超过 32KB。

结果路径使用点号，例如 `output.choices.0.message.content.0.image`。异步模板还要填写轮询地址、状态路径、成功值和失败值。设置页提供「千问同步」和「千问异步」两个预设，也可以直接粘贴文档中的 curl。

## 图像生成请求样例

```json
{
  "description": "图像生成与局部重绘标准调用样例 (Image Generation / Inpainting)",
  "endpoint": "/api/generate/image",
  "method": "POST",
  "headers": {
    "Content-Type": "application/json",
    "Authorization": "Bearer <API_TOKEN>"
  },
  "request": {
    "model": "gpt-image-2",
    "prompt": "极简北欧风亚麻沙发，柔和自然漫射光，摄影级超清细节，8k画质",
    "size": "2448x3264",
    "quality": "high",
    "aspectRatio": "3:4",
    "references": [
      "https://example.com/assets/sample-sofa.jpg"
    ]
  },
  "response": {
    "success": true,
    "taskId": "task_img_20261016_001",
    "recordId": "rec_8839102",
    "status": "IN_PROGRESS",
    "model": "gpt-image-2",
    "size": "2448x3264",
    "resultUrl": null
  },
  "pollResponse": {
    "success": true,
    "taskId": "task_img_20261016_001",
    "status": "SUCCESS",
    "resultUrl": "https://example.com/storage/generated/20261016_001.webp"
  }
}
```
