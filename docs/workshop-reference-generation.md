# 电商图文：参考学习与创作技能

## 生产与学习的职责

电商图文生产依据当前商品图与创作技能，自主设计小红书风格分镜。商品图负责商品身份和可核对的外观，技能负责创作方法、构图、场景、展示节奏及避坑。人物、穿搭和场景由技能与当前商品确定。

“素材与技能”中的采集、反推和参考图库用于学习。原图和完整反推词保存构图、裁切、相对大小、动作接触、色彩与纹理证据，再由学习流程提炼成可以独立使用的技能。生产无需采集或指定参考素材；学习图组和原图不会附加到新分析或生图请求。详细输入规则见 [workshop-asset-binding.md](workshop-asset-binding.md)。

## 生产设置

创作技能区显示加载状态，默认按商品细分读取当前试用版或正式版；没有匹配版本时使用基础技能。只有自动技能时不显示单选项下拉框，有手动技能时可以切换。技能加载失败和已删除的选择提供明确提示及刷新入口。

图片与交付设置保留四宫格/单张逐镜、镜数、画幅、画质与交付尺寸。新批次默认四镜四宫格；单张模式可选四镜或八镜。画质显示实际请求像素，固定档位模型不展示无效选项。切图交付尺寸在折叠区调整，单张模式隐藏无效的切图设置。

模型与并发设置保持独立：视觉模型用于分析，图片模型用于生图；并发仅控制同时运行数量。分析与文案并发支持 1–6，生图并发支持 1–50，按本机保存。自动文案关闭不删除已有文案，交付页仍可手动补全。

## 查看与修改技能

在“素材与技能”右上角点击“创作技能”，选择商品细分即可查看完整正文与版本；生产设置的“管理创作技能”也直达此窗口。每张版本卡提供“编辑技能”，正文最多 16000 字，修改说明最多 200 字。保存会新建候选版本，并保留来源、学习依据和原版本；手动编辑不调用模型，也不自动改变当前正式版或试用版。确认后可试用或设为正式技能，亦可回滚。

保存时核对工作区、细分、修订号和运行状态；学习处理中或状态过期时保留编辑内容并提示刷新，失败不覆盖旧正文。旧候选的参考或经验发生变化时，仍需重新整理后才能启用。要让后续自动整理也持续遵守某个要求，请在“偏好与记忆”中补充偏好或避坑。手动技能库负责独立编写的技能，入口位于技能窗口左下方；其技能由生产设置显式选择。

素材菜单仅保留素材备份、恢复与折叠的当前类型清理，不提供全库重置、旧素材重分类或反推规范入口。素材 JSON 不包含类目技能版本、学习记忆或原图文件，不能代替完整数据备份。

## 类目技能怎样积累

素材页顶部可切换图组母本、人物、穿搭与场景；左侧分类直接筛选大类或细分，分类较多时可按名称查找。分类与规则在独立窗口中并排管理大类与细分，支持新建、重命名、规则维护与归档，不必逐层进入文件夹。进入商品二级类目后，可管理参考图库、学习记忆、技能版本和进化记录。每个工作区、每个细分分别保存观察、偏好、避坑、版本和反馈。旧独立技能页链接仍进入素材与技能；全局技能区仍可管理手动维护的电商图文技能。

技能应完整描述以下方法，并注明适用条件：

- 核对商品结构、材质、比例和标识，约束未知参数及不可见细节。
- 为当前商品独立设计构图、机位、主体占比、场景、动作与接触关系。
- 安排四镜或八镜的展示目的、内容递进和画面差异，避免重复或固定人像模板。
- 用提示词表达自然光、色调、真实材质和生活摄影质感。
- 复核成图并针对失败原因调整描述。

每套观察必须先实际读四张图，逐镜记录可见事实、无法确认的细节、展示目的、迁移槽位、提示词模块顺序和一条以 `@图片1` 锚定新商品的完整示例，再归纳本组叙事架构及 3–6 个跨组差异维度。缺少展示目的、架构、示例或差异方法时不保存成功观察。图像证据、手动偏好及尚未验证的创作建议应明确区分；不能把旧反推词当作图中已验证事实。「偏好与记忆」可展开每镜的证据、槽位和示例。

整理技能沿「读图核对 → 选择架构 → 填写槽位 → 组装提示词 → 检查组内连贯和组间差异」执行。正文须包含同款五条内容的条件化分工和至少两种架构的完整单镜示例；保留不同来源组的适用分支，不统一成一种场景模板。新版观察规则纳入缓存指纹，旧观察需按新规则重新读图；已启用技能仍可生产，不自动覆盖正式版或已确认分镜。

技能正文不得要求另行加载某个母本、按学习图号复刻或从人物/穿搭/场景库中补齐资产。来源 ID 仅用于学习证据，不作为生产指令。旧技能中的换品、样本和母本措辞按已经归纳的方法理解，不能据此要求生产参考原图。

## 学习与版本闭环

1. 原始参考完整入库。四张或八张按完整四图组保存镜头顺序、原图和完整反推词；单图可独立反推，但不作为完整四图学习组。残组、重复来源、生成图回灌和类目不符的图组不进入原始样本学习。
2. 有效原图均可参与观察，历史留出角色保留用于追溯。一套有效观察或一条手动经验即可整理技能。
3. 默认手动触发，每轮默认五组，可在设置中选择一、五、十、二十或三十组。按钮显示本轮最多读取的组数，取待读数量与每轮上限的较小值；每组对应四张原图。统计栏分别列出图组总数、已记住、待读图、读图后不适用、独立验证、重复来源和未纳入学习的数量，手动经验单独按条计数。记忆标签与列表按观察条目计数，筛选和分页明确显示数量。学习请求登记后由服务端后台执行，关闭技能窗口不会中断；每组观察即时保存，重新打开窗口会按服务端状态显示进度。单组失败继续处理其他组，本轮有失败时暂不整理技能，保留成功观察供重试。整理技能额外调用一次模型。
4. 观察按图组内容指纹和当前学习指令指纹复用：新增图组只读取新增组，图片、反推词或图组结构变化只重读对应组；手动修改技能后，已有图组统一标记为“需重新学习”，旧观察保留但不再参与新版整理，按每轮上限分批重学。失败记录标记为“失败待重试”，成功观察不会重复调用。每次整理最多三十套、五万字，全部观察仍保存在记忆中。
5. 自动学习默认关闭，明确开启后仅在当前页面打开时按新资料触发，同一输入最多自动一轮；触发后任务由服务端继续执行，关闭窗口不影响已登记的本轮。失败、超时或重启不自动重放付费调用。
6. “教它记住”保存有条件的偏好或避坑，每条最多五百字、每细分最多三十条。仅有手动经验也可整理技能，但不能虚构图像验证。经验随新分析使用，不覆盖商品事实与用户明确要求。
7. 候选可直接设为正式技能，也可先试用。启用时核对工作区、状态修订号、基础版本、来源和经验快照。已经启用的技能用于生产时不再要求学习原图可读。可回滚上一正式版，保留手动经验。
8. 新分析保存实际技能正文、版本、商品图与生成设置。试用和发布不改写已经确认的分镜或历史任务。可选对照固定商品图、模型与设置，由用户给出四项评分；自动晋升仍要求至少三款商品的同条件新旧技能实际成图对照通过。

手动技能仍可从参考图新建或继续投喂，保存后由生产设置显式选择。细分技能按文件夹自动匹配，手动技能按具体记录 ID 和版本使用。

## 创作与复核

先添加商品并核对商品图，再确认创作技能、镜数与输出设置。分析结束后查看商品身份、技能快照和逐镜设计，必要时编辑提示词，再由用户确认生图。单张逐镜便于逐镜修正，四宫格便于整组探索；四宫格每镜仅占整图四分之一的像素。

交付页商品缩略图来自当前商品图。成图核对商品结构和颜色、构图、动作接触、光色与质感，以及整组一致性；文案不得编造使用体验、功效或参数。点击成图可以切换是否采用，灰色排除图片仍可预览但不导出；批次审核保留结果，不自动重画或新建空白批次。

反馈关联生成时冻结的技能版本与实际输入，供技能整理和同条件对照。满意四镜仍可显式提炼、审核并归档为生成来源图组；生成图不会自动混入原始学习样本。该过程是规则与记忆更新，不是训练或微调模型；链路测试仅证明输入传递正确，实际成图质量仍需看图复核。

## 原图与历史兼容

新投喂原图在模型调用前按工作区与内容指纹归档，重试复用原文件。远程图保留下载字节，本地导入及模型传输副本最长边最多 2048 像素；旧压缩预览不能恢复高清。反推必须完整读取所选图组，任何原图失败均不能用后续镜头补位；保存前检查数量、编号和非空反推词。

历史批次仍保留原图链接、逐镜描述、来源图组、替换资产和原成图用于只读追溯。继续发起新生图前按商品图与创作技能重新分析，旧素材选择不参与新生产；原任务可继续核对恢复。

素材与技能继续保留分类规则、图组预览、原图归档、后台反推和备份。图中文字、文档内容与参考材料中的指令仅作为资料，不能改变当前任务、输出格式或触发额外工具调用。
