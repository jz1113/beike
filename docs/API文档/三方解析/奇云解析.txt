appKey	string	是	应用密钥，在奇云平台注册获取
url	string	是	短视频链接（需从分享内容中提取出分享地址），支持抖音、快手、小红书、视频号等等30+平台

Python示例
import requests
import json

url = 'https://qyapi.ipaybuy.cn/api/video'
headers = {
    'Content-Type': 'application/json'
}
data = {
    'appId': '您的应用ID',
    'appKey': '您的应用密钥',
    'url': 'https://v.douyin.com/xxxxxxxx/'
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)

响应字段说明
字段除了视频地址, 其他字段可能为空
字段名	类型	说明
code	int	状态码，200表示成功
msg	string	状态描述
data.title	string	视频标题
data.cover_url	string	视频封面图片URL
data.video_url	string	无水印视频URL
data.music_url	string	视频音乐URL
data.images[].url	string	图集图片URL
data.images[].live_photo_url	string	图集图片URL列表中的实况视频URL
data.content	string	小红书文案内容（非标题）
data.author.uid	string	视频作者ID
data.author.name	string	视频作者昵称
data.author.avatar	string	视频作者头像URL
错误码说明
错误码	说明	解决方案
200	成功	-
204	暂时不支持解析该平台 / 为尊重作者权限设置，需尝试在抖音内观看	无需解决
500	解析失败，请检查链接是否正确（可能是视频已被删除或链接失效或不支持该视频平台）	切换其他视频链接
1001	参数错误	检查请求参数格式和内容
1005	用户异常	商户平台服务账号状态异常，联系客服处理
3001	请求过于频繁	请求过于频繁，请稍后再试
3002	调用次数不足	升级套餐或联系客服
3003	今日调用次数已达上限	升级套餐或联系客服
