接口对接开发文档
帮助开发者快速接入和使用我们的API

接入说明
API
名称	详情
请求地址	
https://apia.vip/api/dsp/{clientSecretKey}/{clientId}/?url=将分享复制的链接，粘贴到这里（支持带中文链接与图集链接)
请求方式	GET/POST
响应格式	JSON
接口ID	（必填参数）请在管理您的API凭证和密钥信息查看
接口密匙	（必填参数）请在管理您的API凭证和密钥信息查看
解析接口地址	（必填参数）请在管理您的API凭证和密钥信息查看
🎥 通用请求说明
注意：以下字段适用于普通接口的请求，与实况（Live）类型的返回结构不同。

字段名	数据类型	描述说明
title	string	作品标题
cover	string	封面图片地址
download_image	string	下载封面图片地址
url	string	视频播放地址
down	string	视频下载地址
images	array	图集图片地址列表（多张）
bigFile	boolean	是否为超大文件（可选字段）
🎥 实况请求说明
注意：以下字段适用于实况（Live）类型的接口请求，与普通接口的返回结构不同。

字段名	数据类型	描述说明
images	array	返回图集（图片）
videos	array	返回视频（多个）
video	string	返回视频（单个）
image	string	返回图片（单张）
type	string	返回类型字段，值为 live
状态码说明
状态码	返回信息	处理方法
200	解析成功	查看接口请求返回结果
103	请输入正确的链接	检查传入的链接格式是否正确
104	接口不存在/暂停使用	该接口已接口不存在/暂停使用
107	数据结构异常	请联系系统管理员检查后台设置
108	会员接口不存在	检查用户ID和token是否为空或是否正确
109	接口被系统管理员关闭	请联系系统管理员检查接口用户权限
110	解析次数不足	请升级会员等级或明天再试
113	解析失败	请联系系统管理员更新/维护接口
114	作品已不存在或链接不支持	解析作品不存在或不支持检查作品是否公开或存在
115	会员等级不足	请联系系统管理员或者升级会员等级
155	接口ID或密钥不正确	请检查接口ID与密钥
