# 桌面安装包构建

## Windows（x64）

首次准备：
1. 安装 Windows x64 Node.js 22：https://nodejs.org/
2. 安装 Visual Studio Build Tools，勾选“使用 C++ 的桌面开发”和 Windows SDK：https://visualstudio.microsoft.com/visual-cpp-build-tools/
3. 安装 Rust，使用默认的 x86_64-pc-windows-msvc 工具链：https://rustup.rs/
4. 安装完成后重新打开终端或重启电脑，让 PATH 生效。

将完整源码解压到本地目录，双击根目录的 `一键打包Windows安装包.bat`。不要从 Mac 拷贝 node_modules 或 desktop/target；脚本会按照锁文件安装 Windows 依赖，并打包前端、API 服务、Node 运行时和安装程序。首次构建需要联网下载依赖和 NSIS 工具。

输出：`desktop/target/release/bundle/nsis/*-setup.exe`。将这个安装包复制给使用者；使用者无需安装 Node.js 或 Rust。安装器会在需要时联网安装 WebView2。

## Mac

安装 Node.js、Rust 和 Xcode Command Line Tools 后，双击 `一键打包Mac安装包.command`。

输出：`desktop/target/release/bundle/dmg/` 和 `desktop/target/release/bundle/macos/`。默认构建当前电脑架构，Apple Silicon 上的产物不适用于 Intel Mac。

## 配置与数据

构建读取 `.env.production`，不存在时读取 `.env`。源码迁移包默认不包含这些私密文件，需要保持相同服务配置时，请自行将所需配置安全复制到 Windows 项目根目录后再打包。不要把不应交付的密钥放入分发配置，打包程序会将配置内置到安装包中（私人存储字段会过滤）。

安装包使用新建的空白数据库模板，不包含当前电脑的业务数据。Python 深度处理环境需按 `works/scripts/depth/README.md` 另行配置。

默认未配置发布签名，系统可能显示未知开发者提示。构建失败会停留在窗口并返回失败状态，处理错误后重新运行即可。
