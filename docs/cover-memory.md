# 封面记忆

封面生成仍是一次出图：设计模型写出完整提示词，生图模型一次画出商品、背景和标题。封面记忆只约束这段提示词，不改变生图链路。

投喂样张在封面生成页右下角。一次收 1 到 10 张图片或图片 ZIP，每张单独反推。投喂时可按所选模型调整思考强度；尚未确认思考参数的型号使用模型默认设置，不另传档位。反推结束后打开封面记忆，待确认条目采纳后才进入生成。

记忆按工作区隔离，存在 `CoverMemorySample`、`CoverMemoryEntry`、`CoverMemoryUsage`。

## 条目状态

- `pending`：样张反推拆出的条目，等待采纳。不会进入封面设计。
- `adopted`：已采纳的样张规则，以及手写纠正。设计时注入。
- `trashed`：丢弃后进入回收站。可以恢复为待确认；纠正恢复后仍是已采纳。清空回收站会删除这些条目。

来源是 `sample` 或 `correction`。分支是构图、字体、字色、背景、主体、纠正。搭配规则记在字色分支，不单开节点。排重只留在样张拆解和当次设计单里。

## 注入顺序

设计提示词分三段：

1. 技能硬约束：主体居中、占高 62%–74%、标题至少一行压住商品上沿、标题 7–12 字且逐字锁定、不超过三色、禁止新增文字和 Logo。
2. 已采纳条目。全局纠正在前，然后只带本次选中的一张样张。请求留空或 `auto` 时，从已采纳样张里选最近的一组；`corrections` 只带纠正；指定样张编号必须已经采纳，否则设计直接失败。没有样张编号的旧条目归在 `ungrouped`。
3. 本批上一张封面的设计摘要，用来写排重。

没有已采纳条目时，设计提示词附上六句冷启动，并写明只是起稿、不能覆盖硬约束、不要套用固定风格名。已有记忆时不附冷启动。反推按这一张封面描述，不要求多张都成立，也不套用生成硬约束。搭配并入字色，排重不会变成记忆条目。多图一起反推的旧记录保留为旧版分组反推，不自动拆分或重新计费。

设计成功后把选中的样张和条目编号写进当次结果。同一张封面重试时继续用这次记下的样张。

## 引用记录

设计成功后写一条 `CoverMemoryUsage`，保存批次、条目标题、引用的条目和七栏设计。被引用的条目使用次数加一。审计卡的「引用记录」只说明这次注入了哪些条目，不表示模型已经照做。「回收站」读已丢弃条目。
